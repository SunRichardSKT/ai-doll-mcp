# 公共接入模板

普通安装从[使用教程](../docs/README.md)开始。模板中的地址、目标和令牌需替换为自己安装的实际值。

| 文件 | 用途 |
| --- | --- |
| `chatgpt-mcp-config.json` | 本机MCP客户端连接格式 |
| `host-event.example.json` | 自建应用事件接收格式 |
| `openclaw-hook.example.json` | 已有OpenClaw会话路由参考 |

Operit使用[当前统一工具包](../docs/integrations/OPERIT_SETUP.md)。ChatGPT使用[Secure MCP连接](../docs/integrations/SECURE_MCP.md)。更多接入见[宿主指南](../docs/integrations/HOST_INTEGRATIONS.md)，AI执行规则见[AI指南](../docs/ai/AI_GUIDE.md)。
