# ESP32-C3 预编译固件 2.12.1

普通用户按 [一键烧录教程](../../docs/start/QUICK_FLASH.md)操作，不用填写下表。设备连上家庭 Wi-Fi 后仍保留热点与固定设置页 http://192.168.4.1/。

## 维护人员：完整四文件

| 文件 | 地址 |
| --- | --- |
| bootloader.bin | 0x0000 |
| partitions.bin | 0x8000 |
| boot_app0.bin | 0xe000 |
| firmware.bin | 0x10000 |

芯片 ESP32-C3，4MB，DIO，80MHz。应用不能写到 0x0000。正常更新不擦除 NVS 或文件系统；明确恢复出厂才全片擦除。一键入口可选择自定义设备／热点名或随机名称；每次 USB 烧录仍生成独立内部配对编号，日常重启保留。

## 当前应用

应用大小、SHA-256和其他文件逐项校验统一见 [FLASH_MANIFEST.json](FLASH_MANIFEST.json)，避免文字说明与重新编译的镜像漂移。清单与编译输出配套，不含用户 Wi-Fi、NVS、令牌或模型密钥。固件保留 SuperMini 的 8.5dBm 无线功率设置。应用分区大小保持1310720 bytes，镜像必须小于该边界；设置页面、通道编辑和 OTA 脚本以 gzip 嵌入，启用编译链接优化保持原分区布局，由浏览器透明解压。

2.12.1 随软件2.24.1预发布提供，本版修正MCP工具说明后重新编译，不改变接线、电气参数、采样阈值或用户配置。交付检查覆盖编译、四镜像地址／哈希及嵌入网页资源；未向本轮用户设备烧录，尚无本版实板或OTA验收。此前固件的 USB 烧录、联网、CH0 压力及正常OTA记录仅证明各自报告中的版本，不能当作2.12.1的实测。其他硬件见 [验证范围](../../docs/reports/VALIDATION.md)。

全新安装仅CH0已接入真实采样，其他压力端口关闭；旧板通道、校准和旧暂停策略保持。端口关闭／模拟／已接入由内核保存，模拟端口与真实端口可并存。普通设置不再显示日常／手动开关。

源码修改后先 [重新构建](../../docs/developers/DEVELOPER_GUIDE.md)，运行 tools/export_firmware.py 更新镜像和清单。已有固件的局域网升级见 [OTA 教程](../../docs/daily/OTA_UPDATE.md)。

2.12系列新增硬件派生固定 `.local` 连接名和不含凭据的身份查询；家庭IP变化后供Operit按名称重连。服务器上传关闭时的文案同时说明电脑采集与手机直连。设备保持原分区，保留通道、校准与配对数据。
