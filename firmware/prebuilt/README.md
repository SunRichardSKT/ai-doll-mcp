# ESP32-C3 预编译固件 2.13.1

普通用户按 [一键烧录教程](../../docs/start/QUICK_FLASH.md)操作，不用填写下表。首次配网热点最长10分钟，新配网成功后约90秒关闭。已保存Wi-Fi的正常重启不开热点；运行中长按BOOT约3秒重新开启，再连接热点访问 http://192.168.4.1/。

## 维护人员：完整四文件

| 文件 | 地址 |
| --- | --- |
| bootloader.bin | 0x0000 |
| partitions.bin | 0x8000 |
| boot_app0.bin | 0xe000 |
| firmware.bin | 0x10000 |

芯片 ESP32-C3，4MB，DIO，80MHz。应用不能写到 0x0000。正常更新不擦除 NVS 或文件系统；明确恢复出厂才全片擦除。一键入口可选择自定义设备／热点名或随机名称；每次 USB 烧录仍生成独立内部配对编号，日常重启保留。

## 当前应用

应用SHA-256和其他文件逐项校验统一见 [FLASH_MANIFEST.json](FLASH_MANIFEST.json)，清单与编译输出配套，不含用户 Wi-Fi、NVS、令牌或模型密钥。当前2.13.1候选镜像为 **1,297,744 bytes**；单个OTA应用槽保持 **1,310,720 bytes**，余量 **12,976 bytes**。固件保留 SuperMini 的8.5dBm无线功率设置。设置页面、通道编辑、OTA及配对二维码脚本以gzip嵌入，启用编译链接优化保持原分区布局，由浏览器透明解压。新增功能后必须重新检查镜像实际大小，不能缩减历史或OTA分区换空间。

2.13.1随[软件2.25.0预发布](https://github.com/SunRichardSKT/ai-doll-mcp/releases/tag/v2.25.0)提供。新增30个设备工具中的3个内部归档租约工具，以及手机连接文件／连接码／临时二维码页面；不需要给设备贴二维码标签。归档租约90秒、每30秒续租，确认Flash记录必须匹配当前启动、epoch、租约及持有者已读取游标。设备直传、电脑和手机按单主归档协调，不增加物理输出，不改变接线、电气参数或采样阈值。

本轮已通过编译、四镜像地址／哈希、生产租约策略原生C++测试及电脑归档协议检查，分区、启动镜像和boot_app0未改变；没有向用户设备烧录，尚无2.13.1实板、配网或OTA验收。此前的USB烧录、联网、CH0压力及正常OTA记录仅证明各自报告中的版本。其他硬件见 [验证范围](../../docs/reports/VALIDATION.md)。

全新安装仅CH0已接入真实采样，其他压力端口关闭；旧板通道、校准和旧暂停策略保持。端口关闭／模拟／已接入由内核保存，模拟端口与真实端口可并存。普通设置不再显示日常／手动开关。

源码修改后先 [重新构建](../../docs/developers/DEVELOPER_GUIDE.md)，运行 tools/export_firmware.py 更新镜像和清单。已有固件的局域网升级见 [OTA 教程](../../docs/daily/OTA_UPDATE.md)。

2.12系列新增硬件派生固定 `.local` 连接名和不含凭据的身份查询；家庭IP变化后供Operit按名称重连。服务器上传关闭时的文案同时说明电脑采集与手机直连。设备保持原分区，保留通道、校准与配对数据。
