# ESP32-C3 预编译固件 2.12.0

普通用户按 [一键烧录教程](../../docs/start/QUICK_FLASH.md)操作，不用填写下表。设备连上家庭 Wi-Fi 后仍保留热点与固定设置页 http://192.168.4.1/。

## 维护人员：完整四文件

| 文件 | 地址 |
| --- | --- |
| bootloader.bin | 0x0000 |
| partitions.bin | 0x8000 |
| boot_app0.bin | 0xe000 |
| firmware.bin | 0x10000 |

芯片 ESP32-C3，4MB，DIO，80MHz。应用不能写到 0x0000。正常更新不擦除 NVS 或文件系统；明确恢复出厂才全片擦除。一键入口可选择自定义设备／热点名或随机名称；每次 USB 烧录仍生成独立内部配对编号，日常重启保留。

## 当前应用

大小 **1273344 bytes**；SHA-256：

```text
d0c9ab52456c98fca28e54eda5332611e6fb179e4a1e56943e9c20b4d6aad9e7
```

其他文件逐项校验见 [FLASH_MANIFEST.json](FLASH_MANIFEST.json)。清单与编译输出配套，不含用户 Wi-Fi、NVS、令牌或模型密钥。新固件保留 SuperMini 的 8.5dBm 无线功率设置。应用分区大小保持 1310720 bytes，镜像余量 37376 bytes；设置页面、通道编辑和 OTA 脚本以 gzip 嵌入，启用编译链接优化保持原分区布局，由浏览器透明解压。

2.12.0 已完成编译、四镜像地址／哈希校验、烧录流程模拟回读测试和嵌入脚本逐字节解压检查，尚未烧录本轮实体设备。全新安装仅CH0已接入真实采样，其他压力端口关闭；旧板通道、校准和旧暂停策略保持。新增端口关闭／模拟／已接入，由内核保存，模拟端口与真实端口可并存。普通设置不再显示日常／手动开关。2.12.0为本机候选；此前2.9.0 的 USB 烧录、联网和 CH0 压力记录不当作 2.12.0 的实板或 OTA 验收；其他硬件见 [验证范围](../../docs/reports/VALIDATION.md)。

源码修改后先 [重新构建](../../docs/developers/DEVELOPER_GUIDE.md)，运行 tools/export_firmware.py 更新镜像和清单。已有固件的局域网升级见 [OTA 教程](../../docs/daily/OTA_UPDATE.md)。
