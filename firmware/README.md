# 第一代 ESP32-C3 固件

这里的 `supermini-lab` 构建目标、`src/` 源码和 `prebuilt/` 镜像均属于第一代 C3 核心，适用于已制带线板与最终锁扣插座板。配套版本为 0.1.5。

固件目录保留现有位置，供构建、烧录及OTA工具使用；产品代际见[硬件分类](../hardware/README.md)。目前没有在此提供ESP32-S3二代构建目标或预编译镜像，二代状态见[研发进度](../hardware/gen2/README.md)。

- [预编译镜像与烧录地址](prebuilt/README.md)
- [第一代PCB与接线](../hardware/gen1/README.md)
