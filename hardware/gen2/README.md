## 接下来按这个顺序推进

1. **收敛首版需求。** 回收并分析问卷，确定体积、供电、连接方式及最优先的功能；保留摄像头后置安排。
2. **确认开发板和资源。** 固定具体S3板型、Flash／PSRAM、可用引脚和供电方式，形成首个原型的资源清单。
3. **定模块接口。** 交付连接座、供电边界、针脚表和最小通信约定，再接入对应模块。
4. **做开发板原型。** 先让联网、压力输入与一组音频输入输出工作，再逐项加入温度／姿态、振动／舵机和底盘；分别记录实际结果。
5. **再进入PCB和外壳。** 原型功能和功耗稳定后，设计载板、模块板与机械结构，准备打样。

本次工作是整理已有材料与研发状态，没有新增二代硬件设计或宣称完成多媒体驱动。
