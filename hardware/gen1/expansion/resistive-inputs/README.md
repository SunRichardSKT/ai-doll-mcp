# 第一代 C3 核心：温度与擦眼泪扩展

适用于现有八路 FSR 电路，包括已制带线板和第一代最终锁扣插座板。**替换两路传感器，得到 6 路压力＋1 路 NTC 温度＋1 路擦眼泪感应片。** 使用现有八个插口；需要保留八路压力再加探头时，另加分压小板与采样接口。

## 版本和已有数据

| 版本 | 支持情况 |
| --- | --- |
| 0.1.1，`pressure-switch-v1` | 压力、干接点；不能读取 NTC 或识别擦眼泪 |
| 0.1.2，`resistive-inputs-v1` | 增加 NTC 和湿润＋按压事件；配套 0.1.2 软件与 Operit |

准备配套 0.1.2 软件、Operit 与固件，先读 `get_channel_capabilities`，确认 `temperature`、`wetness` 后配置目标端口。升级保留历史、压力校准与原端口设置，按下方步骤选择转换的两路。配套文件见 [v0.1.2 Release](https://github.com/SunRichardSKT/ai-doll-mcp/releases/tag/v0.1.2)。

## 1. 共用电路与端口

```text
3.3V ─ 主板4.7kΩ ─ Jx.1(EXC) ─ [NTC或两片湿润电极] ─ Jx.2(CH)
                                                         │
                                                   主板10kΩ → GND
                                                         │
                                                   4051 → GPIO0 ADC
```

两个针脚是激励端和信号端，**不是供电正负极**。不加外部电源；保留现有电阻、电容和采样接线。无源 NTC／电极自身无正负极，插头仍按主板线序装配。

推荐示例：J1～J6 接压力，J7/CH6 接 NTC，J8/CH7 接湿润片。擦眼泪所需压力可选 J1～J6 中任意已接入的掌部压力；示例引用 CH0，只是演示，按实际安装修改。

第一代最终版 J1～J8 统一使用 **PA2.0 2P 锁扣接口**，板端为S02B-PASK-2，配套线端PAP-02V-S及PA端子。温度探头与湿润片均直接焊接配套PA2.0两芯线束，不另加转接头；两根焊接处分别热缩绝缘，再固定线尾，避免拉力落在探头上。探头无正负极。采购UT422时选择裸线／定制PA尾线；已有探头可剪掉原插头接PA线束。已制带线板按实际线序对接PA插头，不能仅看线色判断。


## 2. 温度：UT422 / NTC 10k B3435

可用 UT422 这类两线无源 NTC，按采购参数 **R25=10kΩ、B=3435K** 换算。采购时确认 R25、B 的参考温区与公差、探头尺寸和耐汗性；软件填写实购 B3435 参数。

本板分压在 0 / 25 / 40℃ 的标称 ADC 电压约为 **0.760 / 1.336 / 1.613V**，属于可采集范围。ADC 使用校准毫伏值，计算包含主板 4.7kΩ 串联和 10kΩ 下拉：

```text
Rntc = Rdown × (Vsupply / Vadc - 1) - Rseries
T(℃) = 1 / (1/298.15 + ln(Rntc/R25)/B) - 273.15 + offset_c
```

默认每秒采样，变化 1℃或每 30 秒归档一次；第一条有效读数建立聊天基线。软件接受 -20～80℃，断线、短路与超范围显示无效状态。`offset_c` 用于与参考温度计对照后的一点修正，测量精度同时取决于探头、分压与安装方式。

**安装在手掌或胸前的薄布下，感知接触带来的升温。** 感温端贴近表层，背面用少量软棉隔热，避开电池、充电板与主控。深埋填充棉时主要测娃娃内部温度；这里用于局部接触温度感知，不用于医疗测温。装好后隔着实际布料测试响应时间。

安装建议：小型绝缘封装探头＋柔软两芯线，感温端不用厚热熔胶包住；线路另做应力释放，用户能拆换探头。先在室温下与参考温度计对照，再隔着实际布料接触测试。默认分压在 25℃ 时 NTC 功耗约 0.18mW，自热影响随探头散热和封装变化。

## 3. 擦眼泪：两片导电布＋掌部压力

双电极感知湿润，并与掌部压力配合：两片导电材料湿润连通，相关压力通道正在按压时，产生一次 `wipe`（擦眼泪）事件。

建议先做可拆换的小布片：约30×25mm吸水布，下面放两条约5×15mm的不锈钢导电布／不锈钢导电线电极，平行间隔2～3mm；两条电极始终分开，不让导电线相碰。表面覆盖薄的非导电吸水布，背面做绝缘层；电极分别接该传感器口的两根线。压力FSR装在掌部另一层，避免金属边缘压伤薄膜。湿润片是独立通道，不能与FSR并接同一个口。

电极与软线用压接或缝合固定，接头绝缘、线尾留弯并固定在布基上，拉线时不把力传到电极。湿润片远离核心、电池和裸焊点，做成能单独拆洗／更换的耗材；不用不明耐腐蚀性的裸铜作为长期接触面。现板是低电流直流激励，长期浸湿会有极化、腐蚀和残留漂移；使用后晾干、定期清洁，持续湿润用途再考虑交流激励小板。

默认规则：

- 原始读数连续高于 `wet_threshold=500` 满 `hold_ms=600` 才确认湿润。
- 此时或其后，对应 `pressure_channel` 的真实压力处于按压状态，发一次 `wipe`。
- 同一湿润阶段，再多次按压也不重复发主要事件。
- 低于 `dry_threshold=250` 持续 `dry_ms=1000` 才复位；短暂抖动不复位。
- `wet`、`dry` 仅归档；只有 `wipe` 可选进入回复。温度和擦眼泪默认只记录，用户在 Operit“身体与传感器”允许后，继续沿用已有主动回复开关、聊天绑定和队列。

500／250 是初始设置。制作后记录干布、湿布两组读数，将上阈值设在两组之间，下阈值略低；确认干布按压不会触发、湿布无按压不发送回复、一次湿润只回应一次、晾干后可再次触发。模拟压力不能帮助真实湿润片确认擦眼泪。

## 4. 设置顺序

1. 保存现有配置；断电后把选定的两个接口换接探头／感应片。
2. 升级配套0.1.2后读能力；设置页中打开对应端口的“硬件高级设置”，原压力端口分别切换为“温度输入”“擦眼泪感应片”。会保留物理端口编号并先关闭该路。
3. NTC 使用默认10k/B3435参数；湿润通道的 `pressure_channel` 填真实掌部压力的逻辑编号。不要直接用示例覆盖已有部位和校准。
4. 点击“保存硬件高级配置”，核对全部通道，再将两路设为“已接入”。检查有效温度、干／湿状态及原始值。
5. 在 Operit“身体与传感器”分别选择“只记录／允许回复”；温度首样本、wet/dry、故障与离线补传不作为新互动。电脑／服务器通过 `update_companion_preferences(changes={policy:{temperature_enabled:true,wetness_enabled:true}})` 设置。

所有部位和阈值按实际装配选择。空白测试设备可使用完整示例；已有设备先读取全部配置，再修改目标行并保留其余行。
