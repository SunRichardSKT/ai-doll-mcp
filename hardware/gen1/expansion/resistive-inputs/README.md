# 第一代 C3 核心：温度与擦眼泪扩展

适用于现有八路 FSR 电路，包括已制带线板和第一代最终锁扣插座板。**替换两路传感器，得到 6 路压力＋1 路 NTC 温度＋1 路擦眼泪感应片。** 使用现有八个插口；需要保留八路压力再加探头时，另加分压小板与采样接口。

## 1. 共用电路与端口

```text
3.3V ─ 主板4.7kΩ ─ Jx.1(EXC) ─ [NTC或两片湿润电极] ─ Jx.2(CH)
                                                         │
                                                   主板10kΩ → GND
                                                         │
                                                   4051 → GPIO0 ADC
```

两个针脚是激励端和信号端，**不是供电正负极**。不加外部电源；保留现有电阻、电容和采样接线。无源 NTC／电极自身无正负极，插头仍按主板线序装配。

推荐示例为 J1～J6 接压力，J7/CH6 接 NTC，J8/CH7 接湿润片。示例文件和接线图演示 CH0 压力联动。0.1.5 起也可只接湿润片。

第一代最终版 J1～J8 统一使用 **PA2.0 2P 锁扣接口**，板端为S02B-PASK-2，配套线端PAP-02V-S及PA端子。温度探头与湿润片均直接焊接配套PA2.0两芯线束，不另加转接头；两根焊接处分别热缩绝缘，再固定线尾，避免拉力落在探头上。探头无正负极。探头可选裸线自行焊接 PA 尾线，或定制 PA2.0 2P 成品线。已制带线板按实际线序对接PA插头，不能仅看线色判断。


## 2. 温度探头 · NTC 10 kΩ B3950

采购规格选 **两线无源 NTC，25℃ 时 10 kΩ，B3950，PA2.0 2P**。“温度（NTC）”已内置对应参数。

本板分压在 0 / 25 / 40℃ 的标称 ADC 电压约为 **0.683 / 1.336 / 1.650 V**，属于可采集范围。ADC 使用校准毫伏值，计算包含主板 4.7kΩ 串联和 10kΩ 下拉：

```text
Rntc = Rdown × (Vsupply / Vadc - 1) - Rseries
T(℃) = 1 / (1/298.15 + ln(Rntc/R25)/B) - 273.15 + offset_c
```

默认每秒采样，变化 1℃或每 30 秒归档一次；第一条有效读数建立聊天基线。软件接受 -20～80℃，断线、短路与超范围显示无效状态。`offset_c` 用于与参考温度计对照后的一点修正，测量精度同时取决于探头、分压与安装方式。

0.1.5 起，温度卡片显示 ADC 毫伏和换算阻值。换用其他探头时，可用数据表或实测阻温点配置[自定义曲线](../../../../docs/daily/SENSOR_CHANNELS.md#温度偏差和自定义曲线)。

**安装在手掌或胸前的薄布下，感知接触带来的升温。** 感温端贴近表层，背面用少量软棉隔热，避开电池、充电板与主控。深埋填充棉时主要测娃娃内部温度；这里用于局部接触温度感知，不用于医疗测温。装好后隔着实际布料测试响应时间。

安装建议：小型绝缘封装探头＋柔软两芯线，感温端不用厚热熔胶包住；线路另做应力释放，用户能拆换探头。先在室温下与参考温度计对照，再隔着实际布料接触测试。默认分压在 25℃ 时 NTC 功耗约 0.18mW，自热影响随探头散热和封装变化。

## 3. 擦眼泪感应片

两片导电材料湿润连通。达到设定持续时间后，独立模式产生一次 `wipe`（湿润互动）事件。使用压力联动时，还需要对应压力通道处于按压状态。

批量制作使用[泪水感应片 R01 设计包](../tear-pad/README.md)：成品30×35mm，双316L导电织物电极、3mm金属间距、薄亲水面布、TPU背衬、密封接点与独立固线，配PA2.0 2P线束。目录包含1:1裁切图、材料清单和检验项目，先做首件和小批封样。压力FSR装在掌部另一层，避免金属边缘压伤薄膜。湿润片是独立通道，不能与FSR并接同一个口。

电极与软线用压接或缝合固定，接头绝缘、线尾留弯并固定在布基上，拉线时不把力传到电极。湿润片远离核心、电池和裸焊点，做成能单独拆洗／更换的耗材；不用不明耐腐蚀性的裸铜作为长期接触面。现板是低电流直流激励，长期浸湿会有极化、腐蚀和残留漂移；使用后晾干、定期清洁，持续湿润用途再考虑交流激励小板。

默认规则：

- 原始读数连续高于 `wet_threshold=500` 满 `hold_ms=600` 才确认湿润。
- 仅湿润模式当即触发一次 `wipe`。压力联动模式等对应 `pressure_channel` 的真实压力处于按压状态后触发。
- 同一湿润阶段只触发一次 `wipe`。
- 低于 `dry_threshold=250` 持续 `dry_ms=1000` 才复位；短暂抖动不复位。
- `wet`、`dry` 仅归档；只有 `wipe` 可选进入回复。温度和擦眼泪默认只记录，用户在 Operit“身体与传感器”允许后，继续沿用已有主动回复开关、聊天绑定和队列。

500／250 是初始设置。制作后记录干布、湿布两组读数，将上阈值设在两组之间，下阈值略低。确认干燥时无触发，湿润时按所选模式触发一次，晾干后可再次触发。压力联动的两个输入需使用相同来源。

## 4. 设置顺序

1. 保存现有配置；断电后把选定的两个接口换接探头／感应片。
2. 打开设备网页的“传感器端口”，按 J 编号找到接探头的口，选“温度（NTC）”，填位置名称，选“已接入”，点“保存此端口”。
3. 同一端口卡片显示温度。新配置的温度端口使用 10 kΩ B3950；如果旧温度端口显示自定义参数，点“使用 10K B3950”并保存。
4. 若也安装了湿润片，在对应口选“擦眼泪感应片”，选择仅湿润触发或相应的压力联动，选“已接入”并保存。0.1.4 用户在高级参数中指定 `pressure_channel`。
5. 在 Operit“身体与传感器”分别选择“只记录／允许回复”；温度首样本、wet/dry、故障与离线补传不作为新互动。电脑／服务器通过 `update_companion_preferences(changes={policy:{temperature_enabled:true,wetness_enabled:true}})` 设置。

所有部位和阈值按实际装配选择。空白测试设备可使用完整示例；已有设备先读取全部配置，再修改目标行并保留其余行。
