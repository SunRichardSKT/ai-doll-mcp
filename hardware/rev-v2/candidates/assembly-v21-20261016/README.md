## 已实际修改

| 项目 | 当前候选 |
| --- | --- |
| 板框 | 从 34.29 × 44.45 mm 扩至 42.418 × 46.482 mm；四角 R1.524 mm |
| 面积取舍 | 增加约 29.4%，先在原电路外增加线束固定空间；不是缩板方案 |
| 八路线束固定 | 左右各四路；每路两个约 2 mm 的无铜铣空，孔心沿纵向相距 3.302 mm |
| 独立绑固位置 | 上方两个约 2.4 mm 开孔，用于绝缘绑固；不是经过紧固件净空认证的螺丝孔 |
| 标识 | 增加 CH0～CH7 与候选版本标识，保留原文字及背面镜像修正 |
| 现有电路 | 51 个元件、焊盘网络、铜层、规则、315 条铜线及 43 个过孔保留；不移动既有元件 |

线束按“SM 线对线接头 → 两芯软线 → 夹住绝缘皮的固定带 → 短剥皮段 → J 焊线孔”装配。固定带从每路两个孔穿过，承担拉力；焊点不直接承担线束拉力。预览只画 CH0 的线束作为示意，未给其他路虚构实体线束模型。

FSR 接口的两端为 EXC／CH，不是 5V／GND；线色不作为电气定义。现有 J 焊盘孔径仍保留，待确定实际线规后再调整。新增孔采用 MULTI 层 64 边形铣空表达，尚未验证钻铣输出与实际孔径公差；不把它当作正式钻孔表。

## 尚未落板的优化

**SuperMini 的邮票孔贴片安装尚未修改。** 现工程仍使用原通孔封装。当前仅有旧封装的 2.54 mm 引脚节距和 15.24 mm 排距，不能由此推定实际模块边缘、邮票孔焊盘外伸量、USB 壳体或模块背面凸起。下一版需要实物尺寸或对应型号的可靠机械图；不能用另一款 ESP32-C3-MINI-1 模组封装替代。

同面集中阻容、专用大焊线焊盘、电源接口防误插与双源隔离也尚未改变。它们需要新封装、真实模块电源关系和重新布局布线。先评估当前固定方式是否值得保留，避免为尚未确认的结构重布整板。

## 本轮检查与限制

- 完成两轮显式保存（`saved: true`）、重载及新数据回读；两轮组件、铜、丝印及板框一致。
- 18 个新增开孔逐轮与生成源对账；10 个新增文字均为顶层文字，原文字未改。新增孔到元件包络最小约 1.65 mm，到新文字包络约 0.23 mm。
- 开孔到直板边最小余料约 0.82 mm，未经过拉力或寿命验证。扎带宽厚、线皮外径、板厚及材料尚未确定，不能据此认证强度。
- 原生 DRC 仍 `passed: false`，有 1 项既有 `Netlist Error / Import Changes`。本次没有自动重绑原理图或导入变更。
- 补充 DFM 检查也未全通过：既有铜几何中报告 CH5 过孔到 U1.2（GPIO6_SPARE）约 5.5 mil，小于该检查的 6 mil 规则，并有其他警告。未用“没有改铜”冒充制造通过；正式改版须逐项复核。
- 原生工程导出通过 ZIP 完整性检查，18 个最终开孔在导出源码中存在，试验开孔已移除；导出文件尚未重导入验收。
- `布局对比.png/svg` 是从两份真实回读生成的工程示意，标出的线束为装配说明，不是官方 3D 或 Gerber 预览。官方画布截图取得过一次，但当时图层隐藏了新增区域；因此不作为装配效果的主要证据。
- 临时预览图层已恢复并核对。本轮没有整板布线、生成新 Gerber、验证邮票孔装配或实物强度。

正式下单前必须完成模块与线材测量、配置网表一致性、封装替换和布局确认、布线与全项 DRC／DFM、正反面和 3D 检查，以及孔槽工艺核对。
