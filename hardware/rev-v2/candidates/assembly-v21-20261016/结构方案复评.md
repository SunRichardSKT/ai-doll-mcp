# 装配结构复评：减少开孔与 SuperMini 尺寸依据

2026-10-16。状态：方案复评，未修改候选 PCB，也未把新尺寸直接写成生产封装。

## 对 V0 的取舍

固定孔只有配合扎带、压线结构或外壳固定点，夹住带绝缘皮的线段，才能减轻焊点拉力。裸孔不能独立完成线束固定；主板安装与线束应力释放是两项不同功能。

V0 为保留全部旧走线，在板外增加固定区，导致面积增大约 29.4%。它可以展示逐路固定的效果，但不建议以此作为最终主方案。18 个铣空也未验收孔槽工艺、扎带配合和强度，不能当作量产优势。

## 更适合当前带线 SM 接头的选择

| 结构 | 适用情况 | 取舍 |
| --- | --- | --- |
| 两束线集中固定 | 手焊、无定制外壳 | 左右四路各收一束，在短剥皮段之前夹紧线皮；优先研究两组共用固定位置，减少逐路孔。需要重排焊线位和检查走线空间，不能保证直接塞入原板框。 |
| 外壳卡槽固定板＋出口压线 | 有 3D 打印或注塑保护壳 | PCB 由卡槽托住，线束由独立压条或软护套夹紧；可减少板上孔位。需要外壳尺寸与反复拉弯验证。 |
| 板端可拆连接器 | 经常更换主板 | 保留传感器侧 SM，用匹配板端连接器的转接线；增加高度、成本和接触点。连接器锁扣不能替代整束线的拉力固定。 |

推荐下一版优先尝试“邮票孔侧焊＋紧凑焊线区＋两束线集中固定”，外壳压线作为有壳版本。不要为没有明确用途的螺丝孔或逐路扎带孔扩大整板。胶粘仅可按胶材与环境验证后作辅助，不默认用热熔胶作为长期唯一固定。

## 已查到的厂家依据

- [Nologo SuperMini 本体页面](https://www.nologo.tech/product/esp32/esp32c3/esp32c3supermini/esp32C3SuperMini.html)：正文外形 22.52 × 18 mm，描述单面元件与表面贴装设计。
- [厂家 GitHub Hardware 目录](https://github.com/NologoTech/ESP32C3-Supermini/tree/main/Hardware)：提供 `ESP32-C3尺寸图.png`、`Super Mini-ESP32C3-外形.PcbDoc` 和电路图。
- 已实际查看厂家仓库尺寸图：标注宽 18.00 mm、长 22.50 mm、两排孔中心距 15.24 mm。正文长度与图纸相差 0.02 mm，不能自行解释为加工公差。
- 用户最初提供的 ExpansionBoard 页面是电池扩展底板，不能用其外形尺寸替代 SuperMini 本体尺寸。

以上足以确定模块的外形包络与两排中心距，继续开展封装核对；不能把模块外形尺寸直接冒充推荐母板焊盘。邮票孔铜形、边缘关系、引脚顺序、USB 凸出与底面净空仍需与厂家源文件和实际采购版本对账。存在对应图纸时先用厂家资料，不重复要求用户手量已明确标注的尺寸。
