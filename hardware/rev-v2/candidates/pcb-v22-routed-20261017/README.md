## 实际修改

- 保留 34.29 × 44.45 mm 板框、51 个器件、126 个焊盘、全部位号、通道网络、70 处文字及四个线束切口。元件位置、原理图连接和电阻电容参数未改。
- 当前回读为 **355 段走线、21 个过孔、2 个 GND 铺铜边界**，两面均有实际材料化铜。不是只有铺铜边框。
- 普通信号采用 10 mil；3V3、SYS5V、PWR5V_RAW 和 GND 设置独立电源网络类，默认线宽 20 mil。维持原两层板及原设计净距/过孔规则，没有降低规则消除告警。
- 优先完成 C12 → U1、C10 → U2 的去耦供电线，以及 U2 → R17 → C9 → U1 的采样链路，再完成其余网络。
- 移除导入产生的一个重叠 ADC 过孔，并清理两个已经进入同网焊盘/过孔的冗余短线段。重建铺铜后重新检查，没有引入开路。
- 天线双面禁铜、背面禁器件以及线束孔保护区域保持原样；铺铜避让这些区域。

八路接口的信号来自 **J1～J8 的第 2 脚**，分别是 CH0～CH7；第 1 脚是各路 EXC 激励端。该对应关系来自本次原理图和焊盘回读，不能按导线颜色推断。FSR 是板外器件，本轮没有重新烧录或进行实体传感器测试。

## 验证结果

1. 两轮保存、重载、实际回读和原生整板图检查已完成，器件、丝印、板框、走线、过孔、禁区、切口及铺铜数据一致。
2. 按器件 uniqueId 逐项核对了 51 个 PCB 器件与原理图的 pin → pad → net。U1 的 8 个未使用脚和 SW1 的未使用脚有明确 NC，不把未知网络当 NC。
3. 八路 Jx.2 → 74HC4051 对应通道脚均取得真实铜路径证明；C12.1 → U1.14、C10.1 → U2.16、U2.3 → R17.1 也已证明。ADC 另行证明 **R17.2 → C9.1 → U1.9** 的顺序路径，跨两层、使用 1 个过孔、最小线宽 10 mil。它们不是同网名推断，路径检查不把铺铜视为已证明走线。
4. 初次布线检查有 1 项 Netlist Error。2026-10-17 用户在编辑器点击应用修改后，两次完整原生 DRC 均返回 `passed:true`、0 项违规，第二次在显式保存和重载后执行。前后回读的器件、引脚网络、丝印、板框、设计规则及全部铜数据一致；接口未提供该次导入的具体元数据差异，因此不推断其内部原因。当前工程与导出文件已更新，先前失败的原始检查记录保留在本机。
5. 补充 DFM 检查原始结果保留：2 项 via/OVAL 包络间距错误、19 项提醒、28 项信息。两项错误以矩形包络保守估算；根据实际 OVAL 胶囊形与圆形过孔独立计算，间距约为 **8.07 mil、6.92 mil**，高于当前 5.98 mil 规则，原生 DRC 亦未报告这两项。这个交叉检查没有修改原工具结果，也不把补充检查改写为全部通过。
6. 其余提醒包括 C11 储能电容位置、带线接口被按板载护套估算、相邻走线耦合及电源铺铜策略。项目采用带线焊接、低速传感输入及较宽电源导线；这些观察仍保留在核对记录中，不能代替装配、电源压降和真实采样测试。

## 定版前仍需完成

- 当前 SuperMini 系统库的外侧焊盘按 18 mm 模块宽度估算只露出约 0.05 mm，手焊空间不足的风险尚未解决。应校核实物邮票孔、加长合适的手焊焊盘并重新检查，不能将“布通”视为封装已适配。
- 检查模块底部元件和 USB 插头净空、线径/钻孔、扎带和 64 边形板材切口的制造解释。
- 确认新工程底面物理 3D 的文字方向，并进行制造预览和实物测试。
