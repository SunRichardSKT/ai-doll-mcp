# C3八路锁扣插座板 P03

[主板资料](../../README.md) · [配套外壳 P04](../../../enclosure/c3-socket-stacked/README.md) · [嘉立创原生工程](AI_Doll_C3_Socket_P03.epro2)

基于现用ESP32-C3内测板，保留34.29 × 44.45 mm双层板、74HC4051、八路采样、原电气参数和固件引脚。后右侧开关为普通直头Type-C留出通道；P03增加三针锁扣电源座，并修正R1/C12的装配间距。

## 传感器插座

J1～J8使用 **JST PA 2.0 mm、2P、通孔侧插、带锁扣** 的S02B-PASK-2(LF)(SN)，嘉立创库料号C265094。左右各四座，中心间距8 mm，插入口朝外。

线端采用PAP-02V-S及配套端子，优先购买压好端子的线束。原SM2.54线不能直接插入；可保留传感器侧SM接头，在主板侧更换PA接头或使用转接线。

**1脚为各路EXC激励，2脚为各路CH信号，并非一脚接地。** J1～J8仍对应CH0～CH7。FSR本体不分极性，其他传感器按实际电路确认接法。

来源：[JST PA系列](https://www.jst-mfg.com/product/index.php?lang=2&series=189)、[原厂尺寸手册](https://www.jst-mfg.com/product/pdf/eng/ePA-F.pdf)。

## 开关、维护口与供电

- SW1移到后右侧并旋转90°，外壳从右侧下沉口拨动开关。
- J9改为后左侧PA2.0 3P侧插锁扣座：**1脚GND、2脚不接、3脚PWR5V_RAW，输入5V**。
- C13、C14移到底面前侧，远离插座塑壳和USB插入空间。
- C12与R1拉开约1.46 mm；C11移到底面，R18、C9和ADC测试点让开电源插座焊脚。
- TP4（ADC）在底面左后侧，名称、网名与原理图一致；底面丝印按底视方向可读。
- 保留SuperMini天线双面禁铜区。此板不集成锂电池充电、保护或升压。

配套[堆叠壳 P04](../../../enclosure/c3-socket-stacked/README.md)为42.89 × 56.45 × 33.5 mm，103450电池下置，主板在上。前侧维护孔15 × 9 mm，按14 × 8 mm截面的直头插头检查插入通道。开关位于后右侧；充电模块仍使用独立[四线保护壳](../../../enclosure/charger-inline/README.md)。

### 三针电源接线

板端为 **S03B-PASK-2(LF)(SN)**，嘉立创料号 **C265095**；线端用 **PAP-03V-S**及配套压接端子，优先购买压好端子的线束。传感器仍使用2P接口。

| J9针号 | 用途 |
| --- | --- |
| 1 | GND，接充电模块输入输出负极 |
| 2 | NC，保持不接 |
| 3 | +5V / PWR5V_RAW，接充电模块输入输出正极 |

**旧两针板J9.2是正极，本版J9.2已空置，不能沿用旧针号。** 不按线色推断极性，装配前核对线端孔位及插座1脚标记。

充电模块的B+/B−仍通过PH2.0接电池；独立输入输出正负焊点接主板。主板端换PA3P插头，已有SM线束可通过正确接线的转接线保留。焊点到外壳夹线区留缓弯，拉力由壳体夹线承受。见[四线接法](../../../enclosure/charger-inline/POWER_WIRING.md)。

## 制造与试装

正反面图由本轮实际回读生成，用于查看位置、焊盘和丝印，不显示走线；完整铜层见原生工程和Gerber。

本轮保存、重新打开并读回后，原生DRC为零项；J9为1=GND、2=NC、3=5V，其他50个器件的焊盘网络保持。额外检查了同面元件包络，全板无重叠。附加几何检查的提示另记在摘要中，不与原生DRC混为一项结论。

首板先试装八个实际PA插头、SuperMini、直头USB线及103450线束，再验证供电和八路采样。插头包胶尺寸、开关手感、卡扣松紧与电池封边需要实物确认。旧居中开关V2.2及其外壳不再作为当前制造入口，已有板请按实物选壳。
