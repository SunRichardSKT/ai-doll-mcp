# C3八路板载锁扣插座 P01（布局候选）

在独立工程`AI_Doll_C3_Socket_20261105`上修改，不覆盖原C3工程。保持ESP32-C3、74HC4051、八路电阻/电容参数、J9供电和固件引脚；本轮没有烧录、修改采样阈值或清理用户历史。

## 插座选择

采用 **JST PA 2.0 mm、2P、通孔侧插、带锁扣** 的S02B-PASK-2(LF)(SN)，本次嘉立创系统库对应C265094。通孔焊脚便于手焊和承受插拔，锁扣比普通摩擦配合更适合娃娃内部线束。

配套线端使用PA系列PAP-02V-S及其适配端子，可优先采购已压好端子的线束。原有SM2.54线不能直接插入；保留线长时，可在传感器端继续使用SM，靠主板端改PA线束或做短转接线。FSR本体不分正负，但其他传感器不能依导线颜色猜接法。

来源：[JST PA系列](https://www.jst-mfg.com/product/index.php?lang=2&series=189)、[原厂尺寸手册](https://www.jst-mfg.com/product/pdf/eng/ePA-F.pdf)。实际库身份、两脚和封装已通过本轮编辑器读回，不按搜索第一项猜封装。

## 布局变化

- 保留34.29 × 44.45 mm、两层板。左右各四座，中心间距8 mm，插入口朝外，部分塑壳伸出板边；焊盘均在板内。
- J1～J8仍对应CH0～CH7；**1脚=各路EXC激励，2脚=各路CH信号**，没有改成一脚GND。每路原电气关系保持。
- 移除旧带线方案的四个线束固定孔及相应局部禁区，保留天线双面禁铜和背面禁器件区。
- C12移到底面靠近原供电脚，C11、R18及几个测试点让开新插座；器件参数、测试点网络和所有焊盘网名保持。
- 通道、位号和测试点丝印重新排齐；底面可见文字已统一设置底面镜像。
- J9仍为1脚GND、2脚PWR5V_RAW；沿用外部5V，充电/升压不集成在主板上。

配套[卡扣堆叠壳](../../../enclosure/c3-socket-stacked/README.md)为42.89 × 56.45 × 33.5 mm，包含103450电池空间、开关低位指拨口、指示灯窗、八个插拔窗口与后端J9出线口。
