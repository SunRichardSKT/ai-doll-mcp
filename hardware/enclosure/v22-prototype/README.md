# V2.2 外壳首版 · P01

配合当前 V2.2 紧凑布线 PCB 的**试装候选**。日常使用 J9 电源线，USB、BOOT / RST 开盖维护。没有修改 PCB、元件、电气参数或既有制造文件。

## 结构与尺寸

- 外形 **46.29 × 56.45 × 20.4 mm**，圆角半径 4 mm，壁厚、底厚、盖厚均为 1.8 mm。只是首版尺寸，尚未实物试装。
- 主板按 **34.29 × 44.45 mm** 安排，板厚暂按 1.6 mm。底面元件空间预留 4 mm，PCB 顶面到盖内壁约 11.2 mm。
- 四处板边托座承托，接触板边约 0.6 mm；上盖限位与 PCB 顶面保留 0.25 mm。没有在 PCB 上新打孔，也不借用原有线束固定孔锁螺钉。
- 4 个壳体螺钉位位于 PCB 外侧。首版按 **M2 × 8 mm 螺钉**预留，塑料导孔 1.7 mm、盖孔 2.3 mm、头部凹位直径 4 mm。须用实际螺钉与打印材料验证，不能强行拧入不匹配的螺钉；首版没有热熔螺母结构。
- J1～J4 左出线、J5～J8 右出线，各槽名义宽 4.4 mm。前端独立 J9 出线槽名义宽 6 mm。槽口从上方敞开，已焊线束可直接放入，上盖挡片补齐上部开口；不需要把线束末端 SM 塑壳穿入。
- 上盖在 SW1 上方有 11.5 × 7 mm 检修开口；开关拨杆高度和手指可达性尚未测量。必要时开盖操作，不使用不明高度的顶杆去压元件。
- 天线一端不设金属螺钉或金属装饰。外壳保留非金属空间，但没有把这一点当作 Wi-Fi 性能已验证。

USB 插座在主板内部，而非主板边沿，因此本版没有伪造“侧壁直插 USB 孔”。卸下上盖后，从上方插拔 USB，维护时仍需检查插头外形、线缆弯折和周边元件净空。当前模型未包含精确 USB 插头或插入扫掠体，不代表所有线材均已适配。

## 先打印什么

1. 先打印 `fit_tray.stl`，放入**断电的已焊主板**，核对四处托座没有顶到电阻、电容、焊点或底面芯片，主板能自然落位。
2. 测量实际板厚、SuperMini 叠高、最高焊点、线束外径与 SW1 拨杆位置。若与参数假设不同，先调整参数再生成。
3. 打印底盒与上盖。建议先用普通非导电 PETG 做样件，0.2 mm 层高、至少 3 道外壁；具体温度按耗材要求。底盒开口向上，上盖外表面向下，STL 已按此放置。不要启用自动缩放；切片时核对 mm 尺寸。
4. 将线束先穿入预留槽，再按实际板上固定孔条件做应力释放。壳体槽和上盖挡片只负责导向，**不是已验证的防拉夹具**；别把外部拉力传到焊点。SM 连接端留在壳外。
5. 合盖前检查导线没有压在挡片、限位柱或螺钉下。试拧螺钉，遇阻停止。必要时针对实际打印机修正导孔和配合间隙。
6. 首次上电分别验证供电、开关、真实 CH0 采样、Wi-Fi 与温升；其余通道仅在实际接入时验收。新外壳未通过这轮实测。

本版不含电池、充电或保护电路，也没有防水、防尘或阻燃等级承诺。用于玩偶内部时，还需按实际装配验证固定方式、温升、线材磨损和拉力。

## 模型检查能证明什么

构建脚本检查两个壳体 BRep 是否有效且各为一个实体，检查导出的 STL 是否封闭、法向一致，并检查底盒与上盖、壳体与 PCB / 元件参考包络的实体相交。检查结果以 `output/audit.json` 为准，失败不会被写成通过。

其中元件 XY 为原生二维包络，Z 向采用预留假设：底面 2.8 mm、SuperMini 高出主板 6 mm、开关 4.5 mm、其他顶面件 2.6 mm。它们不是制造商精确 3D 模型，不能证明实物装配完成。参考板的四个线束孔使用名义圆形表达，不作为 PCB 制造文件，也不用于壳体定位。

原生 PCB DRC 已通过，外壳仍是独立机械候选；SuperMini 手焊焊盘适配、模块底面净空和新板实物均待定版，不能因此直接批量生产。

## 重新生成

在独立 Python 环境中安装 [requirements-cad.txt](requirements-cad.txt)，运行：

```text
python build_enclosure.py
python render_preview.py
```

生成器只写本目录的 `output/`，不会连接或修改 EDA。`pcb_reference.json` 是本次原生读取后提取的机械参考，带源哈希；板框或元件位置改变时须重新提取，不能继续套用旧位置。

模块平面外形参考 [NoLogo 官方资料](https://www.nologo.tech/product/esp32/esp32c3/esp32c3supermini/esp32C3SuperMini.html)；该资料没有给出本项目实物的完整叠高。PCB 来源见 [V2.2 布线候选](../../rev-v2/candidates/pcb-v22-routed-20261017/README.md)。
