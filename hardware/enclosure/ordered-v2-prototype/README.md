# 已制板旧版外壳 · P03 电池与卡扣版

适配已制作、焊接的双排通孔 SuperMini 旧板 `ordered-gerber-20260920`，板框 **34.29 × 44.45 mm**。用户确认排针／排母架高安装，主板上表面至 USB 金属壳最高处约 **8 mm**。P03 增加独立 103450 电池仓、可释放卡扣上盖和指示灯观察窗，保留原板与已焊线材。

只需打印 **底盒与上盖两件**。没有螺钉、螺柱或必需的第三个电池架；`fit_tray.stl` 只是可选省料试装件。当前为 **2026-10-20 打印候选，尚未实物试装**。

电池仓和主板区域在平面上分开，电池不位于排针与焊点下方，卡扣也不伸入电池保留空间。盖子不压紧电芯。电池参考体底面保留 0.4 mm 软垫位置；可用可拆提拉带及少量柔软侧垫限制晃动，不能用硬物挤压电池。电池封边、保护板、鼓包余量和实际连接器必须在打印前按实物确认。

图片中的电池从短边出线，放置时让引线朝 +X。新增的 7.2 mm 端部空间用于让引线自然转向电池上方，再松弯至顶部敞开的隔板槽及插头区。不能把线夹在电池端面与壳壁之间，也不能在电池封边处急折；线材避开盖沿定位唇、扣脚弯曲行程和 PCB 焊点。实际线弯半径尚待实物确认。

**此修改只设计电池容纳空间。** 图片电池是单节 3.7 V、充满 4.2 V；现有 J9 的 5 V 输入仍需合适的充电／保护／升压方案。该外壳未包含电源管理电路，也未宣称电池可以直接接 J9。

## 原板与接口

位置来源为 [原下单 Gerber 核对](https://github.com/SunRichardSKT/ai-doll-mcp/blob/main/hardware/rev-v2/ordered-gerber-20260920/已下单PCB封装核对.md)，未改 PCB、布线或电气参数。

- J1～J4 左侧、J5～J8 右侧，沿原坐标布置八个 4.4 mm 敞口线槽；带线 SM 接头留在外壳外，焊好线后也可从顶部落入。
- J9 保留右侧靠上的 6 mm 出线口；SW1 保留 11.5 × 7 mm 上盖检修口。
- SuperMini USB、BOOT／RST 均开盖维护；保留约 8 mm 架高空间。
- 原板无固定孔，采用空闲板边托座、侧止挡与盖内限位，不在原板上钻孔。右前端止挡移到前边中段，避开 PH2.0 空间。
- 五组扎带通道留在壳体底面、PCB 外侧，供四组传感线和 J9 使用；拉力与线径需实测。
- 模块总叠高采用用户约 8 mm 测量；模型中排座 3.2、模块板 1.6、USB 3.2 mm 仅作示意拆分。其他焊脚、板厚和器件高度仍是公开假设。

观察窗依据 NoLogo SuperMini 外观和模块朝向保留宽范围；LED 精确坐标未获厂家尺寸证据，参数 `led_window` 可单独平移。首次装配需确认实际灯在可视范围，可从外侧贴透明薄片防异物，不能把薄片或胶伸入元件。窗口不具防水等级。

## 打印与装配

1. 可选先打印 `fit_tray.stl`；断电放板，确认托座只接触空闲板边，焊点及针脚不顶底。
2. 建议非导电 PETG、0.2 mm 层高、至少 3 道外壁。底盒开口朝上；上盖外表面朝下，卡扣向上。STL 已按该方向放置，不缩放。卡扣悬臂留弹性，根部与扣钩处不要残留支撑。
3. 先在空盒上试扣。对齐盖沿，均匀轻压，确认四个扣钩进入侧窗；若需要大力或发白，停止并调整配合间隙。PLA 脆性较高，不作为反复拆装默认材料。
4. 拆盖时通过侧窗向内按一对卡扣、轻抬该端，再释放另一对；可使用塑料拨片，操作区域远离 PCB。不要同时强拉四扣，也不要用金属工具顶住主板。
5. 断电整理扎带、主板和线束；电池在独立仓中放置软垫及提拉带，PH2.0 接头与线弯放在隔板后方预留区。过线从隔板顶槽放入，不挤电池封边、不使插头卡入焊点区域。
6. 合盖检查限位肋、扣脚、线槽挡片不挤线。USB、BOOT／RST 开盖操作；SW1、观察窗、电池尺寸按实物核对。
7. 实装后验证已接 CH0、Wi-Fi、供电、温升、线束拉力和多次卡扣拆装。原电路测试通过不代替装壳后测试。

## 实际检查与边界

当前生成脚本已验证：底盒、上盖各为有效单一实体；STL 水密、法向一致且各只有一个连通体；STEP 回读有效且体积一致；底盒与上盖、壳体与原板／元件／电池参考均为零体积干涉。完整 **52×36×12** 电池保留体、**12×8×10** 插头保留体和 **5×14×12** 出线转弯保留体对底盒和上盖也均零干涉。

还检查了四个卡扣内收 0.5 mm 的保守刚体包络，对 PCB、模块、电池、插头和底盒均零干涉；内收后向上每 1 mm 采样至 13 mm，未发现与底盒干涉。该检查不是连续运动、弹性应力或装配力仿真。材料疲劳、扣合声、拆装次数、插入全过程、LED 可视性、电池实物适配及跌落仍需打印后验收。

## 参数化重建

在独立 Python 环境安装 [requirements-cad.txt](requirements-cad.txt)，执行：

```text
python build_enclosure.py
python render_preview.py
```

`module_height_above_main_pcb` 调整模块叠高；`battery`／`battery_reserved`／`connector_allowance` 分别声明参考电池、净空和接头；`led_window` 调整观察口，`snap_*` 调整卡扣。修改后应重新生成、检查并更新预览和 SHA256 清单。不要整体压缩 STL 高度，因为这会改变壁厚和卡扣尺寸。

生成器仅写本目录 `output/`，不连接 EDA，也不改变设备配置。
