**适用于已经制作、焊接的双排通孔 SuperMini 旧板**，对应 `ordered-gerber-20260920`。不是 V2.2 紧凑贴片板的外壳。

用户已确认模块采用**排针／排母架高安装**，并量得主板上表面至 USB 金属壳最高处约 **0.8 cm（8 mm）**。平面位置按实际下单文件核对，P02 总高缩减为 **20.8 mm**，顶部另留 2.6 mm；仍是待实物试装的打印候选。

## 与实物一致的部分

来源是 [原下单 Gerber](../../rev-v2/ordered-gerber-20260920/已下单PCB封装核对.md)：板框中心线 **34.29 × 44.45 mm，直角矩形**。原生标准化工程的 51 个器件中心、角度和装配面已与下单飞针文件逐项核对一致，没有套用 V2.2 的移动后位置。

| 部件 | 原板位置与外壳处理 |
| --- | --- |
| J1～J4 | 左侧，按各自实际 Y 坐标布置 4 个出线槽 |
| J5～J8 | 右侧，按各自实际 Y 坐标布置 4 个出线槽 |
| J9 | 右侧靠上，Y=34.29 mm，独立 6 mm 电源线出口 |
| SW1 | 右上角，上盖对应位置设 11.5 × 7 mm 检修口；可达性需试装 |
| U1 | 原双排通孔位置，排距 15.24 mm；模块偏向板的左上区域，USB 开盖维护 |
| 主板固定 | 原板没有固定孔；使用边缘托座、侧限位及上盖限位，不在已制作主板上钻孔 |
| 线束固定 | 5 组扎带穿槽位于外壳底面、PCB 外侧；4 组用于传感器线束，1 组用于 J9 |

八路线槽名义宽 4.4 mm，从上方敞开，线束可直接放入；上盖挡片补齐上方槽口。线束末端的 SM 接头留在外壳外，无须穿过小孔。扎带穿槽约 1.3 × 2.5 mm，需使用实际扎带检查间隙，不能直接宣称拉力验收通过。

## 当前候选尺寸

- 外形 **46.29 × 56.45 × 20.8 mm**，比 P01 的高度减少 10 mm，长宽按原板安排。
- 底板、壳壁和上盖均为 1.8 mm；外圆角 R4 mm。
- PCB 底面空间预留 5 mm，板厚暂按 1.6 mm，主板上表面 Z=8.4 mm。
- 模块总叠高采用用户测得的约 **8 mm**。参考模型内部拆分为 3.2 mm 排座、1.6 mm 模块板和 3.2 mm USB 壳体，仅为示意，不能把拆分值当作实测。按钮与天线同样非精确供应商模型。
- 盖内壁 Z=19 mm，主板顶面以上容纳约 10.6 mm；相对用户约 8 mm 的最高点留 2.6 mm 余量。首次合盖仍需确认真实最高部件与导线不被顶压。
- 底面针脚参考：U1 露出 3.5 mm，SW1、已接 J1 与 J9 露出 2.5 mm，均为假设。其余未接通道没有伪造为已经焊好线材。
- 四个壳体螺钉柱位于主板外侧。参考紧固为 4 颗 M2×8 mm，导孔 1.7 mm、盖孔 2.3 mm、头部凹位直径 4 mm；按实际塑料与螺钉试配，不含热熔螺母。
- 天线端不放置螺钉或金属装饰；Wi-Fi 与温升仍需装壳后验证。

## 高度依据与调整

2026-10-17 用户报告**主板上表面到 USB 金属壳最高处约 0.8 cm**，换算为 8 mm，已保存为近似测量，未假定为精密尺寸。只需调整 `module_height_above_main_pcb`，壳高由板厚、底部空间和顶部余量自动计算；若其他部件更高，以实际最高点为准。

若测量值小于当前预留，可缩减外壳厚度；若更高，必须增高并重新检查。不能直接改 STL 的 Z 缩放来压低外壳，因为这会同时改变壁厚、螺钉孔和出线槽。

## 试装顺序

1. 先打印 `fit_tray.stl`，板子断电放入。检查四个托座只碰空闲板边，原板无须剪切、打孔或拆焊；底面芯片、排针尾与焊点均不能顶到托盘。
2. 用户已提供约 8 mm 架高后的最大高度，底盒和上盖按此生成；试装确认没有更高部件。首版可用普通非导电 PETG、0.2 mm 层高和至少 3 道外壁；具体打印参数按设备、耗材调整。
3. 按 STL 的 mm 单位导入，不自动缩放。底盒开口朝上，上盖外表面朝下，文件已按打印方向放置。
4. 先将扎带穿过壳体穿槽，再落入主板和线束，整理好 SM 接头。扎带头及导线避开板边、盖限位、螺钉和针脚，不将外部拉力直接传到焊点。
5. 合盖检查挡片和限位肋没有挤线，螺钉不强拧。USB、BOOT/RST 均开盖操作；SW1 上方检修口先验证手指或合适工具的可达性，必要时开盖。
6. 装壳后分别确认供电、开关、已接 CH0 真实采样、Wi-Fi、温升与线束拉力。原板电路此前的成功测试不代替装壳测试。

本版没有电池仓、防水等级或防拉等级承诺。不修改原下单 Gerber，也不要求重做 PCB；当前原板仍按用户已有硬件使用。

## 检查范围与生成

`output/audit.json` 记录两个壳体实体的有效性、单实体、STL 封闭性和法向一致性，以及壳体与主板／元件参考的相交检查。原板 XY 有下单文件支持，模块总叠高采用用户近似测量；其他高度、线径、插头和打印配合仍需试装。模型检查不等于实物已装配通过。

独立 Python 环境安装 [requirements-cad.txt](requirements-cad.txt)，运行：

```text
python build_enclosure.py
python render_preview.py
```

生成器只写本目录 `output/`，不连接或修改 EDA。`pcb_reference.json` 内保存原板来源哈希与引脚坐标；不得换成 V2.2 的数据后继续沿用“已制板”名称。
