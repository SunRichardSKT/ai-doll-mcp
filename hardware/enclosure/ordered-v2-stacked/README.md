# 已制板外壳 · P02 上下堆叠版

为已经焊接、通过排针／排母安装 SuperMini 的通孔主板增加 **103450 下置电池仓**。保持最初无电池壳的 **46.29 × 56.45 mm** 长宽，总高 **35.2 mm**。当前通孔主板采用这一堆叠结构，紧凑贴片主板另用平铺外壳。

2026-10-29根据实物反馈调整：**开关更好拨、上盖扣合更紧**。外形、电池仓和主板位置不变，P01底壳及绝缘托板可继续使用，先只重打[新上盖](output/lid.stl)即可。

开关入口向前侧展开，避开后方卡扣和SuperMini，不给拨杆加延长件。仍按**针脚最底端至开关顶约15 mm、底针约5 mm**设计；打印配合受材料和机器影响，建议先空壳试扣。

## 为什么这版有三件

下层放电池，上层放主板，中间必须隔开约5 mm的金属针脚。**1.4 mm绝缘托板是实际保护件**，不能省略。它可以单独取出，让底壳、托板和上盖分别平放打印，避免在封闭电池仓内打印难拆的支撑。

托板同时带有板边托座，作为可整组取出的主板载架；载架坐在底壳侧轨上，将载荷传到侧壁，不以压紧电池的方式固定。这样先取出载架就能从上方放入电池，不会被固定板托挡住。上盖小限位脚与托板之间留0.25 mm。托板上方距针脚最低处1 mm；电池参考上表面距托板下表面1.6 mm。托板只在PCB以外的线材出口开槽，针脚区下方保留连续隔离。

电池长边沿壳长方向，名义尺寸 **34×50×10 mm**，完整保留体 **36×52×12 mm**。这版用厚度换长宽，不能保留加长版的7.2 mm水平出线余量。电池短边出线朝后端，上弯经托板12 mm开口进入PCB外侧竖向通道；末端到内壁约 **1.85 mm**，向上空间额外开放。线不能强折在包膜封边，原厂引线能否自然转向必须试装；若实物出线结构更长，应调整电池净尺寸或增加长度，不能硬压塞入。

PH2.0接头的 **12×8×10 mm** 保留区位于主板前方空闲上空，避开模块和开关。不是把接头塞到电池侧缝中。约80 mm引线需沿侧边向上整理，实装确认弯曲、余长和焊点净空。

## 开关与维护

右上角电源开关使用下沉拨动凹槽。P02底面降低到距壳底28.8 mm，按原测量拨杆高出局部底面2.4 mm；上方改为15.4×12.4 mm斜面入口。底部10.4×5.8 mm开孔仍包住原开关位置，拨杆不伸出整壳顶面。后侧卡扣保留完整根部，底面和入口的扩大不改变元件位置。

14×12 mm窗口观察SuperMini指示灯。USB、BOOT、RST开盖维护。八路传感器仍用上敞口线槽，带线SM塑壳留壳外。J9右侧出线。四个释放卡扣改在前后墙，避开密集的侧线槽；传感线位置跟随原板XY，未改变PCB。

## 打印和组装

1. 使用非导电PETG，0.2 mm层高、至少3道外壁。三件STL均已归零并排好打印方向。底壳开口向上，托板平放，上盖外表面朝下。检查凹槽桥接和长限位脚，必要时仅局部增加可拆支撑，卡扣活动缝不得粘连。
2. 已有P01底壳时只打印P02上盖，比例100%，不要修改水平膨胀补偿来加紧。先空壳逐端试扣，不放电池；如局部发涩先清理象脚和毛边。通过前后释放窗用塑料拨片向内按扣、逐端抬盖。
3. 断电放入实际电池，加可拆提拉带；软垫只能轻限位，不能增加到压紧电芯的程度。原厂出线朝后端自然上弯。
4. 放绝缘托板，线从后端开口穿出。托板必须平稳坐在侧轨上，不顶封边，不允许针脚穿过托板或贴住电芯。
5. 放主板到托板载架的四个板边托座。按实际针脚检查1 mm间隙；不用力把板压低。整理接头到前方保留区，远离开关、天线和卡扣。
6. 合盖，检查开关拨动、LED可见、传感线不被压夹。若卡扣发白或需要大力，先调整参数，不强扣。
7. 真实测试已接通道、Wi-Fi、温升、线束拉力及重复拆装。电池在天线下方可能影响射频，电脑几何检查不能证明无线性能。

## 供电边界

本候选只做机械仓位。现有J9要求5 V，单节103450为3.7 V，需要匹配的保护、充电、升压与极性确认；没有更改PCB供电电路。外壳没有给未知电源管理板预先设计固定架，实际模块尺寸需要另配。
