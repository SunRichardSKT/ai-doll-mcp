# 充电／升压模块保护壳 P02

[外壳目录](https://github.com/SunRichardSKT/ai-doll-mcp/blob/main/hardware/enclosure/README.md) · [旋转预览](output/preview.html) · [尺寸图](output/drawing.svg) · [四线取电方案](POWER_WIRING.md)

适配本次提供的 Type-C 单节锂电池充电／5V 升压小板。按商品图中的 **16.2 × 12 × 4.4 mm** 包络建模，USB-C 约伸出 PCB 1.3 mm；不是通用 TP4056 大板外壳。

## 打印哪两个文件

| 文件 | 用途 |
| --- | --- |
| [base.stl](output/base.stl) | 底壳、模块托座、下压线槽 |
| [lid.stl](output/lid.stl) | 上盖、四个卡扣、一体上压线块 |
| [assembly_reference.step](output/assembly_reference.step) | CAD 装配参考，含模块示意包络；不要整件打印 |

外形 **长36 × 宽22 × 高11 mm**。只打印底壳、上盖两件，**不需要螺丝、螺母或胶水**。STEP 单件、可调参数和生成脚本同时提供。

- 推荐 PETG，0.4 mm 喷嘴，0.16～0.20 mm 层高，至少3道壁，100%比例打印，关闭自动缩放。
- STL 已摆好打印方向：底壳底面朝下，上盖外表面朝下、卡扣朝上。压线块从上盖连续长出，无悬空横梁；建议先不加支撑，切片预览核对卡扣斜坡。
- PLA 可用于核对尺寸；日常使用优先 PETG。卡扣厚0.7 mm，实际松紧取决于打印机和材料。

## 装配

1. 先断开电池和USB。把模块USB-C朝底壳前孔放入，PCB落在四个边缘托座上。焊点、元件不能顶住底壳，USB插头应能插到底。
2. 把绝缘导线依次放进后端圆槽。焊点到压线区留一点弯曲余量，裸焊点不要放进压线区。
3. 对齐上盖，逐边按下四个卡扣。上盖内侧压线块与底座共同夹住线皮，拉力经外壳传递，减少直接拉扯焊点。
4. 轻拉每根线检查：线不能在槽内滑动、焊点不能跟着受拉；若滑动，先调整线径对应参数，不用暴力扣合或靠拉焊点测试。
5. 需要开盖时，从侧面的卡扣窗口逐个向内轻推卡舌，同时略抬相应一边。可用指甲或塑料薄片，不强撬灯窗。

后端四槽分为两组：**BAT 两线接外置 PH2.0 电池插头，5V两线接外置PA2.0三针插头的1、3脚（新版C3 P03）；旧带线板可保留原SM两线插头**。插头本体留在壳外，不让插头穿过小线孔。每槽按单根线皮外径约1.5 mm设计；出线孔2.0 mm，压线区最小净高约1.4 mm。

## 四线接法

用户补充的卖家标注图已明确给出四个焊点，不需要把主板并接在B+/B-上：

| 模块标注 | 连接到 |
| --- | --- |
| 电池正极 B+ | PH2.0电池正极 |
| 电池负极 B- | PH2.0电池负极 |
| 输入输出正极 | PA3P的3脚 → 新板J9.3（PWR5V_RAW）；旧两针板为J9.2 |
| 输入输出负极 | PA3P的1脚 → J9.1（GND） |

USB-C口留在壳前用于充电。两根取电线沿模块两侧的独立通道向后走，电池线从模块尾端直接进入后部留线区；四根线最终从后端分别夹持引出。侧槽避开卡扣和模块边缘；若两焊点在同一侧，也可在侧槽中上下分层走线。

新版C3 P03为J9.1=GND、J9.2=NC、J9.3=5V；旧两针板仍为J9.1=GND、J9.2=5V。PA与SM不能直接互插，接线前核对板型、孔位及实际极性。B-与输入输出负极不额外短接。图中正负标注比导线颜色优先；PH2.0并不保证不同电池厂家的正负针序一致。

完整示意与检查步骤见[四线取电方案](POWER_WIRING.md)。取电拓扑已根据用户提供的卖家图确定；真实输出、切换掉电、温升和打印件夹持仍需实测，不把“自动切换”当作不间断供电承诺。

## 灯窗与散热

上盖留12 × 7 mm观察口，并留三条通风孔。观察口先做宽窗，以适应照片中灯位尚未实测的情况；没有假定所有同外形模块灯位完全相同。需要防碰时可在窗外贴薄透明片，不覆盖通风孔；本壳不防水。首次通电留意模块及外壳温升。

## 尺寸调整

`parameters.json`中可调整PCB厚度、底部净空、USB孔、灯窗和线径。原图未给出PCB厚度、底面焊点、灯中心和实际线径，当前分别使用1.0 mm板厚、1.1 mm底部净空与宽灯窗，**先打印一套断电试装**。卡扣疲劳、拉力和实际温升尚需打印件确认。

使用`requirements-cad.txt`中的CAD依赖，运行：

```text
python build_enclosure.py
python render_preview.py
python package.py
```

`capture_preview.cjs`是可选的预览截图检查，需Node.js、Playwright与Edge；不影响生成和使用STL。`output/audit.json`记录实体、网格、STEP回读和参考包络净空检查。
