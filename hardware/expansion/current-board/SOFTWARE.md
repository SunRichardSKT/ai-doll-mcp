# 现板固件：压力与开关

[设计总览](README.md) · [当前功能、升级和空间](../../../docs/reports/FIRMWARE_INPUTS.md)

0.1.1固件为 `pressure-switch-v1`，网络修订2，公开23项设备工具。应用1,198,848字节，OTA余111,872字节，静态DRAM73,300字节。更新需自行升级设备固件。

保留八路压力、GPIO1独立压力、GPIO21干接点、三态部位设置与校准，以及配网、USB、MCP、离线缓存、HTTPS直传和双OTA。

温度、LIS3DH、马达和外接灯已按当前取舍移除。该目录中的接线图和配件设计仅作扩展参考，不代表本固件可驱动；旧扩展配置隔离保留，历史仍可读取。物理输出一直关闭，旧客户端控制命令明确返回不支持。

手机、电脑、服务器的聊天队列和已有历史保留。工具和网页按设备能力使用，不把旧设计说明当成当前驱动支持。
