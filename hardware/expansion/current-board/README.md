# 现板扩展设计：开关居中靠下的内测板

适用对象：SuperMini贴片安装、SW1在底部居中的34.29 × 44.45mm现板。沿用原八路FSR电路，通过现有模块焊盘引线扩展；不切主板走线、不更换主控、不改变历史分区。

本目录保留接线设计与配件参考，不是可下单Gerber。0.1.1固件采用`pressure-switch-v1`，仅支持压力与干接点；温度、动作及马达/外接灯设计不再属于当前驱动能力。下一代主板另行设计，避免与历史V2/V2.2编号混淆。

## 功能范围

| 功能 | 现板扩展做法 | 当前软件状态 |
| --- | --- | --- |
| 八路触摸 | J1～J8继续接FSR | 已有真实采样、校准、历史和Operit触摸回复 |
| 温度 | GPIO1接1～2只DS18B20，共用数据线 | 候选已接入驱动、历史和可选温度变化回复 |
| 姿态变化 | GPIO6/7接LIS3DH三轴加速度小板 | 候选已接入驱动、朝向/摇晃事件和聊天队列 |
| 振动 | GPIO10经MOSFET控制一只ERM马达 | 保留显式PWM输出；安装与供电待实测 |
| 灯效 | GPIO20接低电流单色LED及限流电阻 | 候选支持常亮、呼吸、闪烁和停止；不是RGB灯带 |
| 一个开关输入 | GPIO21接按键、干簧管或干接点浮球开关 | 候选已接入去抖、开合事件和可选闭合回复 |
| NTC温度替换 | 占用一个现有FSR口，配置NTC参数 | 已有驱动；替换后该口不再同时接FSR |
| UART调试 | GPIO20/21复用为串口 | 与灯效、开关互斥；不是本方案新增常驻串口功能 |

LIS3DH只提供加速度。本方案定义朝向变化、静止/运动、摇晃候选事件，不承诺完整三维姿态、精确位置或仅凭传感器确认拥抱。单色LED优先控制固件体积；RGB、音频、加热和多马达阵列不纳入现板完整配置。

## 内测用户选配

建议由组装者统一预焊带防呆的转接线并检查，普通内测用户只插配套模块。扩展是选配，不要求已收到基础设备的用户重新换板或自行焊接。

- **基础包**：八路FSR，保持已有使用方式，不要求购买扩展配件。
- **温度包**：增加探头、4.7kΩ上拉和独立逻辑供电；使用固件已有温度读取。
- **温度＋振动包**：再增加马达、匹配电源和驱动电路；软件输出默认关闭。
- **完整包**：在前述基础上增加LIS3DH、单色灯和一个开关；配合同批扩展候选固件和软件，逐项验收后启用。

前面的6P扩展口讨论是草案。本设计统一采用下述8线功能分配，不把该线序称为已经存在的板载接口；原主板没有这只8P插座，需要由装配者引线到带防呆的转接线束。

## 明确保留的条件

1. GPIO0、3、4、5、8、9及J1～J8保持原用途；C9仍是原设计的1nF滤波电容，维修时临时拆下不等于正式设计取消它。
2. 不把FSR两线口当作5V/GND电源口或数字总线。所有传感器模块与马达均按自己的电源和信号要求接线。
3. 不从SuperMini的3V3稳压器给马达供电；扩展板从开关后的SYS5V取电并自行稳压。
4. 现有103450电池下置外壳未预留本扩展的体积。先采用独立绝缘小盒或娃娃内部独立固定，不能挤进电池仓，也不覆盖天线。
5. 扩展候选程序文件1,252,640字节，单OTA应用槽1,310,720字节，余58,080字节。已编译核对，不通过缩减历史、取消OTA或清空校准来强行容纳功能。

## 给内测用户的说明

现有内测板继续维护，扩展方向为温度感知、振动反馈，以及后续的姿态变化、灯效和开关互动。基础八路触摸保留，新增配件按需选择。配套扩展软件已在本地接入，新增模块仍需逐项完成实物检查，不把这份接线设计当作已经发布的功能升级。下一代主板另行开发，不以换板作为继续使用现有设备的前提。
