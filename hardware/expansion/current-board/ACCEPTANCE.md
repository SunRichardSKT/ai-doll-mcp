# 现板扩展的安装与验收

[设计总览](README.md) · [接线](WIRING.md) · [软件边界](SOFTWARE.md)

## 安装顺序

1. 确认是开关底部居中的现板，记录当前设备身份、八路状态和校准。先完成原八路按压复测，再接扩展。
2. 所有电源断开后焊接线束。检查8P线序、模块电源和公共地，确认电源对地没有持续近零电阻；电容充电的瞬时变化不单独算短路。
3. 不接马达，只接转接电源，核对3V3_LOGIC和3V3_MOTOR。两路输出不接回SuperMini的3V3。
4. 接一只温度探头，暂停真实输入后扫描地址，再恢复原输入状态；检查断线和重新连接。
5. 安装马达和驱动，先明确开启输出许可，做短时低强度测试；确认联网不重启、采样不中断，再增加强度。3V马达不直接接5V。
6. 确认固件能力标识为current-board-expansion-v1后，姿态、灯和开关逐个接入；每加一项都确认原八路仍正常。不要把尚未实现的类型配置成压力来冒充支持。
7. 扩展模块独立绝缘和固定，线束留应力释放，不压电池、不遮挡天线。现有外壳不默认容纳全部模块。

## 验收清单

| 项目 | 通过条件 |
| --- | --- |
| 八路触摸 | 每路按压/释放对应正确，其余路无异常串扰；阈值和校准保留 |
| 温度 | 地址可读，读数合理，断线返回故障而不是0℃ |
| 姿态 | 已知方向放置、缓慢翻转和摇晃可区分；静置不持续触发 |
| 振动 | 强度/时长/停止有效；复位后不重放；温度和压力采样继续 |
| 灯 | 关闭/常亮/呼吸可控，不改变原网络状态灯 |
| 开关 | 闭合/断开各一条有效事件；开机按住不制造额外互动 |
| 反馈循环 | 马达自身振动不反复触发动作回复或再次驱动马达 |
| 思考期间排队 | 首次触发后，模型生成期间的后续输入能按规则合并处理 |
| 断网和重启 | 保留安装配置和历史；恢复连接后旧补传只归档 |
| 资源 | 完整固件未越应用槽；网络并发、输出时无内存分配失败或异常复位 |

## 本轮排障记录的正确解释

用户在一块新板上测得GPIO0对地与表笔短接近似低阻，拆下C9后变为OL。这说明该板的ADC对地短路随C9隔离而解除，尚不能区分C9本体故障和焊锡桥连，也不能代替恢复八路采样验收。

C9原规格为1nF/0805/50V。可临时不装作短时采样排查，正式装配恢复原设计并重新查短路。U2第3脚经R17（1kΩ）到GPIO0；这一路正常约1kΩ，不应要求蜂鸣档必须响。
