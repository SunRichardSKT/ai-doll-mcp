# 无线连接电脑服务

运行链路：独立供电的娃娃 → 局域网 Wi-Fi → 电脑采集服务 → 历史和互动会话 → 用户选择的 AI。无线模式不打开 USB 串口。

## 电源与网络

设备使用稳定的独立电源。可接 5V USB 电源，也可使用板外单节锂电充放电模块的 5V OUT/GND 接主板 J9；拔掉唯一电源会关机。主板不集成充电电路。

ESP32 连接 2.4 GHz Wi-Fi，电脑与设备须互通，避免访客网络或 AP 客户端隔离。配网步骤见 [使用指南](USER_GUIDE.md)。从路由器列表或设备设置页获取私网 IPv4，建议 DHCP 地址保留。

## 首次配对

完成 [安装依赖](AI_INSTALL.md) 后，在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe tools/pair_wifi_device.py --host 192.168.1.50
.\tools\start_companion.ps1 -DeviceHost 192.168.1.50
```

替换设备 IP。MCP 令牌在设备设置页取得，终端隐藏输入。已有配对会复用本机令牌，需要重新输入时加 `--new-token`。验证成功才保存连接，不会在失败时覆盖原配对。

打开 <http://127.0.0.1:8768/companion>，确认连接为 Wi-Fi、设备在线、采集正常。之后可以将 ESP32 移到独立电源，等待重新联网。后续启动用 `.\tools\start_companion.ps1 -Background`，沿用已保存方式。

统一安装入口也可使用 `.\tools\install_bridge.ps1 -DeviceHost 192.168.1.50`。只运行一个采集服务；已有不同连接方式时先关闭本项目服务。配对配置保存在本机 `build/device-lab`，不要分享。

## 切换 USB

先关闭无线采集服务，再运行 `.\tools\start_companion.ps1 -Transport usb -Port COM3`，替换实际串口。历史和人设使用同一数据库。无线断线不会自动回退 USB，也不会自动重发输出命令。

仅配对 MCP 令牌即可采集、配置通道及互动；没有管理员密码时，电脑首页不能代替设备扫描/修改 Wi-Fi，直接打开设备网页操作。无线服务不提供远程复位按钮，重启用 RST。

## 断线与恢复

服务约每 0.7 秒采集，单次网络超时约 4 秒。恢复后按设备和事件标识补传、去重；IP 改变时尝试验证已配对设备的新地址，详见 [无线恢复](WIRELESS_RECOVERY.md)。电脑服务仍需运行以保存长期历史，设备缓存容量见 [离线记录](OFFLINE_RECORDS.md)。

局域网数据链路使用 HTTP，不映射到公网。电脑管理网页只监听 127.0.0.1。真实无线链路已通过模拟事件、历史和会话测试；测试期间串口独占且不传输数据。电池独立供电及真实 FSR 仍需实物验收。
