## 保持的设计约束

沿用用户原 AI、模型、人设和上下文，不新建聊天产品。保持 SuperMini、74HC4051、现有电气参数及手焊封装，主板不集成充电。

端口按用户安装情况保存“关闭／模拟／已接入”，不凭零读数推断插拔；未接硬件不启用真实输入，输出默认关闭。旧日常／手动接口仅作兼容，不作为普通页面入口。Sakura 普通 Chat 添加失败仍保留未解决状态；Secure 的限时模拟反馈不能冒充普通 Chat 空闲唤醒。

每项新增能力分别记录软件测试、真实设备、真实宿主和模型结果，公开包不带个人配置。接口扩展见 [开发指南](DEVELOPER_GUIDE.md)。
