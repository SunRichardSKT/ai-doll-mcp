# 后续开发计划

> 当前版本：[内测0.1.1版](../../CHANGELOG.md) · [教程目录](../README.md)

| 优先级 | 方向 | 下一步 |
| --- | --- | --- |
| 1 | 手机日常稳定性 | 收集不同安卓机型的后台、省电与网络恢复反馈 |
| 2 | 免电脑体验 | 完善热点切网、二维码图片读取和首次配对的实机体验 |
| 3 | 硬件装配 | 试装P02上盖，确认开关可达性、卡扣手感和重复拆装 |
| 4 | 新紧凑板 | 校核SuperMini邮票孔手焊焊盘、模块底部和USB净空，再做制造确认 |
| 5 | 更多宿主 | 依据宿主实际事件能力扩展主动回应，保持同一聊天队列和回执 |

现板支持优先参考[开关居中靠下的内测板扩展设计](../../hardware/expansion/current-board/README.md)：先交付接线与配件方案，温度和PWM振动复用现有驱动；姿态、灯、开关及跨类型反馈按[软件清单](../../hardware/expansion/current-board/SOFTWARE.md)实施。下一代主板另行设计，不把现板扩展接线变成要求所有内测用户换板。

现板设计包及软件候选已在本地完成：LIS3DH、单色灯、干接点，类型化历史、可选温度/动作/开关回复和原聊天排队。新增硬件默认关闭，扩展回复默认只记录。下一步按安装清单接入真实模块并核对供电与目标手机，再决定发布；自动触摸短振等规则不默认开启。

已工作的采集、排队、历史和配对流程继续维护；新增能力按实际设备与宿主分别验收。当前记录见[检查汇总](../reports/VALIDATION.md)。
