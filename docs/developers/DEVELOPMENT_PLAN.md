## 第一代维护：全部ESP32-C3方案

已制带线板、居中开关修订、PA2.0插座板以及SuperMini手焊焊盘改进都归第一代。当前任务是维护现有用户的配网、后台任务、记录、客户端接入和装配体验，不把PCB的V2／V2.2名称当作第二代产品。

| 方向 | 接下来做什么 |
| --- | --- |
| 日常连接 | 继续收集安卓后台、省电、网络恢复和首次配网反馈 |
| 制作与装配 | 核对各批次板型、手焊焊盘、Type-C净空、卡扣与PA2.0插接 |
| 当前输入 | 维护压力、NTC、湿润片和干接点；早期动作／马达／外接灯接线保留为参考，按固件能力使用 |
| 软件接入 | 维护MCP客户端、Operit、历史、部位组合与原聊天队列；区分查询与宿主主动触发能力 |

资料从[第一代总览](../../hardware/gen1/README.md)开始。

## 第二代研发：ESP32-S3开发板路线

当前处于需求调查与方案预研。22题调查模板和早期发布记录已有保存；具体S3模组、模块接口、原理图、PCB、专用固件和外壳仍待完成。

按“需求收敛 → 确认开发板与资源 → 定模块接口 → 开发板原型 → PCB与外壳”推进，摄像头放后续。完整分项进度及已有调查材料见[第二代研发进度](../../hardware/gen2/README.md)。
