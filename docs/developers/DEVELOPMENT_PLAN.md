## 优先顺序

| 优先级 | 工作 | 通过条件 |
| --- | --- | --- |
| 1 | 完成已组装主板的剩余传感器验收 | CH0 基础按压/释放已通过；逐路校准、其余七路、独立供电分别验证 |
| 2 | 在用户真实环境完成首次安装 | 全新电脑 / 网络实际配对，原 Chat 返回新工具结果并完成模拟互动 |
| 3 | 真公网接收服务 | DNS、安全组、可信 ACME、设备上传与断线恢复实际通过 |
| 4 | 自定义人设与真实模型 | 原聊天上下文保持，用户反馈偏好实际生效，结束 / 去重正确 |
| 5 | 支持宿主的后台事件 | 实际订阅、签名回调、原窗口自动回应和取消；普通 Chat 单独确认支持范围 |
| 6 | 温度和电机 | 实物 NTC / DS18B20 精度与总线，板外驱动 / 电源 / 超时停止 |
| 7 | 宿主和稳定地址 | Operit、OpenClaw、Claude、固定 Cloudflare 按用户实际账号分别验收 |
| 8 | 故障与长期使用 | 写 Flash / OTA 时物理断电、电池续航、长期采样与数据维护 |

## 保持的设计约束

沿用用户原 AI、模型、人设和上下文，不新建聊天产品。保持 SuperMini、74HC4051、现有电气参数及手焊封装，主板不集成充电。

未接硬件时模拟 / 手动，输出关闭；日常模式仅恢复已确认输入。Sakura 普通 Chat 添加失败仍保留未解决状态；Secure 的限时模拟反馈不能冒充普通 Chat 空闲唤醒。

每项新增能力分别记录软件测试、真实设备、真实宿主和模型结果，公开包不带个人配置。接口扩展见 [开发指南](DEVELOPER_GUIDE.md)。
