# 项目结构与文件规则

> [教程目录](../README.md) · [开发与打包](DEVELOPER_GUIDE.md)

| 位置 | 当前用途 |
| --- | --- |
| 三个根目录CMD | 管理、服务器、烧录入口 |
| `src/ai_doll/core/` | 共享策略、版本、历史与互动上下文 |
| `clients/operit/` | 当前手机工具包和设置页 |
| `firmware/src/` | ESP32固件、设备网页与协议 |
| `firmware/prebuilt/` | 当前四个镜像及清单 |
| `tools/` | 当前服务、构建、维护和对应测试 |
| `docs/` | 当前使用说明、开发资料与AI指南 |
| `hardware/` | 在用主板、研发中的紧凑板、采购资料及各自当前外壳 |
| `deploy/`、`templates/` | 部署文件和公共连接模板 |
| `python/` | 源码只保留运行环境说明和元数据，完整环境在Release |
| `delivery/` | 当前下载入口及校验清单 |

仓库只展示当前版本。废弃Operit独立原型、早期布局草案和历史发布说明已移除；Git提交历史保留。制造Gerber、BOM、当前DRC和供应商资料仍用于在用硬件，不作为软件版本残留删除。

`build/`保存个人配置、配对、数据库、日志与本机检查记录；`outputs/`保存本机图文素材；`.tools/`、`.venv/`和`.pio/`属于开发环境。以上内容不进入Git或公共包，不清理用户数据来完成版本重命名。

网页`*_asset.h`从源文件生成，不提交。完整安装包、PCB包和外壳包放在Releases，通过明确文件清单、SHA-256、文档链接和密钥排除检查后发布。
