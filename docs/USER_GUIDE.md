# 共感娃娃使用指南

当前固件 2.7.0，电脑 Bridge 2.12.3。首次电脑安装见 [安装指南](AI_INSTALL.md)，日常操作按下面流程。

本机 MCP 客户端可直接使用局域网采集，不需要公网隧道。当前 Work 已实测；普通 Chat 的本机插件路径尚未接通，见 [聊天连接范围](CHAT_MCP.md)。提供给云端 AI 的事件仍会随对话发送给该平台，不能称为完全离线。

如果提示“设备连接正忙”，本次操作没有发送，稍后由用户决定重试。程序不会在恢复连接后补发这个控制命令。历史查询仍可显示已归档记录，同时提示设备尚未刷新；这不表示刚刚发生了新互动。

## 首次配网

1. 给 ESP32 接通电源。没有 Wi-Fi 配置时，灯快闪，出现无密码热点 `AI-Doll-xxxxxx`。
2. 手机或电脑连接该热点。系统可能弹出配网页；没有弹出时访问 <http://192.168.4.1/>。
3. 扫描 Wi-Fi，选择 2.4 GHz 网络，输入密码并保存。记下管理密码。
4. 连接成功后灯常亮，设置热点关闭。手机和电脑切回家庭 Wi-Fi，在路由器列表或电脑连接页取得设备 IP。
5. 打开设备 IP 的网页；联网后的管理账号为 admin，使用设备生成的管理密码。可设置通道、MCP、模拟测试并查看最近日志。

已有 Wi-Fi 配置时，上电后最多尝试连接 60 秒，期间慢闪；未连接成功则打开设置热点并快闪。运行中长按 **BOOT 约 3 秒**随时重新进入配网。**RST** 仅重启，保留网络和通道配置；不要按住 BOOT 上电或复位，以免进入芯片下载模式。

| 灯 | 状态 |
|---|---|
| 快闪 | 设置热点已打开 |
| 慢闪 | 尝试连接 Wi-Fi |
| 常亮 | 已联网 |

通过 MCP 测试灯会临时覆盖网络指示 3 秒。

## 每天使用

设备独立供电，电脑和娃娃连接可互通的局域网。启动 `.\tools\start_companion.ps1 -Background`，打开 <http://127.0.0.1:8768/companion>。长期历史由电脑保存，因此电脑服务需运行。设备断线时有有限缓存，恢复后补传；详见 [离线记录](OFFLINE_RECORDS.md)。

通道类型、部位和参数保存在设备；人设、偏好和长期历史保存在电脑。普通模式中触摸安静记录，用户问“查询今天的互动”时由 AI 查询并按人设回答。

## 通道和模拟测试

每路可设置类型、部位、驱动和参数。最多 16 个逻辑通道，现有主板仍为八路 4051 输入。保存全部配置会关闭真实输入/输出并回到手动模式，历史不改写。

没有传感器时保持手动模式，用模拟输入验证链路：压力 0～4095，0 表示释放，非零最多 5 秒自动释放；温度使用摄氏度；震动模拟输出最长 5 秒。页面和历史均标记 simulation，不表示实物读数或电机运动。

FSR 接好后，对 CH0～CH7 逐路做 [压力校准](CALIBRATION_AND_DAILY_MODE.md)，也可在通道参数中设置按下/释放阈值。确认硬件后保存日常模式，后续上电恢复输入；震动输出始终不自动恢复。

温度有 NTC 和 DS18B20 两种驱动，电机需板外驱动。接线见 [通道指南](SENSOR_CHANNELS.md) 和 [数字温度指南](DIGITAL_TEMPERATURE.md)。

## 一次完整互动测试

1. 在 `/companion` 保存你希望 AI 使用的人设。
2. 按 [安装指南](AI_INSTALL.md) 将 MCP 接入所选客户端，让 AI 实际读取设备状态和配置。
3. 对 AI 说“我要和你互动啦，进行一次 60 秒测试”。AI 开始会话并等待新事件。
4. 在设备页或 `/companion` 发送模拟按压；接好并校准 FSR 后，也可实际按压。
5. AI 根据发生时的部位、来源、数据和当前聊天回应。结束后关闭会话，普通历史仍继续记录。

若要在没有新用户消息时自动反馈，自建应用使用事件订阅并接入模型回调；其他客户端须有对应的事件能力。先在 `/bridge` 做主动投递演示测试，该页回执明确标为“非 AI”。详见 [主动互动](PROACTIVE_INTERACTION.md) 和 [聊天窗口](CHAT_MCP.md)。

## 常用维护

- IP 改变：电脑连接页点击查找已配对娃娃，见 [无线恢复](WIRELESS_RECOVERY.md)。
- 查询、导出、删除和保留期限：见 [历史管理](HISTORY_MANAGEMENT.md)，默认不自动删除。
- 更换 Wi-Fi：运行中长按 BOOT，再按首次配网流程操作。
- 固件更新：选择可信交付镜像和清单，见 [无线升级](OTA_UPDATE.md)。

连不上时先检查电源、灯、同一网络、路由器隔离和电脑采集状态。MCP 无工具时重新连接客户端；HTTP 401/403 检查配对和认证。浏览器显示 “SSE stream not offered; use POST” 时，是把设备 MCP 地址当网页打开了；设置页使用设备根地址，MCP 由客户端发送 POST 调用。
