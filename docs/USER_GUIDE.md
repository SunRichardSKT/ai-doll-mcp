# 日常使用指南

首次电脑安装见 [安装指南](AI_INSTALL.md)。已安装后，每天给娃娃供电，双击 **AI_Doll.cmd**，在原 AI 对话中使用。

## 首次配网

1. 设备没有保存 Wi-Fi 时，上电后灯快闪，出现无密码热点 `AI-Doll-xxxxxx`。
2. 手机连接热点；没有自动弹出页面时，访问 `http://192.168.4.1/`。
3. 扫描并选择 **2.4 GHz** Wi-Fi，输入该网络密码并保存。
4. 灯常亮后，设置热点关闭。手机切回家庭 Wi-Fi，从设备页面或路由器取得设备 IP。
5. 在同一局域网打开设备 IP，即可设置通道、MCP、模拟测试和日志。设备网页默认免登录。

| 操作 / 指示 | 含义 |
| --- | --- |
| 快闪 | 配网热点已开启 |
| 慢闪 | 正在连接已有 Wi-Fi，最多尝试 60 秒 |
| 常亮 | 已联网 |
| 运行中长按 BOOT 约 3 秒 | 重新打开配网热点 |
| 按 RST | 重启，保留已保存配置 |

已有 Wi-Fi 连接失败 60 秒后自动进入配网。不要按住 BOOT 上电或复位，否则可能进入烧录模式。测试板载灯会临时覆盖网络指示 3 秒。

## 设置部位和人设

在管理中心“通道与校准”给每路命名，例如头、左手、腹部。通道类型按实际硬件选择，未接硬件时选模拟。完整通道配置保存后会关闭真实输入、输出并回到手动模式。

在“人设与反馈”保存希望 AI 使用的人设、称呼和语气。人设与历史存于电脑；通道与 Wi-Fi 配置存于设备。直传模式下人设和历史存于接收服务器。改名不会改写旧事件的部位快照。

## 平时记录与查询

普通状态下触摸安静记录，不保证每次都让 AI 回复。问原 AI：“查询今天的互动，并按保存的人设回答。”AI 通过 MCP 读取已存历史。

设备离线时仍能查询已保存记录，但应检查最后同步时间；历史可用不表示设备当前在线。电脑模式需采集服务运行，直传模式需接收服务器运行。离线缓存有限，见 [离线说明](OFFLINE_RECORDS.md)。

## 没有传感器也能测试

在“模拟与读数”选择压力通道，发送 0～4095 的数值：0 表示释放，非零最多 5 秒自动释放。温度模拟使用摄氏度；模拟震动只记录命令，不驱动电机。

记录明确标记 `simulation`。原始 ADC 值不能当作牛顿，单通道按压不能直接断言是拥抱。

对原 AI 说“开始 60 秒互动测试”，等待它创建会话后再模拟按压。测试流程见 [原聊天验证](CHAT_MCP.md)。到期结束后，普通记录继续；普通 Chat 的空闲主动唤醒未验证。

## 接好硬件以后

先读 [通道接线](SENSOR_CHANNELS.md)，再按 [压力校准](CALIBRATION_AND_DAILY_MODE.md)逐路校准。确认硬件后保存日常模式，可在重启后恢复输入；真实输出始终不自动恢复。
