## 已有专项验证及范围

配网热点、页面重定向、Wi-Fi 扫描和 60 秒恢复曾在开发板实测；配网逻辑本轮未修改。离线专项验证 256 条缓存、270 条事件容量覆盖、软件重启补传、去重和未知时间。历史删除及保留期限使用一次性数据库测试，未操作用户历史。

无线升级专项实测了取消、30 秒超时、SHA 错误和确认前重启后由启动程序真实回滚。本轮最终镜像完成正常升级；没有对该最终镜像重复所有异常操作。基本启动确认不能发现全部业务故障。

事件桥测试覆盖持久队列、会话目标绑定、合并、租约/ACK、取消、过期、安静时段、去重和签名回调。远程回调使用测试替身；网页“演示回执”不是模型生成。
