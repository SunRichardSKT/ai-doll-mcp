# ESP32-C3 实机测试结果（v2.2）

## Bridge v2.4 无线采集验收（2026-10-04）

开发板固件保持 v2.2，电脑服务为 `doll-bridge-2.4.0`。本次未重新烧录或修改 PCB。无线配置保存到本机，电脑页面显示实际连接方式。

- 11 项无线传输测试通过：HTTP MCP 握手与认证、私网地址校验、错误／重定向拒绝、身份检查、断线重连、历史去重、超时命令不重放，以及无线选择／恢复过程中不打开串口。
- 原 7 项归档和 17 项事件桥测试通过，共 35 项。
- 实际 ESP32 无线测试通过：独立 HTTP 客户端发送模拟按压，电脑通过 Wi-Fi 采集普通历史和互动事件；会话归属、持续时间、游标、去重和结束恢复正常。测试期间 COM3 被独占且没有发送数据，证明采集不经过 USB。
- 27 工具 STDIO 的官方 SDK 调用及 MCP 2.0 接口验证通过；工具不因无线模式减少。
- 页面在 Wi-Fi 模式下自动接收模拟事件，刷新复用订阅、ACK、取消和 390px 布局验证通过。演示回执仍标明非 AI。
- 设备仍由电脑 USB 供电时的串口独占测试不等同于电池供电验收；真实 FSR、NTC、电机和云端 ChatGPT 连接未在本次验证。

本机记录：`wifi-companion-live-test.json`、`bridge-protocol-test.json`、`bridge-live-test.json`，保存在不交付的 `build/device-lab/`。使用方式见 [无线连接指南](WIFI_CONNECTION.md)。下文保留历史验收记录。

## Bridge v2.3 软件验收（2026-10-04）

开发板固件保持 v2.2，电脑服务更新为 `doll-bridge-2.3.0`；本次未重新烧录或修改 PCB。

- 17 项事件桥测试通过：事务回滚、按压合并／去重、普通模式不通知、独立温度基线、输出不回触摸、陈旧记录排除、目标互斥、租约续期、ACK、取消／到期、重启恢复、webhook 重试与签名／回调校验。
- 原 7 项归档测试继续通过，个人历史表保留并增加桥接表。
- 本机主动推送网页通过：另一窗口向实际 USB 开发板发送模拟按压，接收窗口无需新用户消息就出现演示回执；保存回复及 ACK，释放不重复反馈，取消后恢复普通记录，手机布局无溢出。
- 页面刷新后复用同一订阅；旧连接交接经过实机回归。前端在 ACK 成功后显示回复，取消或租约失效时不显示迟到回复；事件重复投递复用已生成结果。
- 本机原生 MCP Events 端点认证、发现／27 工具、事件目录、参数校验与协议冲突拒绝通过；旧 STDIO 使用官方 SDK 验证 27 工具和新偏好／状态调用通过。
- 本机演示明确标注“非 AI”和 simulation。没有配置模型 API、启用真实输出或部署公网服务。
- MCP Events 的远程回调在单元测试中使用替身验证；实际用户账号中的 ChatGPT Work／Claude 接入与模型生成尚未验收。

桥接使用范围见 [主动互动指南](PROACTIVE_INTERACTION.md)。本机证据为 `build/device-lab/bridge-live-test.json`、`bridge-protocol-test.json`、`bridge-live-mobile.png`；以下保留开发板 v2.2 的验收记录。

验收日期：2026-10-03。固件：`doll-lab-2.2.0`。对象：USB COM3 上的 ESP32-C3 SuperMini；测试期间没有启用真实输入和真实电机输出。

最终源码已重新构建、烧录；四个烧录文件均返回 `Hash of data verified`。保留了 Wi-Fi、原通道名称、人设及电脑数据库，测试结束恢复原八路压力配置。软件重启后联网正常，真实输入和输出保持关闭。
