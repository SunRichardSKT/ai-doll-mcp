# 管理中心怎么用

双击软件根目录 **AI_Doll.cmd**，打开 `http://127.0.0.1:8769/`。这是设备管理页面，不是新的 AI 聊天框。

## 第一次打开

按“安装引导”完成四步：**准备环境 → 设备配对 → 选择 AI → 连接验证**。完整 Windows 包自动检查内置 Python、生成配置，无需手动安装依赖。详细步骤见 [首次安装](AI_INSTALL.md)。

设备可先通过 USB 一次识别 IP 和 MCP 令牌，再改为 Wi-Fi。普通 Chat 的 Platform 配置在 [Secure 指南](SECURE_MCP.md)完成一次；本机客户端复制 STDIO 配置即可。

## 日常从哪里操作

| 页面 | 常用操作 |
| --- | --- |
| 安装引导 | 首次配对、复制配置、核对原 Chat 调用 |
| 设备连接 | USB / Wi-Fi、查找已配对设备、网络设置 |
| 通道与校准 | 部位、类型、参数、压力校准、探头扫描 |
| 人设与反馈 | 人设、语气、称呼、回复长度、安静时段 |
| 互动历史 | 查询、统计、导出、删除预览、保留期限 |
| 模拟与读数 | 模拟压力 / 温度、查看读数与来源 |
| AI / MCP 连接 | Secure 启停、工具范围、STDIO 配置 |
| 维护与诊断 | 服务停止、登录自动采集、诊断和升级 |

每天供电联网后双击入口，自动启动或复用已配置的采集与 Secure 服务。没有 Secure 配置时，只启动本地采集。关闭页面后服务继续运行。

## 怎么判断是否在线

“运行概览”分别显示采集、设备同步和隧道状态。隧道检查超过一分钟显示待检查。设备离线时历史和人设仍可用；通道可能显示上次同步的只读副本，不会生成假读数。

在原 Chat 实际调用两个状态工具，将新返回的调用编号粘贴到连接验证处核对。本机健康检查不等于原 Chat 已连通。

## 停止与维护

- **停止隧道**：电脑仍继续采集历史。
- **停止全部服务**：停止本项目采集及 Secure，管理中心仍可操作。
- **准备 / 修复运行环境**：检查依赖、重新生成配置，不清空历史。
- **无线升级**：明确选择固件和清单后操作，见 [OTA](OTA_UPDATE.md)。

旧 `Install_Secure_MCP.cmd` / `Start_Secure_MCP.cmd` 打开同一管理中心。原 `8768/companion` 等页面继续兼容。个人数据在 `build/device-lab/`；目录移动后重新生成客户端配置。

若要让设备直接上传给自己的应用，请用 **AI_Doll_Server.cmd** 或 [远程部署](REMOTE_SERVER_SETUP.md)，见 [两种入口](SERVER_QUICKSTART.md)。启动或连接失败见 [故障排查](TROUBLESHOOTING.md)。
