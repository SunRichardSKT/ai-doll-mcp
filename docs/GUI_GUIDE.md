# 管理中心：安装、配置与日常操作

新增设备直连通路：[手机配置、自部署服务器及原聊天主动反馈](DIRECT_SERVER.md)。原电脑采集 / MCP 流程继续兼容；直连模式无需本地电脑运行。验证范围见 [直连验收](DIRECT_SERVER_ACCEPTANCE.md)。

更新：2026-10-11，电脑 Bridge 2.16.0；设备固件为 2.8.1。

## 从一个入口开始

解压代码包到固定、可写的目录，双击根目录 **AI_Doll.cmd**。它打开本机浏览器中的管理中心 `http://127.0.0.1:8769/`。这是设备和服务管理界面；AI 回复仍出现在你的原聊天中。

Windows 64 位完整包在根目录 `python/` 内置 Python 3.14.8 和 MCP 依赖。完整解压后双击即可启动，无需安装 Python、配置 PATH 或下载依赖。保留 `python/`、`tools/` 和文档等完整目录，不要只复制启动文件。浏览器使用 Edge 或 Chrome，不需要 Node、Electron 或前端构建工具。

## 首次安装：四步

1. **环境准备**：点击“准备 / 修复运行环境”。完整包直接检查内置环境并生成本地 MCP 配置，无需联网安装依赖。源码开发版仍可创建 `.venv` 安装依赖；已有历史不会清空。
2. **设备配对**：先给 ESP32 配网，让电脑与设备连接可互通的家庭 Wi-Fi。在设备设置页启用 MCP，填入局域网 IP 和设备 MCP 令牌，点击“验证并保存配对”。验证失败不会覆盖原配对。设备设置页默认免登录；只有开启登录保护后，电脑端修改网络和无线升级才需要保存对应账号密码。
3. **选择 AI**：普通 Chat 选择 Secure MCP Tunnel；本机 MCP 客户端选择 STDIO。后者生成配置后复制 `mcpServers.ai_doll` 项到原客户端设置，保留其他服务。
4. **连接验证**：检查设备与隧道，在原聊天实际调用两个状态工具。普通 Chat 返回的两个 `verification.call_id` 可以粘贴回管理中心核对服务器记录。本机检查不替代目标聊天调用。

普通 Chat 的首次账号操作仍在官方页面完成：创建专用隧道、关联目标 ChatGPT 账号或工作区、创建具备 Tunnels Read / Use 权限的运行 API 密钥。在管理中心填写隧道 ID 与运行密钥，点击“保存并启动”；官方客户端下载及校验由服务完成。在 ChatGPT 创建自定义 MCP，选择“隧道”，填写同一个 ID，选择无需身份验证。无需另建娃娃账号或填写聊天模型密钥。详见 [官方隧道说明](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)。

已有配置时，令牌和密钥输入框可以留空。修改部位、人设、阈值与反馈偏好需要在对应页面明确保存。

## 日常使用

给娃娃独立供电并联网，再双击 **AI_Doll.cmd**。已有环境和连接时自动启动 / 复用采集及已配置的 Secure 隧道；也可点击“启动日常服务”。不需要保持 USB 数据连接。关闭浏览器后服务继续运行。

“运行概览”分别显示电脑采集、设备同步与隧道检查结果。隧道结果超过一分钟显示“待检查”，不会把旧状态当作当前在线。未配置 Secure 的本机客户端只启动本地采集即可。

| 页面 | 能做什么 |
|---|---|
| 安装引导 | 准备依赖、配对、选择宿主、复制配置、核对 Chat 实际调用 |
| 设备连接 | Wi-Fi 配对、查找已配对设备、USB 切换及 USB 配网 |
| 通道与校准 | 类型 / 部位 / 参数、数字温度探头、压力三阶段校准与诊断 |
| 人设与反馈 | 保存人设、称呼、语气、回复长度、事件间隔与安静时段 |
| 互动历史 | 日期 / 部位 / 类型查询、统计、导出、删除预览及保留期限 |
| 模拟与读数 | 压力 / 温度模拟、当前读数、震动命令与物理开关 |
| AI / MCP 连接 | Secure 配置、2 / 9 / 13 工具范围、启动 / 停止 / 检查 / 内部地址重置；STDIO 45 工具配置 |
| 维护与诊断 | 依赖修复、登录自动采集、服务停止、诊断导出、固件文件校验与无线升级 |

通道、历史和偏好复用原有实现，旧的 `8768/companion` 等地址保留，便于已有客户端继续使用。设备离线时，历史与人设仍可用；通道配置可显示电脑上次保存的只读副本，重新连接后再编辑。尚未同步过的通道不会生成虚假默认数据。

## 测试原聊天

在“连接验证”复制状态查询提示，在原聊天发送，核对两个实际调用编号。然后在“模拟与读数”复制 60 秒测试提示，让 AI 开始会话并等待，再发送一次模拟压力。释放只更新持续时间；到期结束。来源 simulation 不能视为真实触摸，也不能把单通道按压直接等同于拥抱。

模拟功能不会另开 AI 对话或假装生成模型回复。普通 Chat 空闲唤醒、实体温度探头和电机仍需单独验收。Operit / OpenClaw / 自建前后端继续使用 [宿主接入说明](HOST_INTEGRATIONS.md)，目前不是管理中心自动安装的宿主。

## 停止、升级与故障

- **停止隧道**：保留电脑采集与历史。
- **停止全部服务**：停止本项目采集与 Secure 隧道；管理中心仍可操作，其他程序不受影响。
- **升级固件**：Wi-Fi 配对时保存管理密码，选择 firmware.bin 和 FLASH_MANIFEST.json，确认稳定供电后点击升级；或明确选择交付固件。程序校验目标、大小和 SHA-256，并在重启后检查版本。不会自动重试写入；没有刷写意图时不要点击升级。
- **设备 IP 改变**：使用“查找已配对设备”；首次配对仍需设备页面提供 IP 与令牌，不自动配对陌生设备。
- **同步异常**：检查供电、同一局域网和设备 MCP 开关；已保存历史不丢失。
- **Chat 无工具**：核对正确隧道、账号关联、工具范围及当前聊天是否添加连接。检查隧道通过不代表 Chat 已调用。
- **管理中心打不开**：确认 Python 版本、完整解压、目录可写及端口 8769 未被其他程序占用。采集使用 8768；Secure 网关默认 8774。

诊断导出只包含连接状态和操作结果，不导出数据库内容或保存的配对 / 运行密钥。个人数据位于 `build/device-lab`，公开交付包不包含它。电脑休眠、关机或服务停止时不能持续采集及远程调用。

旧的 Install_Secure_MCP.cmd / Start_Secure_MCP.cmd 改为打开同一个管理中心。命令行入口保留给开发、自动化和其他宿主，普通使用不必逐个运行脚本。
