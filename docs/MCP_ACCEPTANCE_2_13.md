## 诊断记录如何解释

Sakura 电脑端 DNS、可信 TLS、HTTP/1.1 / HTTP/2、两工具及 13 工具 SDK 检查成功，仍不能证明 OpenAI 云端访问成功，也不能确定失败来自端口、证书或节点。请求日志阶段曾有缺口，修复后仍未获得成功的目标 Chat 添加证据。

Secure 初次客户端超时而 readyz 成功，没有被当作已连通；沿用本电脑已有代理后观察到控制轮询，目标 Chat 随后成功。旧 AI Doll 和 AI Doll SE 是不同连接，选错插件不能当作隧道故障。

官方客户端文件大小 / 摘要 / 版本检查与生命周期分别测试。Sakura 目录版本标签与可执行输出不同被明确记录，没有跳过校验；ClientManaged 模式不读取用户客户端访问密钥或启动第二个 frpc。

SDK、服务器审计和用户提供的原聊天文字分别作为证据。回归数量按各阶段记录，不能相加当作当前版本一次完整测试。详细调用编号与数据在本机，不公开复用。
