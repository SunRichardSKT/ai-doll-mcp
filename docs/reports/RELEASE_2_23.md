## 队列约定

新事件仍需在 30 秒内被读取并判定有效。已经在会话中及时捕获的触摸，在上一条模型回复期间可排队至多 120 秒，并受本次会话期限约束。保留事件原始时间，不把离线补传、过期历史或故障值改称实时触摸。释放不另触发主要回复。

接收、游标保存和确认由同一个任务串行写入；模型生成可同时进行。下一次提交前重新检查会话、主动偏好、静音和端口状态。结束、静音、端口关闭或排队期限届满时取消尚未提交的内容。已提交的模型回复可以完成；发送结果不明时保留记录并暂停自动续接，由用户核对原聊天。

一个队列片段只合并成一条后续回复，避免每次触摸都打断聊天。返回模型结果后才确认覆盖的回执，确认失败保留已完成记录，不重新生成。确认仍只代表客户端报告处理完成，不证明用户已看到消息。

## 固定名称的范围

IP 由路由器 DHCP 分配，重启后可能保持，也可能变化。固件 2.12.0 的连接名为 `ai-doll-硬件标识.local`，与可编辑的设备显示名分开，普通重启和改名不改变它。USB 重新烧录产生新的内部配对 ID，仍需按新身份配对。

手机仅接受家庭私有 IPv4 或项目生成的 `.local` 名称。恢复候选先读取不含令牌的身份信息，确认是原配对设备后再连接 MCP。旧 IP 被占用时不会把配对令牌发送给那个候选。写入操作失败不会自动重试。

`.local` 依赖安卓系统解析和路由器允许组播，尚无本次手机实测证据。无法解析时保留手填家庭 IP 的入口；也可在自家路由器设置 DHCP 固定租约。电脑端继续使用已有的设备 ID 与带签名 UDP 发现。服务器直传不依赖设备家庭 IP 保持不变。

手机替换 ToolPkg 后即可获得显示、首页自检与排队修改；固定名称及设备页面新文案需要设备安装 2.12.0。现有设备可以保留设置进行无线升级，不必为了手机界面更新重新 USB 烧录。

## 检查与边界

- ToolPkg 使用 Operit 1.12.2 实际 JS 桥检查工具注册、主题颜色标记、首页必需按钮、禁用状态和回调；Android 页面最终渲染仍需手机确认。
- 运行实际队列模块，以明确的设备／模型替身模拟 45 秒生成和多次触摸，检查持续读取、先保存游标、合并后续回复、串行发送、静音、停止、期限和确认失败。
- 手机适配器测试旧 DHCP 地址被其他设备占用，通过固定名称找回原设备，核对实际 IP、设置链接、原聊天和历史标识；错误身份拒绝连接。该检查不证明真实安卓 DNS 已通过。
- 安装的 MCP SDK 检查状态、历史、互动上下文及隔离；编译固件后校验四镜像、分区边界和嵌入网页解压结果。完整包核对文件哈希、文档链接和私密内容排除。
- 本次不新增实体 CH0、目标 Operit 聊天或锁屏后台实测结论。需要用户升级手机包后，在上一条 AI 正在生成时再按两次，核对下一条自然反馈；固定名称需另测设备重启后的安卓解析。
