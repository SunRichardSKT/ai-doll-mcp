# 2.21 连接稳定性与日常使用改进

日期：2026-10-20。发布版本2.21.0，固件2.10.0。[GitHub Release](https://github.com/SunRichardSKT/ai-doll-mcp/releases/tag/v2.21.0)提供Windows、Linux、Operit、PCB与独立外壳包。发布不改变下方的目标环境验收边界。

## 已实施

- 日常启动与 Windows 登录启动使用同一管理入口；采集、Secure 和 Operit 分别恢复，一条通路失败时仍处理其他通路。概览提供“修复连接”。
- Secure 官方客户端通过明确的控制面代理参数启动；本机 MCP 保持直连。使用已有项目进程身份记录和客户端重连逻辑；同配置的429/网络退避不会触发反复重启。系统代理改变时，仅更新本项目运行实例。
- 手机可手工检查并保存电脑 IP，保留原端口、私密路径、聊天绑定和发送记录。已有任务停用后，再从原聊天开启新任务；失败保留原连接。
- 设备当前 LAN IP 来自近期已成功同步的状态，USB 模式同样可读。离线或过期状态显示未确认。
- 烧录页面和 `--name` 支持自定义显示名与热点；每次 USB 烧录仍生成独立配对编号，读回编号、名称和启动结果后才成功。标准升级保留设置与校准。
- 全新固件设置默认仅 CH0 真实输入与日常模式，输出关闭。已有通道、阈值、校准和模式保留。
- 模拟与输出测试归入开发者选项，提供读数、事件、配置及连接只读窗口，收起或离开后停止对应刷新。
- 新增三种卡扣电池外壳候选：旧板平铺P03、紧凑板平铺P02、旧板上下堆叠P01。堆叠版46.29×56.45×35.2mm，按约15mm整板高度与5mm底针预留独立绝缘载架、下沉开关口及LED窗口。几何检查通过，未打印试装。

## 下载与使用

- Windows完整包：`delivery/AI_Doll_Code_v2.21.0.zip`，解压后双击`AI_Doll.cmd`。
- 手机工具包：`delivery/AI_Doll_Operit.toolpkg`，在Operit中更新导入，再在AI Doll设置修改电脑IP；保留已有聊天绑定。
- Linux小型包：`delivery/AI_Doll_Server_v2.21.0.tar.gz`，含MCP与同版手机工具包。
- 烧录入口`Flash_ESP32.cmd`提供随机或自定义名称；只有希望升级设备时才实际烧录，旧固件可继续使用。
- 已开启的Windows登录入口，在首次打开新管理中心时升级为完整恢复；未开启的仍关闭。

全部制品从[本版Release](https://github.com/SunRichardSKT/ai-doll-mcp/releases/tag/v2.21.0)下载，下载哈希见[交付目录](https://github.com/SunRichardSKT/ai-doll-mcp/blob/main/delivery/README.md)。外壳独立下载，避免只为打印模型下载Windows运行环境。

外壳检查包括STEP/STL有效性与单实体、水密、装配静态碰撞、电池完整净空、接头与走线保留体。堆叠版另核对23处5mm参考针脚下方绝缘层，以及电池、载架从上方进出的离散路径。卡扣弹性、开关可达性、电池封边与线弯、射频及温升均待实物验收；电池仓不会替代J9所需的5V电源管理。
