# 2.22 候选：Operit 陪伴界面与内核端口三态

本地候选版本：软件 2.22.0、固件 2.11.0。尚未上传新版 GitHub Release，也未在本轮给用户的实体板烧录。公开稳定版下载仍以仓库 README 的链接为准。

## Operit 2.22.1 导入修正

用户报告2.22.0的`Failed to parse toolpkg file`后，检查实际归档发现：新增`update_port`的3个参数和`set_persona_source`的2个参数缺少必填`description`。Operit 1.12.2先把元数据反序列化为`ToolPackage`；这一步失败，尚未进入已测试的JS注册桥。原先的归档、运行及界面检查未覆盖该解码契约，不能当作安卓导入验收。

手机工具包已更新为2.22.1，保留同一个插件ID和数据目录。补齐5个字段，增加打包前和实际ZIP写入后的元数据校验，以及6项导入契约回归检查；注册检查在存在官方JS缓存时使用1.12.2实际注册桥。Windows与Linux包内也同步放入新版工具包，软件本体与固件版本不变。

替换手机上的同名工具包，保留插件数据，关闭旧面板后重新打开。无需重新烧录或输入连接参数。修复定位与检查结果见本机`build/operit-import-2.22/validation.json`；目标安卓重新导入仍由用户实测确认。

## 界面与日常操作

手机工具包2.22.2另补充各页面的“停止后台任务”，包括自检等待期间；明确区分本机已停止与远端清理未确认，离线也能解除本机设置锁。烧录器修复Windows结果文件替换冲突：网页轮询读取受锁保护的内存快照，文件只作持久保存，并对短暂共享冲突有限重试。已用真实Windows文件占用复现和测试，永久拒绝访问仍报告错误，不删除旧结果或扩大权限。

Operit 工具包保持 `org.ai_doll.companion` 身份和原插件数据目录，工具使用 `ai_doll_companion:` 子包名称。替换同一个 ToolPkg，关闭旧面板后重开；不删除插件数据、不重新输入聊天 ID。

## 常开如何运行

主动开关默认关闭。用户先完成原聊天发送自检，再选择“常开，直到我关闭”并打开开关。内部使用交替的一次性原生工作流执行有限任务，保存同一聊天的会话、游标和发送记录；服务端会话仍有限期。另有15分钟周期恢复任务，用来发现手机调度中断；网络错误延迟续接。

关闭先持久保存停止意图，再结束本聊天的服务端会话并停用本安装拥有的工作流。旧发送结果不明时暂停自动续接，要求用户核对，不重新发送；过期触摸不补发。更改电脑 IP 会停止常开，保留绑定与发送记录，用户可重新打开。

“常开偏好已开启”和“当前任务正在运行”分开显示。Android 可能延迟、暂停或杀死任务，周期恢复也不保证及时运行；强制停止应用后需重新打开 Operit。没有全天、锁屏或系统省电限制的实测承诺。已提交给模型的回复不能可靠撤回。

## 端口状态由固件保存

| 状态 | 内核行为 |
| --- | --- |
| 关闭 `off` | 不采样、不接受该端口模拟输入；上下文排除该端口旧的未回应事件 |
| 模拟 `simulation` | 暂停本端口真实采样，仅接受明确模拟输入；保留真实驱动与校准，其他真实端口可照常运行 |
| 已接入 `connected` | 根据已保存驱动采样，保存重启恢复；原始读数仍不等于物理力度 |

新增设备 MCP `set_channel_state(channel, mode?, name?)`；名称和状态局部更新不重写其他通道、接线或阈值。仅改名称不中断当前按压。全量高级配置显式提供三态时按三态恢复输入，物理输出继续关闭；省略三态的旧全量调用保持关闭输入的兼容行为。

FSR 松开与未插入可能都接近零，现有硬件不能可靠自动识别插拔。“已接入”表示**用户确认并由固件持久保存的安装状态**；“试摸一下”另行验证能否观察到真实按压，不凭零值自动改状态。普通界面删除“日常／手动”双开关；旧 RPC 和旧重启策略保留兼容，已有暂停配置不会静默启用，明确保存端口状态后采用新策略。

旧固件缺少 `port_state_model: per_port_v1` 时，界面禁用端口写入并提供设备设置入口。已有历史、校准、人设和聊天绑定保留。软件名称修改仍兼容旧 names-only 接口。

## 传输与验证范围

STDIO 共52个工具；设备固件共27个；远程 interaction 配置继续19个，新增状态操作经 `update_body_part` 执行，status/history 仍只读。Linux 反向命令白名单包含 `set_channel_state`，离线不排队，超时不自动重放。

本机检查使用已安装 MCP SDK、实际共享代码、Operit 1.12.2 官方 JS 桥及隔离替身。覆盖配置迁移、端口局部更新、来源过滤、独立聊天确认、三种连接适配、常开跨会话续接、停止、地址变化、结果不明不重发、界面桥和移动宽度。真实输入采样算法未调整。

构建与测试具体结果见本地 `build/operit-2.22-validation.json`。固件编译和镜像哈希不等于实板验收；Android 后台、真实 CH0、新版目标聊天和锁屏仍需分别验证。上版用户报告“收到触摸回复”的证据不延伸为这些新功能已通过。
