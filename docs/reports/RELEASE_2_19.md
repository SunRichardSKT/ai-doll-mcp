# 2.19 统一入口：分阶段交付记录

日期：2026-10-15。Bridge / 完整包 / ToolPkg 2.19.0；设备固件保持 2.9.0。本地候选，未发布 GitHub。面向 [统一规划](../developers/UNIFIED_DELIVERY_PLAN.md)的第 1～4 阶段的可独立实施部分，包含完整候选制品；真实手机验收与其余适配器目录整理未完成。

## 实现范围

- Windows 保留 `AI_Doll.cmd` 主入口，完整包直接调用内置 Python，缺失时才使用兼容启动器。
- 原管理中心新增 Operit 页面：模式、局域网选择、保存启动、状态、停止、工具包与连接下载。管理页继续只监听回环；仅专用 MCP 在选定局域网地址提供服务。
- 一份 `AI_Doll_Operit.toolpkg`，整合设置、聊天选择、后台自检、有限互动、恢复和诊断。手机不手填 MCP 工具参数、聊天 ID 或状态文件路径。
- 用户按标题确认已有聊天；自动持久配置和工作流安装；只更新已保存、归属匹配的本插件工作流。
- 使用一次性原生计划启动，控制操作立即返回“已安排”。不从聊天工具轮等待并递归调用原聊天。90 秒启动租约、重复消费保护和停止检查。
- 后台自检仍使用原 MAIN 聊天，输入可见、编号唯一；确认后才开放互动。失败或未知结果不自动重发，确认仅代表客户端或用户报告。
- 支持选择旧发送 JSON 后核对导入，不删除旧状态；服务配置、SQLite、真实配对和校准保持。
- 陪伴上下文、事件策略、压力摘要和历史管理迁到 `src/ai_doll/core/`。旧 `tools` 导入是同一模块的兼容别名；Windows 与 Linux 打包同一份核心，不复制两套实现。
- ToolPkg 和 Windows / Linux 制品由当前源码允许清单生成。旧独立脚本冻结为兼容参考，不再作为新用户安装步骤。
