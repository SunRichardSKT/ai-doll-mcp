# 2.24.1：安装与文档审查整改

2026-10-22。软件、服务端与Operit工具包 **2.24.1预发布**，固件 **2.12.1**；稳定版继续保留2.21.0。[本版下载](https://github.com/SunRichardSKT/ai-doll-mcp/releases/tag/v2.24.1)。

本版处理74份项目Markdown和PCB下单说明审查发现的18类问题。没有烧录用户设备、调整电气参数、修改校准或删除历史；手机直连尚不支持的部位偏好写入以能力边界说明，不冒充新增实现。

## 安装修复

Linux安装器现在同步 `src/` 和 `delivery/AI_Doll_Operit.toolpkg`，使目标目录满足Dockerfile构建输入。源文件缺失时明确失败，不用旧安装中的残留模块掩盖不完整包；升级保留部署数据。安装回归核对实际COPY源及新旧文件刷新，不再用无条件成功的Docker替身证明目录完整。

源码交付先准备开发Python、声明依赖和Node，再构建Windows运行环境、重打包已校验机械导出文件，最后制作完整交付包。仅重新制作机械ZIP不需要重新生成几何或安装CAD。

- 固件2.12.1仅修正版本和工具自描述，不改变接线、采样参数、存储格式或输入恢复逻辑。软件修复不要求重新烧录。
