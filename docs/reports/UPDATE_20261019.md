## 已配对设备搜索与恢复

- Windows 直接读取系统网卡表，短时缓存网卡信息；先验证设备上次地址，无回应再并行广播到局域网接口，并进行一次丢包重试。
- Wi-Fi 采集启动时先搜索，避免持续等待旧 IP。验证失败按 2～30 秒退避重试，恢复后回到正常采集频率。
- 保存的 USB 失效时，已配对设备可以通过签名挑战及实际设备身份核对恢复为 Wi-Fi。显式指定 USB 或串口的维护操作仍遵守指定连接。
- 写入、输出及事件确认不因恢复自动补发；身份或保存失败时保留原配置。不扫描整个网段，也不自动配对陌生设备。
- 管理页可从失效 USB 连接发起搜索，并展示实际连接方式。

使用方法见 [配网与连接恢复](../daily/WIFI_CONNECTION.md)，常见问题见 [故障排查](../TROUBLESHOOTING.md)。
