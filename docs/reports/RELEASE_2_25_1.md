# 2.25.1 修订与验证记录

日期：2026-10-24。软件／Operit 2.25.1，配套固件2.13.2。本次修复2.25.0源码检查中复现的问题；不重新烧录用户设备，不改校准、电气参数、分区或工具包身份。

## 已修复

| 问题 | 处理 | 检查方式 |
| --- | --- | --- |
| 手机设置截断后所有入口报错 | 设置和任务保存校验副本，恢复时保留安装身份与聊天绑定并暂停后台；两份都不可用时仍能打开面板、停止与重新导入，原文件保留 | 实际工具入口配合文件故障替身，覆盖截断、校验不符、写入中断、文件消失与任务恢复 |
| 换Wi-Fi时旧连接启动90秒计时 | 等新连接尝试执行且当前SSID匹配目标后，才缩短配网窗口；失败不延长原10分钟期限 | 编译生产网络状态机，模拟延迟500ms、错误凭据和旧连接回调 |
| 新归档不断全量读取旧段 | 运行中只读取新提交段；每日兼容文件首次写入、之后每新增128条做检查点；完整记录仍立即写入校验段 | 已有10／100／250批后新增一批，文件读取均为8次，修复前33／213／513次；重启及索引损坏重建保留251条 |
| 回归依赖人工执行 | 新增GitHub Actions：固件校验、生产策略、手机包所有构建检查、MCP SDK、文档与Linux包审计 | 本机使用相同入口；远端结果以Actions实际运行记录为准 |
| 固件缺少预留门禁 | 检查源码／镜像／清单版本、完整四文件哈希及固定分区；OTA剩余低于8KiB阻止导出和打包，低于32KiB警示 | 使用实际预编译文件；不缩减历史和OTA分区 |

记录的文件读取次数是API调用量，不是Android耗时。校验副本与读回不能保证物理断电时文件系统已落盘。每日文件仅为兼容检查点，不能单独用于完整导出或降级；新版历史查询从提交段重建完整记录，不丢弃检查点之后的数据。

## 升级与恢复

- 从[本版Release](https://github.com/SunRichardSKT/ai-doll-mcp/releases/tag/v2.25.1)使用同批次Windows／Linux／Operit包及其固定校验文件；不要覆盖旧Release附件。
- 更新手机工具包保留插件ID、配置路径、历史、回执及聊天绑定。旧设置第一次保存时补充恢复副本，无需删除重装。
- 设置恢复后先核对连接和原聊天，再明确开启。无法恢复的原文件另存于插件数据目录；两份配置同时损坏时需要重新导入和绑定，不声称已自动找回原绑定或原归档映射。
- 设备热点计时修复需要实际升级2.13.2固件，仅更新手机包不会改变板上策略。USB烧录产生新安装身份，按实际返回重新配对；保留原校准与历史。
- GitHub在2026-10-24将旧v2.25.0标为正式发布；该平台标记不补充硬件证据。本修订继续作为预发布候选，保留旧版原附件与元数据，2.21为兼容回退基线。

## 软件证据与剩余验收

本机手机包构建检查通过，包含19组归档场景和5组关键存储故障场景；生产网络／归档策略、嵌入资源、容量拒绝规则及安装的MCP SDK两种传输共16项Python检查通过。固件2.13.2编译成功，四镜像校验通过，应用1,298,304字节，OTA槽1,310,720字节，余12,416字节。交付包最终结果以Release校验清单为准；GitHub Actions以实际运行记录为准。

本轮没有实板烧录、手机相机／WebView操作、家庭网络切换、真实触摸慢模型排队或30分钟锁屏验收。已有真实压力证据仅覆盖CH0。公开V2丝印工程的1项原生网表差异仍需在EDA内核对，不将软件修订当作PCB生产放行。新用户销售交付前按[当前验证范围](VALIDATION.md)逐项记录，不能宣称八传感器或所有手机路径均已通过。

固件OTA余量仍小，门禁只避免继续无约束消耗空间；后续固件功能需要先缩减代码或网页体积。主机与手机界面新增功能优先放在相应软件端。
