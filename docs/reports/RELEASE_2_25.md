# 2.25.0：免电脑配对、地址恢复与手机补传候选

2026-10-23。本地候选：软件／Operit **2.25.0**，固件 **2.13.0**。本版先交付本机 `delivery/` 的完整候选包；尚未发布为 GitHub Release。已发布的2.24.1与稳定2.21下载保持原样，不能把旧手机包当作本版。

## 改进内容

- 单手机从设备热点读取配对草稿，家庭网络核对成功后再提交；保留文件、连接码及手填入口。
- 设备设置页与服务器管理页本地生成临时二维码，无需实体标签；Operit支持拍照或相册图片的离线识别流程。
- 二维码生成和解码依赖固定来源、哈希与许可；不使用CDN，不将二维码内容交给模型识别。
- 同一安装身份更换地址保留聊天和历史；服务器导出持久实例标识、配对标识及已知设备身份。
- 手机记录同步与主动回复分开，实时采集优先于Flash补传；设备重启、过期及旧记录不触发恢复后的旧回复。
- 手机增加可校验归档段与提交记录，归档完成后才确认设备缓存；未知旧启动时间保持未知。
- 固件增加90秒归档租约，电脑、手机与设备直传协调主归档归属。旧固件的手机兼容路径只复制，不自动ACK。

## 本地文件与升级

Windows使用 `AI_Doll_Code_v2.25.0.zip`，Linux使用 `AI_Doll_Server_v2.25.0.tar.gz`，手机使用同批次 `AI_Doll_Operit.toolpkg`。这些文件由本版打包器产生，校验使用同目录 `DELIVERY_MANIFEST.json` 与 `SHA256SUMS.txt`。

从新的Linux候选包解压目录运行其中的 `Install_Server.sh`，复用原项目、目录和数据卷。候选尚未上传时，不使用已安装入口联网下载2.25的升级方式。电脑／服务器与手机包同版更新；手机完整租约ACK另需设备支持，旧固件会显示复制归档限制。

保留原插件身份、手机数据目录、`storage_key`、聊天绑定、旧日文件、发送结果记录、电脑／服务器历史和校准。标准固件更新不更改电气参数；标准USB烧录仍会生成新的安装身份，必须重新配对，不能仅凭固定硬件名称接管旧安装。
