# 2.18 自然陪伴交付记录

记录日期：2026-10-13。本轮为本地交付候选，尚未发布 GitHub。[教程目录](../README.md)

## 功能

- STDIO 51 工具；电脑 HTTP/Secure 与 Linux 直传 interaction 19 工具，status/history 保持 2/9 工具及只读边界。
- 名称单独同步，别名、部位回应等级和提示留在电脑/服务器；保留采样与校准，不修改固件和接线。
- 聊天融入默认开启，主动回应默认关闭；近期上下文读取不消费，确认按聊天隔离，并在重启后保留去重。
- 原模型和人设优先。日常不展示诊断报告；配置页增加独立开关和部位局部保存。原前端可使用 replyWithContext，沿用原聊天队列与消息列表。

## 验证与边界

隔离数据库测试覆盖字段验证、名称失败、离线元数据、采样参数保持、历史名称、重复读取、确认隔离、重启、释放、冷却、过期与静音。官方 MCP SDK 通过 STDIO、电脑 Streamable HTTP 和 Linux 直传工具调用；浏览器验证手机宽度的部位局部保存及两个开关，不操作真实硬件。旧会话、事件桥和共享队列使用测试数据回归，不等同于目标聊天实测。

实物成功采用用户已确认的结果；本轮没有重刷固件、修改校准或用模拟替代实体传感器。当前设备通信可能离线，不能据旧报告宣称它正在运行。目标普通 Chat 需要刷新工具后，分别验收近期触摸融入、查询历史、聊天内修改和设置入口；主动空闲唤醒需宿主订阅及真实反馈证据，本轮不将 SDK 结果冒充唤醒验收。
