# 2.20：Operit 免电脑连接与日常入口

发布：2026-10-16，**v2.20.0 预发布版**。[下载与发布说明](https://github.com/SunRichardSKT/ai-doll-mcp/releases/tag/v2.20.0)。包含自 2.17.0 后的自然陪伴与 Operit 统一交付更新，固件保持 2.9.0。

用户已确认现有 Operit 能回应触摸；本记录不推断该反馈属于真实传感器还是模拟来源，也不将其扩大为新增部署路径已通过。

## 已实现

- 同一个 ToolPkg 保留电脑导入，并增加服务器导入和仅手机直连入口。配置、已有聊天绑定、内部工作流、回执仍在原插件目录。
- 直传服务器的已授权管理页可下载工具包与按设备生成的 Operit JSON。连接仅含 MCP 地址与标签，不混入管理令牌或设备上传令牌。无授权、撤销配对、缺少 MCP 或非互动配置不能导出可用连接。
- Linux 小型包和 Docker 构建包含同一个工具包，接收与 MCP 共用 SQLite，无需另开电脑采集器。公共下载包不含个人地址或历史。
- 手机直连读取现有 ESP32 的 HTTP MCP；默认免登录时从本地设备接口取得连接信息，开启登录保护时支持显式输入设备令牌。保存前核对实际身份，拒绝公网或回环设备地址。
- 手机侧新增有限会话、按聊天隔离的上下文回执、按压释放与冷却去重、30 秒新鲜度、故障与补传过滤、重启结束、分日历史和近期查看。只在运行任务期间采集，不称完整离线归档。不会确认设备 Flash 队列或修改硬件配置。
- 家庭 DHCP 地址变化时，确认同一硬件后保留绑定、历史与未决回执；身份变化拒绝沿用。手机断网仍能读取已采集历史、停止本地会话及关闭偏好。
- 面板提供显式开启／关闭触摸回应、1 分钟测试、15 分钟陪伴。关闭主动开关先停止任务。继续沿用原 MAIN 聊天生成队列和持久发送日志，不新增聊天或模型密钥。

## 检查与边界

本机检查使用声明的 MCP SDK，以及明确的 Android / 模型 / ESP32 RPC 替身：

- `test_operit_phone.cjs`：配对、认证、身份、旧事件边界、每日历史、稳定回执、两个聊天隔离、释放过滤、过期／故障／缺口、重启、地址改变、断网停止及原 MAIN 发送。
- `test_operit_server.py`：实际 HTTP 下载与权限、实际 MCP SDK 工具发现、手机入口导入、模拟设备向真实接收服务上传、MAIN 调用及回执确认、历史保留与配置撤销。Android 和模型调用仍为替身。
- 现有统一 ToolPkg、官方 1.12.2 JS 注册／UI 桥与 MCP SDK 模拟互动回归；服务器手机页面的实际 HTML / JS、下载和响应式布局另测。
- 完整 Windows / Linux 制品、文档链接、校验和及安装凭据排除逐项检查；固件四文件保持 2.9.0，不重新烧录。

Operit 1.12.2 的默认脚本时限为 1800 秒；本轮 15 分钟模式低于该值，不等于已证明不同手机能持续后台运行。参考[官方时限配置](https://github.com/AAswordman/Operit/blob/v1.12.2/app/src/main/java/com/ai/assistance/operit/core/tools/javascript/JsTimeoutConfig.kt)。

新增服务器实际 HTTPS 部署、家庭设备手机直连、15 分钟真实持续运行和锁屏行为仍待目标环境验收。没有云服务器时，不能把本机接收服务测试称为公网部署完成。用户日常流程见 [免电脑指南](../integrations/OPERIT_NO_PC.md)。
