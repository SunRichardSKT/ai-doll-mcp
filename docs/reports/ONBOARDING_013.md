# 0.1.3 连接与组合动作

2026-11-15。本地软件、Operit 与固件版本统一为0.1.3，对应 GitHub v0.1.3。

## 完成内容

- Operit 三步连接与私有草稿：热点读取、网页配网、家庭网络核对；已联网跳过填写，关闭后可继续。
- 网页上方返回按钮自动读取家庭地址；文件、二维码、连接码和手填入口集中到其他连接方式。
- 固件配网页新增 Operit 呈现模式，独立浏览器保留固定入口与家庭 IP；鉴权与热点时限保留。
- Windows USB 配网、已联网自动配对；ChatGPT、Claude、DeepSeek、Operit及其他客户端分流；USB 测试折叠到开发者区。
- 配对失败保留旧连接；同设备地址变化保留聊天、历史、校准与回复选择。
- 官方客户端入口补齐 DeepSeek DSH 与 Gemini CLI 的原生本机配置、服务器远程配置复制；ChatGPT 与 Claude 保留原路线。
- 手机、电脑与服务器支持自定义压力部位组合；同次重叠按压标注动作名称，不改写原事件。跨游标、释放、冷却、来源隔离与配置保存已纳入检查。

## 本地检查

配对与实际 Operit 1.12.2 JavaScript 桥检查涵盖首次草稿、重开继续、过期、提前切网、旧 IP 占用、名称失败、认证保护、错误身份和迟到结果。二维码取消、手机归档、回复队列、配置更新和停止任务沿用工具包回归。

配网页检查运行在实际源码和构建嵌入资源上，覆盖390px明暗主题、长网络名、表单验证、扫描为空、等待联网、状态失联、身份／权限错误和浏览器备用入口。Windows 页面使用明确接口替身检查各平台路线、Claude 配置合并与 HTTPS 地址要求及已联网 USB 跳过填网。

固件镜像1,208,352字节，OTA槽1,310,720字节，余102,368字节；静态 RAM 74,692字节。分区和256条缓存容量保持不变。

已将候选工具包装入用户 Operit 1.12.2，保留原聊天绑定，实机显示旧草稿过期及第1步入口。用户随后连接设备热点；按用户后续要求暂停手机测试，尚未完成真实热点读取、切网与恢复检查。各平台账号内的实际 MCP 调用需按对应账号完成。
