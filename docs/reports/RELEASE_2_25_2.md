# 2.25.2 固件空间优化

日期：2026-10-24。软件／Operit 2.25.2，固件2.13.3；基线为2.25.1／固件2.13.2。本次未向用户设备烧录。

## 实际大小

| 项目 | 优化前 | 优化后 |
| --- | --- | --- |
| 应用镜像 | 1,298,304字节 | 1,278,192字节 |
| 单个OTA槽 | 1,310,720字节 | 1,310,720字节 |
| 可用余量 | 12,416字节 | 32,528字节 |
| 编译器报告的静态RAM | 75,892字节 | 75,892字节 |

减少20,112字节，约19.64KiB；余量约为原来的2.62倍。余量仍略低于32KiB，保留容量警示，不表示可以无限增加功能。导出与打包的最低余量由8KiB提高到24KiB，禁止通过缩小历史或OTA分区绕过。

## 改动

- 将30个工具的固定名称、描述、参数与注解保存到`firmware/src/device_tools.json`，构建时生成Flash常量，`tools/list`直接序列化该数据，避免反复构造相同JSON。调用分发、工具顺序和参数含义保持一致。
- 网页脚本在构建时移除无用空白与注释。使用固定来源的rJSmin 1.2.5纯Python实现，来源、散列与Apache-2.0许可位于`tools/vendor/`，不从网络临时取脚本。
- Nayuki二维码脚本使用固定Terser 5.44.0缩短局部标识符，关闭压缩变换和属性重命名，保留原TypeScript、公开接口与完整MIT许可。生成步骤、来源与散列更新到`clients/operit/vendor/SOURCES.json`及`tools/qrcodegen_minify.json`。
- 资源使用构建端Zopfli 0.4.3生成标准gzip；浏览器继续原生解压。未在ESP32加入解压器，不占用额外板上RAM。开发者依赖见`requirements-firmware.txt`，完整下载包用户无需安装这些工具。
- 新增独立CI固件编译，检查实际编译镜像、原生工具清单序列化、安装的MCP SDK、预编译清单与固定分区。

完整证书库、HTTPS验证、64位归档编号、传感器与校准逻辑、256条缓存、双OTA槽和回滚策略均保留。不切换不支持64位格式的精简C库，不删除异常回溯表来降低体积。

## 检查与边界

本机已编译ESP32-C3镜像并验证四镜像清单；启动镜像与分区文件保持原字节。原工具构造器生成的30项JSON与新清单逐项相等；生产序列化函数在原生C++运行后，通过安装的MCP SDK解析，未修改工具协议。

实际gzip资源在浏览器隔离环境验证：管理页鉴权／临时热点、二维码图片往返／连接文件下载、OTA缺文件／取消／分块／确认，以及电脑、设备和两种嵌入视图的端口设置、校准与开发者窗口。设备、HTTP和无线使用明确替身，这些结果不证明实板或锁屏可用。

完整包、手机包与文档的校验以[本版Release](https://github.com/SunRichardSKT/ai-doll-mcp/releases/tag/v2.25.2)固定清单为准；CI结果以GitHub实际运行记录为准。更新工具包保留原插件数据和聊天绑定；旧Release附件不替换。

2.13.3仍需目标实板配网、HTTPS直传、真实触摸及OTA验收；本次没有重刷、复位或改变用户硬件参数。目标Operit相机／WebView、真实触摸排队和30分钟锁屏仍依[验证范围](VALIDATION.md)单独记录。
