# 2.25.3：Operit 日常互动与维护

发布日期：2026-10-28。软件与 Operit 为 **2.25.3 正式版**，配套固件沿用 **2.13.3**。

## 主要更新

- **自定义触摸回应**：在“设置 → 人设与反馈 → 触摸回应方式”编辑提示词，控制语气、长短、是否提次数和连续触摸的回应方式。支持恢复默认，下一批反馈使用新设置。
- **连接与状态更稳定**：修复前台状态查询和后台任务同时运行时的结果错位，减少错误的“尚未绑定”提示。
- **连续触摸继续排队**：AI生成期间保留后续触摸，完成后合并回应；一批中关闭某个端口，不影响其余端口。
- **减少漏回应**：修复新触摸先被Flash页读到时无法进入实时上下文的问题，旧补传仍只归档。
- **历史更好用**：支持中文输入法的全角日期横线，翻页保留筛选，修正补传数量。
- **清理更可靠**：改善停止任务、异常收尾和部分确认恢复，精简已确认回执与无用代码。
- **改名保持原配置**：支持的固件使用局部端口接口，不覆盖校准、阈值和其他通道。

## 升级方式

从[2.25.3 Release](https://github.com/SunRichardSKT/ai-doll-mcp/releases/tag/v2.25.3)下载同批次文件：

| 使用方式 | 下载文件 |
| --- | --- |
| Windows电脑 | `AI_Doll_Code_v2.25.3.zip` |
| Linux服务器 | `AI_Doll_Server_v2.25.3.tar.gz` |
| Operit手机 | `AI_Doll_Operit.toolpkg` |

升级保留历史、连接、聊天绑定和校准。已运行2.13.3固件的设备无需重刷。Operit先停止后台任务，再按[工具包升级](../integrations/OPERIT_SETUP.md#工具包升级)操作；保留插件数据及原聊天。

提示词保存在本机Operit，电脑采集、服务器和手机直连使用相同入口。最多4000字，保存空白或点击恢复默认即可还原；编辑不会发送测试消息。
