# 0.1.2：NTC温度与擦眼泪扩展

2026-11-14 · 当前源码／同版候选包。设备能力 `resistive-inputs-v1`，网络版本仍为2。硬件仍为第一代C3，未重新设计PCB。

## 硬件和固件兼容

0.1.1不支持这两种输入；0.1.2增加temperature／wetness，使用现板已有4.7k串联＋10k下拉及4051。推荐6压力＋NTC＋湿润片，不新增实体插口。UT422按R25=10k、B3435配置，直接焊接PA2.0 2P线束。文件中的湿润＋掌部压力方法已改为现板MUX通道，未占用已用于选通的GPIO4。

温度输出为探头接触温度，深埋填充棉不能可靠测人体体温。擦眼泪为双电极湿润600ms且相关压力按下，单湿润阶段只生成一个主要wipe，干燥1000ms复位。可调阈值、持续时间和关联压力编号；不增加液体分类。

## 软件路径

- `resistive_inputs.h`：Beta换算、有效范围、温度报告节流和湿润状态机；没有波形缓存、任务或第三方温度库。
- `channel_devices.h`：能力、类型、配置往返和资源／关联校验；旧压力阈值和retired_channels保留，不自动复活旧驱动。
- `touch_events.h`：真实ADC毫伏采样、故障有效性、raw／mv记录及来源隔离。
- 设备／电脑共用编辑器按能力显示类型，转换时保留MUX编号并先关闭。早于0.1.2的设备不显示新增类型。
- STDIO、HTTP、Linux直传、Operit均保留类型与质量；wet／dry仅归档，wipe经单独用户偏好进入原队列。温度首次采样静默建立基线，默认变化1℃才进入反馈。
- wipe不会被前一条压力的冷却直接丢弃；生成中的回复继续完成，新事件排队。回执、聊天隔离、离线不重放沿用现有协议。
