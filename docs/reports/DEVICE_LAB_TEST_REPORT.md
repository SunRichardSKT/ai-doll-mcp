## 专项结果

- 配网热点、Wi-Fi 扫描、60 秒恢复与 BOOT 重配曾在裸板实测。
- 离线验证 256 条缓存、270 条容量覆盖、软件重启补传、去重和未知时间；不等同写入时拔电。
- OTA 异常覆盖取消、30 秒超时、SHA 错误、确认前重启后真实回滚；最终正常升级未重复全部异常。
- 历史删除 / 保留使用独立数据库，不删除用户历史。页面多页操作使用模拟数据。
- 队列验证普通消息与完整互动生成 / ACK / 写入顺序、取消、租约、容量和聊天隔离，模型为明确替身。
- Bridge 2.12.3 连接争用排队最多 2 秒，超时控制不补发；26 项针对性测试通过。2 秒不是整次网络调用时限。

## 真实 Work 调用

当时本机工作对话实际经 Wi-Fi 注入模拟头部压力并读取会话开始 / 释放，在同一 AI 对话回应。记录为 `simulation`，raw 1800，时长约 5002ms；恢复测试同样为 raw 1800、5002ms。输出保持关闭。

该测试证明执行中的 Work 工具调用，不能代表普通 Chat 或后台唤醒。普通 Chat 后续已独立通过 Secure 状态、历史和模拟反馈，见 [MCP 报告](MCP_ACCEPTANCE_2_13.md)。Sakura 在此基础阶段尚未配置，后续 SDK 成功 / Chat 失败也在该报告记录。
