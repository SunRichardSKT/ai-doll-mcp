## 已取得的本轮证据

实板为 ESP32-C3 / 4MB，只有 CH0 安装实体 FSR。基础压力测试在 2.8.4 上得到 508 个有效样本、0 次读取错误；核对 7 组完整实体按压/释放，持续 1.217～2.013 秒。松开后 424 个样本范围 3～12，没有触发。

2.9.0 的标准烧录通过实际页面启动，四个镜像写入校验、应用启动、新设备 ID 保存与重启回读均成功。原 CH0 配置、1691/708 阈值、日常模式保留。电脑历史数据库保留，匹配旧设备的本机配对更新，采集服务恢复。

电脑实际连接设备热点，通过 192.168.4.1 读取 HTTP 200 的设备页面；返回 NORMAL、家庭 Wi-Fi 已连接、设置热点仍开启。截图来自实际烧录页面与实际设备页面，网络、密钥和本机路径区域遮挡。

固定热点的联查同时修正网页登录恢复、OTA 和直传的判断：正常联网时热点开启不绕过登录；只在恢复状态且从热点访问时允许重设密码；OTA 仅家庭 LAN，正常直传不受保留热点影响。纯逻辑 C++ 测试覆盖这些状态组合，固件已重新编译。

最终修订镜像已再做标准 USB 烧录，得到与前一次不同的设备名称，两次成功日志分别保留。再次回读确认原通道和阈值完全一致，启动标识已经改变，日常真实输入恢复、输出保持关闭。固定页的展示与功能截图不含本机路径或密钥。

## 没有据此声称通过的内容

本轮标准烧录保留已有板的数据，没有为了出厂演示清空用户校准。首次默认配置及出厂路径有代码/测试检查，不冒称对一块新空白实板完成全部出厂体验。CH1～CH7、温度、电机、5 秒长按、整机电池和新版本真实校准仍需实际操作。

普通 Chat、真实公网和宿主后台唤醒沿用明确的历史验证范围，没有因本轮 USB 和页面成功而扩大结论。
