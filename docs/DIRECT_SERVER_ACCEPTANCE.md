# 设备直连与原前端回调验收

日期：2026-10-11。交付为固件 2.8.0 / Bridge 2.15.0。使用真实 ESP32-C3 SuperMini；无实体传感器，模拟压力，物理输出关闭。本机接收服务器承担未来远端服务器的角色，原电脑采集器停止，USB 只用于升级诊断和软件重启，没有转发事件。

## 实现与结果

| 项目 | 实际结果 |
|---|---|
| Wi-Fi 直传 | 开发板主动发送事件页与配置快照，接收服务器提交 SQLite 后返回 ACK |
| HTTPS | 内网 CA 签发的证书与主机名校验通过；错误根证书被拒绝，期间未新增同步或 ACK；公网明文 HTTP 配置被拒绝 |
| 手机配置 | 390px 浏览器实测设备直连配置、上传状态、自有根证书开关；服务器手机页可绑定设备并进入完整设置 |
| 远端设置 | 保存现有通道配置经设备实际执行回执确认；保留原通道、硬件开关与参数 |
| 原前端空闲接收 | 模拟通道 0 按压由真实设备直传，SSE 自动触发原生成回调；无需新增用户文字，原聊天上下文保留 |
| 回复与停止 | 使用标明 demo 的生成测试替身，一次主要回调；ACK、原消息插入、结束后停止回调通过 |
| 动作解释 | 保留 ADC 原始值；固件旧“高值等于拥抱”提示改为模拟按压记录，动作含义交由原 AI 判断 |
| 重启 | 软件重启后 Wi-Fi 与直传配置保留，恢复校验证书的 HTTPS 上传；本轮不冒充物理断电测试 |
| 双采集保护 | 实际电脑采集器发现直传已开启，仅读取状态后拒绝采集，不读取记录或发送 ACK |
| Windows 重复启动 | 第二个同地址监听被拒绝，防止请求进入旧进程 |
| 原电脑功能 | GUI 管理中心 14 项回归；原浏览器去重、取消、生命周期与聊天队列测试通过 |

服务器、离线归档及会话基础共 48 项自动化测试通过：包含有效提交后 ACK、无效页回滚、重传去重、重启、旧事件仅归档、设备离线历史、设备隔离、令牌绑定/撤销、真实 HTTP/SSE、命令最多一次下发与回执、过期控制及配置与状态并行。浏览器测试与生成回调均明确使用测试替身，没有据此声称调用真实模型。

本地证据保存在 `build/direct-device-test/` 与相关 `build/direct-*.log`，包含 HTTPS、重启、浏览器报告和手机尺寸截图；运行数据不进入公共交付。

## 交付和限制

预编译镜像校验值见 [固件说明](../firmware/prebuilt/README.md)和 `FLASH_MANIFEST.json`，与实际烧录验证的镜像一致。编译 RAM 22.6%，Flash 95.0%，未改变分区。

最终镜像采用 USB 烧录并通过设备 Flash 校验。Wi-Fi OTA 期间也实测了传输超时：设备中止上传并保留旧固件；未将失败上传记为成功升级。

Compose 配置校验通过；此电脑 Docker 引擎未启动，未构建或启动容器。用户暂时没有服务器 / 域名，因此真实公网部署、自动签发证书、跨公网断线恢复与用户现有前端的真实模型生成仍待对应环境验收。代码包已提供 Python 服务、Dockerfile、Caddy、持久数据卷和部署指南，没有把模板交付标作实际云部署。

普通 Chat 的空闲唤醒未实现验收，原 Secure MCP 限时互动结果不变。新能力面向可接入事件回调的本地或服务器自定义前端。页面关闭后需要原应用后端接收事件，并使用其现有消息推送；不承诺手机浏览器脚本后台永久运行。实际压力、温度、震动仍需接线校准与实物验收。

操作见 [直连与原前端接入指南](DIRECT_SERVER.md)。默认仍保留原电脑采集通路；启用服务器直传是用户可选配置。
