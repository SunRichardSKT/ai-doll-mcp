# 通道、压力、温度与擦眼泪

按实际安装，为每个端口设置输入类型、身体部位和采样状态。八个实体口 J1～J8 对应 MUX 0～7；逻辑通道最多 16 个，实体插口仍为八个。

[教程目录](../README.md) · [扩展接线与配件](../../hardware/expansion/resistive-inputs/README.md)

## 按实际固件选择

| 固件能力 | 可用输入 |
| --- | --- |
| 0.1.1 `pressure-switch-v1` | 压力、GPIO21 干接点 |
| 0.1.2 `resistive-inputs-v1` | 压力、NTC 温度、湿润片、GPIO21 干接点 |

设置页按 `get_channel_capabilities` 返回的能力显示选项。温度与湿润片需要配套 0.1.2 固件和软件。J1～J8 使用电阻分压采样，适合无源电阻传感器；电机和数字探头需另行设计接口。

## 端口设置

| 状态 | 用途 |
| --- | --- |
| 关闭 | 暂停本端口采样，未安装时使用 |
| 已接入 | 按保存的安装配置读取真实传感器 |
| 模拟 | 开发者测试，事件标记为 `simulation` |

“已接入”由用户按装配情况确认；FSR 松开时也可能接近零，零读数不能用于判断插拔。

改名或开关使用“保存此端口”，保留其他通道、阈值与校准。更换类型或接线时进入“硬件高级设置”，修改目标行后保存完整配置。设备重启后恢复已保存的端口状态。

## 六路压力＋温度＋擦眼泪示例

1. 断电。J1～J6 保留压力，J7 接两线 NTC 10k/B3435，J8 接双电极湿润片。锁扣板统一使用 **PA2.0 2P** 线束，焊点分别绝缘并固定线尾。
2. 在 CH6 的“硬件高级设置”选择“温度输入”，保留 `mux_adc` 和端口 6；使用 10k/B3435、主板 4.7k 串联与 10k 下拉参数。
3. CH7 选择“擦眼泪感应片”，端口 7；将 `pressure_channel` 指向实际安装在掌部的 FSR 通道。
4. 类型切换后两路先关闭。核对并保存全部通道，再将两路设为“已接入”，在诊断窗口查看温度、干湿状态和原始值。
5. 默认记录扩展事件。需要聊天回应时，在 Operit“身体与传感器”允许对应回复，再开启全局主动回复并绑定聊天。

NTC 放在手掌或胸前薄布下可感知局部接触升温；深埋填充棉时测得的是娃娃内部温度。首个有效样本建立基线，默认变化 1℃ 后可回应；断线、短路和越界显示无效状态。

擦眼泪在湿润持续 600ms、关联压力按下时产生一次 `wipe`；干燥持续 1000ms 后复位。`wet`／`dry` 进入历史，同一湿润阶段回应一次。初始干湿阈值为 250／500，按实际干布、湿布读数调整。

具体分压电路、感应片结构和参数见[制作指南](../../hardware/expansion/resistive-inputs/README.md)。本板 GPIO4 用于 4051 选择，扩展探头接 J1～J8 中选定的传感器口。

## 压力校准和测试

J1 对应 CH0、`pressure`、`mux_adc`、端口 0，其余依次类推。保留主板的 4.7k 串联、10k 下拉与滤波电容，再按[校准指南](CALIBRATION_AND_DAILY_MODE.md)逐路采集。

开发者选项提供独立模拟：压力 0 为释放，非零值最多 5 秒后自动释放；温度单位为 ℃；湿润输入为 0 干、1 湿。模拟湿润与关联模拟压力配合检查 `wipe` 事件路径。实物验收使用真实探头和实际干湿测试，压力原始值按 ADC 数值查看。
