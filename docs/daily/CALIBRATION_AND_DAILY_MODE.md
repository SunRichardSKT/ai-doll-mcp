# 校准压力传感器：静置、轻按、较强按

> 按本页步骤操作即可；无需读完开发者资料。 [全部目录](../README.md)


校准的作用是让程序分清“没有按”和“已经按住”。你只需校准实际安装的通道，不用先装满八只传感器。

## 开始前先检查

打开 [固定设备设置页](WIFI_CONNECTION.md)，或电脑管理中心“通道与校准”。接 CH0 的 FSR 时选择压力、`mux_adc`、端口 0；没有安装的通道关闭。

勾选已接好传感器，启用真实输入。按住再松开：实时读数应明显升高再回落，来源是 `sensor`。读数始终不变时先按 [接线指南](SENSOR_CHANNELS.md)检查，别用降低阈值来掩盖问题。

## 按顺序做三次采集

1. **静置**：选择通道，保持娃娃最终安装姿态，不碰传感器，采集约 3 秒。
2. **轻按**：持续轻按感应面，点击轻按采集，采集结束后松开。
3. **较强按**：比上一阶段更明显地按住，再点击较强按采集，结束后松开。
4. 页面显示推荐值通过检查后，点击 **保存推荐阈值**。

做完一条再处理另一条。静置不稳、样本不足、轻按与静置分不开、强按反而更低、读数饱和时，程序不会允许保存。修复安装/接线后重新采集。

## 验证是否成功

松开时不显示按压，按住时显示按压；再做几次短按和一次约 5 秒长按，核对历史中的开始、释放及持续时间。原始读数是 ADC 数值，不能当作牛顿。

## 断电后还想继续采样

检查硬件后保存 **日常模式**。两种模式的区别：

| 模式或操作 | 重启后 |
| --- | --- |
| 手动模式（新板默认） | 真实输入关闭，需要手动开启 |
| 日常模式 | 恢复已确认的真实输入 |
| 只临时关闭输入 | 不改变之前保存的重启策略 |
| 保存全部通道配置 | 回到手动模式，关闭输入和输出 |

真实电机输出不会自动恢复。取消校准或约 60 秒不操作会退出，不保存推荐值。

<details><summary>维护人员：阈值和工具参数</summary>

每路 `0 <= release_threshold < press_threshold <= 4095`；每阶段 `duration_ms=500..10000`。工具为 `capture_pressure_calibration`、`get_pressure_calibration`、`apply_pressure_calibration`、`cancel_pressure_calibration`。日常模式通过 `set_operating_mode(mode="daily", hardware_confirmed=true)` 保存，必须确实接好硬件。

</details>
