# 校准压力传感器：静置、轻按、较强按

> 按本页步骤操作即可；无需读完开发者资料。 [全部目录](../README.md)


校准的作用是让程序分清“没有按”和“已经按住”。你只需校准实际安装的通道，不用先装满八只传感器。

## 开始前先检查

打开 [固定设备设置页](WIFI_CONNECTION.md)，或电脑管理中心“通道与校准”。接 CH0 的 FSR 时选择压力、`mux_adc`、端口 0；没有安装的通道关闭。

当前0.1.0软件／0.1.0固件使用端口三态：把实际安装的端口设为“已接入”，没安装的设为“关闭”，不必开启旧版“日常模式”。能力以设备实际返回的 `per_port_v1` 为准。按住再松开，在“开发者选项”的传感器窗口核对读数应明显升高再回落，来源是 `sensor`。读数始终不变时先按 [接线指南](SENSOR_CHANNELS.md)检查，别用降低阈值来掩盖问题。

## 按顺序做三次采集

1. **静置**：选择通道，保持娃娃最终安装姿态，不碰传感器，采集约 3 秒。
2. **轻按**：持续轻按感应面，点击轻按采集，采集结束后松开。
3. **较强按**：比上一阶段更明显地按住，再点击较强按采集，结束后松开。
4. 页面显示推荐值通过检查后，点击 **保存推荐阈值**。

做完一条再处理另一条。静置不稳、样本不足、轻按与静置分不开、强按反而更低、读数饱和时，程序不会允许保存。修复安装/接线后重新采集。

## 验证是否成功

松开时不显示按压，按住时显示按压；再做几次短按和一次约 5 秒长按，核对历史中的开始、释放及持续时间。原始读数是 ADC 数值，不能当作牛顿。

## 断电后还想继续采样

新版直接保存端口状态，不显示“日常／手动”开关：

| 端口状态或操作 | 行为 |
| --- | --- |
| 已接入 | 按已存驱动真实采样，重启后恢复 |
| 关闭 | 不采样、不接收模拟输入 |
| 模拟 | 仅本端口接受模拟测试；其他已接入端口继续真实采样 |
| 只改部位名称 | 采样和阈值保持，不重写旧历史 |

全新安装仅CH0默认已接入，其他压力通道关闭。升级保留已有配置、阈值和旧的暂停策略，不会静默开启以前关闭的输入；明确保存端口状态后使用新重启策略。旧固件不支持三态时先升级，不能把软件显示的推算状态当成已同步。已接入是保存的安装确认，不能自动区分FSR松开与未插入。

真实电机输出不会自动恢复。取消校准或约60秒不操作会退出，不保存推荐值。

<details><summary>维护人员：阈值和工具参数</summary>

每路 `0 <= release_threshold < press_threshold <= 4095`；每阶段 `duration_ms=500..10000`。工具为 `capture_pressure_calibration`、`get_pressure_calibration`、`apply_pressure_calibration`、`cancel_pressure_calibration`。新版局部操作使用`set_channel_state`。旧`set_operating_mode`、全局采样接口保留兼容，不作为普通使用入口。省略端口mode的旧全量配置仍关闭输入，显式提供所有mode的新版全量配置按端口恢复；两者都不自动启用物理输出。

</details>
