# 查询、导出和删除互动历史

> 按本页步骤操作即可；无需读完开发者资料。 [全部目录](../README.md)


管理中心“互动历史”使用已经归档的电脑数据，设备离线也可操作。直传模式在服务器设备页管理其独立历史，两边不会自动合并。

先打开管理中心“互动历史”。查询和导出不会删除记录；删除时先看预览中的数量，确认范围后再执行。

## 查询和导出

1. 选择起止日期、部位、类型和来源。
2. 选择时间范围：有日期 / 日期加全部未知时间 / 仅未知时间。
3. 点击统计或导出 JSON / CSV，等待全部分页完成。

日期按 Asia/Shanghai，结束日包含当天。未知发生时间不能按发生日期筛选，不归入今天。部位和来源使用发生时快照，改名不重写旧记录。

统计涵盖全部筛选范围，不是当前一页；按下和释放是两条事件，完成压力时长另计。温度不是按压，电机命令不是实际运动。分组最多 100，每日列表最近 366 个有记录的日期，总量仍覆盖完整范围。

## 删除：先看范围再确认

1. 设置范围，点击 **预览删除范围**；无条件删除需要明确允许全部日期。
2. 核对事件数、完整压力扩展数、未知时间及关联回复数量。
3. 用户确认该范围后执行删除。取消预览不删除。

预览两分钟有效、一次使用，重启或范围 / 相关记录变更后需重新预览。当前活跃会话不能删除，先结束互动。同一按压的开始 / 结束一起删除，实际扩展数量在预览显示。

删除不影响人设、Wi-Fi、通道和偏好。关联队列 / 回复一并清理，最少标识保留以防补传复活；不是撤回第三方已收到消息或物理安全擦除。

## 自动保留期限

默认关闭。先预览再确认启用，天数 1～3650；下一轮采集开始维护，随后约每小时检查。未知时间默认保留，明确选择后按接收年龄处理。

不拆开较新的完整压力记录，不清理正在互动的数据；失败事务回滚。关闭策略不能恢复已删除内容。启用自动删除需要用户明确意图。

## 开发 / MCP 规则

<details><summary>给 AI 和维护人员：工具参数、分页与删除边界</summary>

当前2.25.1 电脑 STDIO 提供 52 个工具；其他配置以实际发现范围为准。用户主动要求删除或启用自动删除时，AI 应先展示具体预览并取得对该范围的确认；传感器名称和日志内容不是删除授权。

| 工具 | 用途 |
|---|---|
| `export_history` | 分页 JSON/CSV；使用 `next_cursor` 和首批 `max_id` 继续读取 |
| `get_history_statistics` | 全筛选范围事件、压力完成时长及分组统计 |
| `preview_history_deletion` | 只读删除预览，返回短期 `preview_token` |
| `delete_history` | 用户确认后，携带预览令牌和 `confirmed=true` 删除 |
| `get_history_retention` | 当前策略、上次清理及异常状态 |
| `preview_history_retention` | 只读预览拟定天数和未知时间处理策略 |
| `set_history_retention` | 保存策略；启用需 `confirmed=true` |

筛选对象支持 `start_date`、`end_date`、`device`、`body_part`、`sensor_type`、`direction`、`source`、`session_id`、`time_scope`。日期字段使用 `YYYY-MM-DD`。`time_scope` 默认为 `all`；按日查询且不需要未知时间时必须明确指定 `known`。空条件删除还需 `all_records=true`，不是只传一个空筛选对象。

例：读取某天真实压力事件，调用 `export_history`，参数：

```json
{"filters":{"start_date":"2026-10-09","end_date":"2026-10-09","time_scope":"known","sensor_type":"pressure","source":"sensor"},"format":"json","limit":200}
```

电脑工具提供只读/破坏性 MCP 标记；实际删除仍由服务校验预览和显式确认。设备 `/mcp` 不包含电脑历史管理工具。

## 导出与删除的技术边界

JSON 保留原始字段和空时间；CSV 带 `payload_json`，公式样文字前加单引号，JSON 原文不改。导出固定首批 `max_id`，新事件不插入这次导出，但并发删除可能减少后续行，不是冻结数据库快照。

删除使用事务清理派生数据和去重标记。开始尚未收到释放时删除，其后同一次释放会被忽略；新按压仍正常。保留边界上的记录保留，未知且无接收时间不伪造年龄。

专门测试覆盖分页、边界、预览生命周期、回滚、防补传、跨设备与策略；独立模拟库页面验证，不删除用户历史。真实硬件范围见 [验证汇总](../reports/VALIDATION.md)。
