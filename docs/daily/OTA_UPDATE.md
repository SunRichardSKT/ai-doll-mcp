# 无线升级固件

> 按本页步骤操作即可；无需读完开发者资料。 [全部目录](../README.md)


已有本项目固件并连上家庭局域网后，可升级应用；空白开发板首次仍需 [USB 烧录](../../firmware/prebuilt/README.md)。电脑文档或 GUI 更新不要求重刷设备。

准备同一版本的应用固件与清单，保持稳定供电并连接家庭局域网。空白板用 USB；本页用于已有程序的板子，不在娃娃设置热点中执行 OTA。

## 页面操作

1. 从已配对的Operit或电脑管理中心打开设备设置／维护入口。2.13.1起，新浏览器裸IP不会自动取得令牌；已开启网页登录保护时使用自己的账号密码。
2. 选择同一交付的 `firmware/prebuilt/firmware.bin` 与 `FLASH_MANIFEST.json`。
3. 核对目标版本，释放按压 / 取消校准，确认稳定供电后点击 **检查并安装固件**。
4. 等上传、校验、重启和启动确认，通常重启约 30 秒后完成。IP 改变时重新查找设备。

不要上传引导文件、分区表、文件系统或合并镜像。配网热点不开 OTA；局域网设置接口不要公开到互联网。清单为完整性校验，不是数字签名，应使用可信来源。

## 升级保留什么

- 只写入非当前运行的应用分区，保留现有分区表、NVS 网络/通道配置及 LittleFS 离线记录。电脑历史、人设和反馈偏好不随设备升级改动。
- 升级开始时停止震动并关闭输出许可；升级期间暂停触摸采样和模拟输入，不把这段空白当作传感器读数。正在按压或校准时拒绝开始升级，先释放或取消校准。端口状态及已有暂停策略保留，重启后按保存配置恢复输入，输出始终不自动恢复。
- 每次最多传输 3072 字节，严格检查偏移。上传期间临时关闭 Wi-Fi 省电，结束或取消后恢复。30 秒未收到有效分块自动取消。完整长度、SHA-256 和 SDK 镜像校验全部成功后才切换启动分区。
- 新应用启动后至少运行 30 秒、完成足够主循环且有足够空闲内存，才确认启动。确认前重启时，由启用回滚的启动程序退回上一份有效应用。这个检查验证基本启动能力，不能发现所有业务故障或保证今后任意版本兼容。
- 上传过程中取消或断线不会切换启动分区；若提交已成功，取消无法撤销。不能开机或始终无法联网时，用 USB 恢复已知可用版本，不要全片擦除。传感器配置格式的未来迁移仍需保留向后兼容；回滚应用不会自动还原已经修改的用户数据。

状态字段包括运行分区、分区容量、已接收字节、待启动确认和最近错误。不公开上传票据或私有凭据。

## 命令入口与失败处理

```powershell
.\python\python.exe tools/ota_device.py --host 192.168.1.50 --config build/device-lab/device-private.json --firmware firmware/prebuilt/firmware.bin --manifest firmware/prebuilt/FLASH_MANIFEST.json --confirm
```

替换实际 IP。工具先检查芯片、大小、SHA-256 和镜像头；写入失败不自动重发，提交响应丢失时先读版本和运行分区。不能启动或一直无法联网时用 USB 恢复已知版本，不先全片擦除。

历史正常 OTA 证据来自 [2.8.1 固件／2.16.2 软件阶段的设备报告](../reports/DEVICE_LAB_TEST_REPORT.md)，对应报告中 1056672 字节、SHA-256 以 `59359b79` 开头的旧镜像，不能沿用为新镜像验收。当前2.13.1候选镜像尚未完成本轮实体板与OTA验收；编译和清单校验也不能代替它。升级后保存了家庭Wi-Fi的设备不会自动开热点，已配对客户端按原身份恢复；需要重新配网时运行中长按BOOT约3秒。写入时物理断电和全部未来版本迁移仍未验证。见 [验证汇总](../reports/VALIDATION.md)。
