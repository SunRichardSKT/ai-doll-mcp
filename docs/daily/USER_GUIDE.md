# 日常使用：开机、记录、查询

> 按本页步骤操作即可；无需读完开发者资料。 [全部目录](../README.md)


本页对应 0.1.0 内测第一版版的电脑采集路线。完成 [首次安装](../start/AI_INSTALL.md)后，每天给娃娃供电、双击 **AI_Doll.cmd**，继续使用原来的 AI 聊天。Operit 的电脑、服务器和手机直连路线分别见 [统一指南](../integrations/OPERIT_SETUP.md)。

## 首次配网

手机连接娃娃的设备热点（默认 `AI-Doll-…`，自定义名以烧录回读为准），打开 **http://192.168.4.1/**，在“Wi-Fi 配网”选择家庭的 **2.4 GHz** 网络并保存。固件0.1.0中看到“已联网”后，热点约90秒后关闭；首次窗口最长10分钟。日常使用已配对客户端打开设置，或运行中长按BOOT约3秒重新开启热点。完整操作见 [配网教程](WIFI_CONNECTION.md)。

| 你想打开什么 | 固定入口 | 在哪台设备上打开 |
| --- | --- | --- |
| 娃娃的网络和传感器设置 | http://192.168.4.1/ | 已连接娃娃热点的手机或电脑 |
| 电脑管理中心 | http://127.0.0.1:8769/ | 运行软件的这台电脑 |
| USB 烧录页面 | http://127.0.0.1:8770/ | 双击烧录入口的这台电脑 |

`127.0.0.1` 表示“当前这台电脑”；把它输入手机，不会打开电脑上的管理中心。

## 看灯和用按钮

| 指示或操作 | 含义 |
| --- | --- |
| 快闪 | 配置热点已开启，但家庭 Wi-Fi 尚未确认连接；也可能正在连接家庭 Wi-Fi |
| 慢闪 | 配置热点未开启且家庭 Wi-Fi 尚未确认连接；不是单独的故障代码 |
| 常亮 | 已连上家庭 Wi-Fi；固定设置热点仍开启 |
| 程序运行时长按 BOOT 约 3 秒 | 暂停家庭联网，进入重新配网/恢复设置页访问 |
| 只点按 RST | 重启，保留设置 |

不要按住 BOOT 复位或上电，那会进入烧录模式。网络连接失败约 60 秒后会进入重新配网状态。正常启动会先开启配置热点，因此连接家庭 Wi-Fi 期间也可能快闪。以设置页的网络状态、实际 IP 和最近同步为准，不凭快慢闪判断烧录是否成功。板载灯测试可临时覆盖指示。

## 管理页面从哪里操作

| 页面 | 用途 |
| --- | --- |
| 设备连接 | USB / Wi-Fi 连接、找回已配对设备 |
| 通道与校准 | 传感器部位、驱动和压力校准 |
| 开发者选项 | 按需展开传感器曲线、事件、配置和连接诊断；模拟测试收在其中 |
| 人设与反馈 | 保存角色、称呼、语气和安静时段 |
| 互动历史 | 查询、统计、导出和删除预览 |
| AI / MCP 连接 | 连接原 AI、复制配置、检查隧道 |
| 维护与诊断 | 停止服务、检查环境、升级和启动项 |

## 平时记录，想看时再问

普通状态下，触摸记录进入电脑历史。对原 AI 说：

> 查询今天的互动，并按我保存的人设回答。

电脑模式需要采集服务运行；直传模式需要接收服务器运行。设备离线也能查询已经保存的历史，因此历史查得出来不代表设备现在在线。

## 怎么判断是否在线

在“运行概览”核对设备 ID、最后同步时间和错误；“设备连接”只在最近同步确认后显示可用的设备局域网 IP，过期或断线时提示尚未确认。需要确认原 AI 已接上时，让它真正调用状态工具。页面保留的旧读数不是新读数。

## 想在按压时得到回复

普通 MCP 聊天先对 AI 说“开始 60 秒互动”，等它确认会话开始，再触摸已安装的传感器。结束后恢复普通记录。具体步骤见 [聊天测试](../integrations/CHAT_MCP.md)；普通 Chat 的空闲主动唤醒没有验证。Operit 可在已绑定聊天的面板开启限时或常开陪伴，见 [Operit 指南](../integrations/OPERIT_SETUP.md)。

## 设置部位和人设

接了哪一路，才把哪一路设为“已接入”。普通改名或开关使用“保存此端口”，保留其他端口和校准。只有换驱动、接线或温度参数时才展开“硬件高级设置”；新版全量保存会结束当前动作，并按各端口明确的状态恢复输入，物理输出保持关闭。省略端口状态的旧接口仍会暂停输入，属于兼容流程。

在“人设与反馈”保存希望 AI 使用的角色、称呼和语气。设备保存网络、通道和校准；电脑保存历史、人设与反馈偏好。直传模式的数据在接收服务器。

下一步可看 [校准](CALIBRATION_AND_DAILY_MODE.md)、[历史管理](HISTORY_MANAGEMENT.md)、[登录保护](RUNTIME_AND_LOGIN.md)。找不到入口或连接失败看 [故障排查](../TROUBLESHOOTING.md)。

## 开发者选项与调试

普通使用默认连接真实主板和传感器。全新安装仅 CH0 压力端口默认“已接入”，其他压力端口“关闭”；已有设备保存的暂停策略、端口和校准不会被覆盖。只启用实际安装的通道，电机输出始终需要单独开启。

在电脑管理中心“开发者选项”，或设备设置页底部展开“开发者选项 · 模拟与调试”：

| 窗口 | 用途 |
| --- | --- |
| 传感器读数与模拟测试 | 真实/模拟来源、有效质量、原始值、曲线及模拟按钮 |
| 事件记录 | 查看最近事件，不确认或消费聊天记录 |
| 当前配置与校准 | 读取通道、工作模式和校准进度 |
| 设备连接诊断 | 读取设备版本、网络和运行状态 |

仅展开的窗口刷新；收起或离开页面后停止调试请求。诊断读取不修改配置；模拟和输出按钮会发送测试命令。模拟按钮只接受状态为“模拟”的输入端口。“关闭”或“已接入”端口不能直接注入模拟值；需要时按 [模拟测试分支](../integrations/CHAT_MCP.md#可选没有传感器时做模拟测试)记录并调整一个端口，结束后恢复其原状态。模拟结果不能代替真实硬件测试。正常校准与端口状态仍在“通道与校准”。
