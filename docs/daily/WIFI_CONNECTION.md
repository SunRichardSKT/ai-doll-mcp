# 配网、配对与找回设备

先让娃娃连上家庭 Wi-Fi，再让手机或电脑识别这台娃娃。配网使用临时热点，日常操作使用家庭网络。[教程目录](../README.md)

当前0.1.3版：Operit 用户从“连接娃娃”进入三步向导，网页联网后先点上方“返回向导并检查联网”，保存地址后再切网络。[手机完整步骤](../integrations/OPERIT_NO_PC.md)

## 一、独立浏览器给娃娃配网

1. 给娃娃供电。首次开机提供设备热点；已配过网时，在程序运行中长按 **BOOT 约 3 秒**并松开，保持 RST 不动。
2. 手机连接热点，名称以烧录回读为准，默认 `AI-Doll-…`。提示“没有互联网”时选择保持连接。
3. 在浏览器打开 **http://192.168.4.1/setup**。
4. 扫描并选择家庭 **2.4 GHz Wi-Fi**，填写路由器密码，点击“保存并连接”。隐藏网络可以手动填写。
5. 等待显示“已联网”和家庭 IP，保存页面提供的完整设备入口，再到系统设置切回家庭网络。

扫描和连接期间页面显示等待提示，超过 30 秒可查看排查建议或点击“检查连接状态”。“已联网”表示连接确认完成。

首次热点最长开放 **10 分钟**，新配网成功后约 **90 秒**关闭。已保存家庭 Wi-Fi 的设备日常重启连接家庭网络，断线后持续重连。需要维护时再长按 BOOT 开启热点。

家庭网络中，从已配对的 Operit 或电脑管理中心打开“设备设置”，使用当前 IP 和配对入口。`192.168.4.1` 在连接娃娃热点时使用。入口链接含凭据，保存在自己的设备上。

### 热点密码

设备网页可提前关闭热点，也可设置独立热点密码（8～63 字节，下次开启生效）。手机连接热点时填写它；网页账号和路由器 Wi-Fi 分别使用各自密码。忘记热点密码可通过 USB 重设，长按 BOOT 会保留密码。

## 二、电脑与娃娃配对

电脑连接与娃娃互通的家庭网络，在管理中心“设备连接”操作：

1. 用 USB 数据线连接娃娃，选择当前串口。
2. 点击“连接开发板，检查联网”。未联网时在 USB 页填写 Wi-Fi，等待连接成功后点击“已联网，自动配对 Wi-Fi”；已联网则自动跳过填写。
3. 核对设备 ID、Wi-Fi 连接状态和最近同步时间。成功后可拔掉数据连接，改用独立供电。

手动配对在“高级”内，从设备页复制实际 IP 和 MCP 令牌，在管理中心验证并保存。

外部供电使用 **5V／GND**，按板型接 J9：

| 主板 | J9 针序 |
| --- | --- |
| 第一代最终锁扣板，PA2.0 3P | 1=GND、2=NC、3=5V |
| 旧两针板 | 1=GND、2=5V |

主板电源口接充放模块的 5V 输出，电池接模块 B+/B−。[主板与接线资料](../../hardware/rev-v2/README.md)

## 找回已配对设备

设备家庭 IP 改变后，电脑采集器自动验证原设备并更新地址；也可在管理中心点击“查找已配对设备”。先确认设备供电、网络互通以及路由器客户端隔离设置。

电脑先尝试上次地址，再通过局域网发现验证已配对身份。已保存的 USB 连接失效时，可以恢复到已配对且验证通过的 Wi-Fi 设备。离线重试从 2 秒逐步延长至 30 秒，恢复后回到正常采集频率；手动“查找”可立即重试。

同一身份换地址保留历史与配对。重新 USB 烧录产生新内部编号后，重新识别并配对。配置写入和事件确认按原操作结果处理。

## 切回 USB

在“设备连接”选择 USB 和当前串口，保存并核对状态。电脑 USB 与 Wi-Fi 采集使用同一历史库。

维护时可用 `DOLL_TRANSPORT=usb` 或 `DOLL_SERIAL_PORT` 为当前运行实例固定 USB。

## 登录恢复日常服务

在“维护与诊断”开启当前用户登录后启动，可恢复采集、已配置的 Secure 隧道及 Operit 服务；互动按用户选择开启。移动安装目录前关闭旧启动项，移动后重新开启。

## 常见情况

| 现象 | 处理 |
| --- | --- |
| 手机跳回其他网络 | 选择保持连接娃娃热点，必要时暂时关闭自动切网 |
| 找不到家庭 Wi-Fi | 确认提供 2.4 GHz；隐藏网络手动填写 |
| 家庭 Wi-Fi 下打不开 192.168.4.1 | 从已配对客户端打开当前设备设置，或重连娃娃热点 |
| 切回家庭网络后原页面失联 | 打开已保存的家庭入口，或在客户端检查设备状态 |
| 页面返回 401／403 | 使用配对入口，或按页面要求登录 |
| 无线配对失败 | 检查设备身份和网络互通，必要时先用 USB 核对 |
| 再次烧录后旧配对失效 | 使用本次新内部编号重新配对 |

## Operit 单手机配对与恢复

在“添加娃娃”向导读取热点草稿，配置家庭 Wi-Fi，切回家庭网络后核对并保存。设备页也可下载连接 JSON、复制连接码或临时显示二维码。[完整步骤](../integrations/OPERIT_NO_PC.md#只有安卓手机没有电脑和服务器)

手机优先尝试上次地址与固定 `.local` 名称；解析失败时用“从设备热点重新获取地址”。身份相同保留绑定和历史，重新烧录后重新配对。“停止后台任务”结束手机的自动恢复。

## iPhone 配网

1. 长按 BOOT 打开临时热点，热点开放时蓝灯快闪。
2. 手机连上热点后，在 Safari 打开 `http://192.168.4.1/setup`；系统弹出的配网向导也可使用。
3. 保存设备入口，选择家庭 2.4 GHz Wi-Fi 并填写密码。
4. 等页面显示家庭 IP，在 iPhone 系统设置中切回家庭网络，再打开保存的入口。固定名称解析失败时使用备用家庭 IP 链接。
5. 需要调整传感器时，进入“更多设备设置”。

简洁配网页由固件 `network_revision=2` 提供。Wi-Fi 切换在手机系统中完成，页面保留上次确认状态和设备入口。[网络恢复与空间说明](../reports/FIRMWARE_NETWORK.md) · [Wi-Fi 提示](../reports/WIFI_FEEDBACK.md)
