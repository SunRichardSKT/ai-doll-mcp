# 配家庭 Wi-Fi，并让电脑无线连接

> 按本页步骤操作即可；无需读完开发者资料。 [全部目录](../README.md)


先给娃娃供电。第一次用的新板还没有家庭 Wi-Fi；已配过网时，运行中长按BOOT约3秒再松开（不按RST），开启临时热点后修改。

## 一、手机给娃娃配网

1. 打开手机 Wi-Fi 列表，连接烧录成功页显示的设备热点；默认名为 **AI-Doll-…**，自定义名称以实际回读为准。
2. 如果提示没有互联网，选择保持连接。
3. 在浏览器地址栏输入 **http://192.168.4.1/**。
4. 在“Wi-Fi 配网”点击扫描，选择家庭的 **2.4 GHz** 网络。
5. 填写家庭 Wi-Fi 密码，点击 **保存并连接**。不是填写娃娃网页的登录密码。
6. 等页面显示“已联网”和实际家庭 IP；正常指示为常亮。连接期间也可能快闪，不能只凭快慢闪判断失败。

![实际设备配置页面；个人网络及密钥区域已遮挡](../images/device-configuration.png)

**固件2.13.1起，首次热点最多开放10分钟，新配网成功后约90秒关闭。** 已保存家庭Wi-Fi的日常重启只连接家庭网络；断网持续重连，不自动开热点。需要重新配网时，运行中长按BOOT约3秒，再连接娃娃热点打开 http://192.168.4.1/。网页可提前关闭热点，也可设置独立的可选热点密码（8～63字节，下次开启生效）。忘记热点密码可通过USB重设，长按BOOT不清除该密码。

在家庭Wi-Fi中，从已配对的Operit或电脑管理中心打开“设备设置”；链接携带本次浏览器会话所需的配对凭据。直接输入裸IP的新浏览器不自动取得令牌，开启网页登录保护时也可登录。该IP可能变化。`192.168.4.1` 只有连接娃娃热点时才能使用，不是家庭局域网中的固定 IP。

## 二、电脑与娃娃配对

电脑连接与娃娃可互通的家庭网络。在管理中心“设备连接”：

1. 用 USB 数据线把娃娃接到电脑，填写实际串口。
2. 点击 **一键识别并配对 Wi-Fi**。
3. 看到配对成功、连接方式 Wi-Fi、同步时间更新后，可拔掉 USB 数据连接。

也能在设备页复制实际 IP 和 MCP 令牌，到管理中心手动验证并保存。令牌只在自己的设备和电脑之间使用。

拔掉 USB 后仍要供电。主板外部供电用 5V / GND，J9 的 1 脚为 GND、2 脚为外部 5V；主板没有充电、升压或电池保护电路。板外电池模块按 [接线指南](SENSOR_CHANNELS.md)处理。

## 找回已配对设备

设备换了家庭 IP 时，采集器会自动查找并验证原设备，再保存新地址。使用已保存的 Wi-Fi 连接启动时，也会先搜索再发送首次状态请求，减少等待旧地址超时。也可在管理中心点击“查找已配对设备”。先确认供电和同一可互通局域网；访客网和客户端隔离可能阻止发现。

搜索先向上次地址发送不含密钥的新挑战，无回应时再同时向各局域网接口广播。Windows 优先直接读取系统网卡表，短时缓存网卡信息，减少多网卡和慢命令启动造成的等待；没有对整个网段逐个 IP 扫描。

保存的 USB 连接失效时，若本机已经配对过这台设备，状态读取可自动恢复到验证通过的 Wi-Fi 设备，无须重新填写 IP 或令牌。必须同时通过签名与实际设备身份校验；设备离线时保留原连接与历史，不自动首次配对或连接陌生设备。

离线重试从 2 秒逐步延长，最长 30 秒；点“查找”可主动重试。正常恢复后回到原采集频率。配置写入、输出和事件确认不会因为断线自动补发。

查找只识别已经配对的设备。**再次 USB 烧录后名称变了，需要重新识别/配对**，这不是普通 IP 变化。

## 切回 USB

在“设备连接”选择 USB 与当前串口，保存后检查设备状态。USB 与 Wi-Fi 电脑采集使用同一个历史库。Wi-Fi 失败不会自动改为 USB。

维护时若需要严格固定 USB，可用环境变量 `DOLL_TRANSPORT=usb` 或明确设置 `DOLL_SERIAL_PORT`；该运行实例不会自动切到 Wi-Fi。

## 登录恢复日常服务

默认不开启。需要时在“维护与诊断”设置当前用户登录后启动；这会恢复本项目采集、已配置的 Secure 隧道与已启用 Operit 服务，互动会话仍由用户开启。移动软件目录前关闭旧启动项，移动后再开启。

## 常见情况

| 现象 | 处理 |
| --- | --- |
| 手机总是跳回其他网络 | 选择保持连接娃娃热点，必要时暂时关闭自动切换 |
| 找不到家庭 Wi-Fi | 确认路由器提供 2.4 GHz，隐藏网络手动填写 |
| 配网完成但不知设置地址 | 从已配对客户端打开设置，或长按BOOT约3秒再连临时热点打开192.168.4.1 |
| 电脑无线配对失败 | 检查电脑和娃娃网络是否互通；先用 USB 验证 |
| 再次烧录后旧配对失败 | 新的内部编号是预期行为，用 USB 重新识别 |

## Operit 2.25候选：单手机配对与恢复

在“添加娃娃”向导连接设备热点，读取配对草稿；打开固定页配置家庭Wi-Fi，等待取得实际家庭IP，再切回家庭网络核对并保存。不必在设备上贴二维码，也不必手填聊天ID；设备页可临时生成二维码、下载JSON或复制连接码。[完整步骤](../integrations/OPERIT_NO_PC.md#只有安卓手机没有电脑和服务器)。

同一安装身份换IP时保留绑定和历史，优先上次地址与固定名称；`.local`解析失败可从设备热点重新获取地址。新SSID或密码仍由用户重新填写；不跨访客隔离网络或公网搜索。后台恢复有退避，“停止后台任务”后不自动重启。

USB重刷后的安装身份可能变化，必须重新配对；固定硬件名称不能替代安装身份。候选二维码和恢复代码检查不能冒充当前手机与路由器实际通过。
