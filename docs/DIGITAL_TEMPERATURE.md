# DS18B20 数字温度探头

当前固件支持多个 DS18B20 共用 GPIO1，每个逻辑通道绑定一个探头地址和部位。压力、NTC 和震动通道仍可同时配置，总计最多 16 个逻辑通道；现有 PCB 的 74HC4051 仍为八路模拟输入。

## 接线

使用三线、外部供电方式：探头 VDD 接 3V3，GND 接公共地，DQ 接 SuperMini GPIO1；DQ 与 3V3 之间接一个 4.7kΩ 上拉电阻。多个探头共用数据线和上拉，按实际探头资料确认线序。数字探头接模块引脚，不接 FSR 接口；DQ 不接 5V。当前驱动不支持寄生供电。接线与转换要求依据 [DS18B20 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/DS18B20.pdf)。

GPIO1 不能同时用于 `gpio_adc`。原八路压力使用 GPIO0 和 4051，不占用 GPIO1。多个 DS18B20 可以共享 GPIO1，但地址必须不同。逻辑通道数量不等于任意线长、探头数量都已通过电气验证。

## 页面设置

1. 关闭真实输入；如果已有 GPIO1 ADC 通道，先移除该绑定并保存。
2. 在设备设置页或电脑 `/companion` 页面添加温度通道，选择“DS18B20 数字温度”，GPIO 为 1。
3. 点击“扫描数字温度探头”，从列表选择地址，填写部位名称。扫描不会自动启用采样，也不会自动保存配置。
4. 点击“保存全部通道配置”，确认希望保留的压力通道仍在列表中。
5. 检查接线后启用真实输入。需要重启后自动采样时，确认硬件并保存日常模式。

地址为按总线字节顺序显示的 16 位十六进制 ROM，包含型号与 CRC。不要复制测试地址代替实际扫描结果；更换探头后需要重新绑定。

## MCP 配置

调用 `scan_input_devices(driver="ds18b20", gpio=1)`，从返回的 `devices` 读取实际地址。扫描仅在真实输入关闭时允许，已有 GPIO1 ADC 绑定也会拒绝；无探头返回 `quality=no_device_found`，不会返回温度。

先调用 `get_channel_config`，在完整通道列表中追加或修改温度通道，再调用 `set_channel_config`。以下地址字段必须替换为实际扫描值：

```json
{
  "channel": 8,
  "name": "腹部温度",
  "type": "temperature",
  "driver": "ds18b20",
  "gpio": 1,
  "rom": "替换为16位实际地址",
  "enabled": true,
  "options": {
    "model": "ds18b20",
    "offset_c": 0,
    "sample_ms": 1000,
    "report_ms": 30000
  }
}
```

采样间隔至少 1000ms，报告间隔不小于采样间隔，偏移范围为 −30～30℃。数字驱动不使用 NTC 电阻、Beta 或毫伏换算参数。模拟测试可使用摄氏度 −55～125℃，来源仍为 `simulation`，不代表读取过探头。

## 数值与故障

转换采用分阶段调度，等待至少 750ms 后读回，不用连续阻塞等待整段转换。多个地址分别启动转换、校验 ROM 和读数 CRC。正常读数单位为 `degC`；断线、CRC 错误、寄生供电、无效配置或越界会产生故障状态和空值，不能解释为 0℃。

探头上电默认值 85℃与实际 85℃无法仅凭该数值区分。当前驱动保守地将 85℃标记为 `power_on_or_85c`，不会报告为有效温度；如应用必须测量恰好 85℃，需要进一步完善此判定。

关闭输入、改变配置或重启会取消尚未完成的转换。查看 `read_channel_values` 和温度历史时同时检查 `valid`、`quality`、`source`；不能复用故障前的温度冒充新读数。

原生算法、页面扫描选择、MCP 配置验证、无探头提示及重启保存已经测试。当前开发板没有探头，真实温度精度、线长、多探头电气时序和安装热传导仍需接线验收。
