# 抱抱星｜一代产品资料

按成品用户的上手顺序制作，视觉采用奶白、浅蓝、粉色与星星元素。说明书对应配套内测0.1.3软件。

- [产品介绍 PDF](抱抱星_共感娃娃核心_产品介绍.pdf)：2页A5，适合向新用户介绍功能。
- [新手说明书 PDF](抱抱星_共感娃娃核心_新手说明书.pdf)：6页A5，可在手机查看或打印随产品发出。
- [产品介绍文字稿](产品介绍.md)、[新手说明书文字稿](新手说明书.md)：便于复制和修改。
- [外壳主图](assets/core-hero.png)、[外壳正视图](assets/core-front.png)：根据用户实物照片美化的效果图。说明书采用渲染外壳图，并配主控按键定位示意；[原始主板照片](assets/board-reference.jpg)保留作结构参考。

## 更新资料

编辑 [content.json](content.json)，在项目根目录安装本目录开发依赖，运行 `tools/build_product_materials.py` 重新生成PDF和文字稿。渲染使用Windows微软雅黑字体；重新生成后逐页检查版面。依赖仅用于制作产品资料，不属于设备或聊天服务运行依赖。

本代以触摸输入、记录和AI连接为主。温度、湿润感应占用现有输入口；DeepSeek 使用官方 DSH 接入；Gemini 可选官方网页或 CLI，按账号支持的入口连接。具体步骤见[平台选择](../integrations/OFFICIAL_CLIENTS.md)。

外壳图由内置图像工具生成；提示词与素材用途见[图片说明](assets/IMAGE_NOTES.md)。
