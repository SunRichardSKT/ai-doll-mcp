# 抱抱星共感娃娃核心｜新手说明书

配套软件 内测0.1.3版。面向已装好的成品；配套文件与界面版本保持一致。

## 1. 第一次使用，从这里开始

成品核心的新手指南

准备：已烧录的核心、至少一只压力传感器、供电线或已接好的电池，以及2.4 GHz家庭 Wi-Fi。

1. **接好设备**：断电时插好传感器，再开机。
2. **连接网络**：安卓手机用 Operit 向导；电脑可直接用 USB 配网。
3. **选择 AI**：按你使用的应用完成连接，再试一次按压。

裸板需先完成焊接与烧录。拿到已装好的成品可直接按本指南使用；界面步骤对应随附0.1.3安装包。

## 2. 先认清插口，再通电

传感器、开关与充电口各有用途

1. **传感器口**：J1～J8：PA2.0两针锁扣口。J1对应CH0，后面依次类推。
2. **电源开关**：拨到ON开机，拨回OFF关机。
3. **主控 USB-C**：用于电脑供电、烧录与调试，不给电池充电。
4. **BOOT 按钮**：主控上标有BOOT的小按钮。正常运行时长按约3秒并松开，可重开配网热点。

电池接独立充放电模块，模块输出接核心。充电时，将USB线插到独立充电模块的Type-C口。成品用户保持原线束连接即可。

插拔传感器前关机；捏住插头并按锁扣，别拉线。保持电池与焊脚绝缘，发现破损、鼓包或异常发热时停止使用。

## 3. 让娃娃连上家庭 Wi-Fi

安卓 Operit：跟着三步向导走

1. **连接娃娃热点**：在Operit包管理导入随包的AI_Doll_Operit.toolpkg，从工具箱打开AI Doll，点“连接娃娃”。到手机系统Wi-Fi连接设备热点，再点“已连接热点，读取设备”。
2. **配置家庭网络**：点“打开家庭 Wi-Fi 配网页”，选择2.4 GHz网络并输入密码。设备联网后，点上方“返回向导并检查联网”，先保存地址。
3. **切回家庭网络**：到手机系统设置切回家庭Wi-Fi，再点“检查并完成连接”。已经联网的娃娃会跳过填写密码。

配网页里先别切网；先返回向导保存地址。退出后可点“继续上次设置”，草稿15分钟内有效。

iPhone或独立浏览器：连接娃娃热点后打开 http://192.168.4.1/setup，选择家庭Wi-Fi；保存页面的设备入口，再切回家庭网络。iPhone查看配网页不需要安装Operit。

首次热点最长10分钟，新配网成功约90秒后关闭。需要重开时，在正常运行中长按BOOT约3秒；不要同时按RST。

## 4. 选你正在使用的 AI

电脑打开 AI_Doll.cmd，按应用选择

先用USB连接开发板，选实际串口，点“连接开发板，检查联网”。未联网时填写Wi-Fi；联网后自动配对，再进入“选择 AI 接入方式”。

1. **Operit · 安卓手机**：手机直连：按上一页向导完成后，选择聊天并开启触摸回复。电脑采集：启动手机连接服务，导入工具包和电脑生成的连接文件。
2. **Claude Desktop · 本机**：选择“Claude 桌面版 · 本机连接”，点“写入 Claude 桌面版配置”。完全退出并重开Claude，在聊天中启用AI Doll。其他已有服务保留。
3. **ChatGPT · 电脑私有隧道**：按管理中心链接创建隧道，保存并启动。到ChatGPT Plugins添加自定义MCP，选择同一隧道；创建后安装，在聊天中启用。
4. **Claude网页／手机、ChatGPT HTTPS**：已有公网HTTPS服务器时，在其设备卡片复制完整MCP地址，再在官方连接器中添加。Claude远程连接需HTTPS 443，不能填设备内网IP。

DeepSeek模型可通过支持MCP的客户端使用；目前未确认其官方网页／手机应用的自定义MCP入口。详细步骤见文末的完整教程。

## 5. 试一下，让触摸有回应

先确认记录，再开启互动

1. **设置真实接入的部位**：在“身体与传感器”或设备设置中，将实际插上的接口设为“已接入”，写上对应部位。空接口设为关闭。
2. **轻按一次，确认有记录**：按住传感器约1秒再松开，查看历史。太灵敏或不容易触发时，按设备页提示重新做压力校准。
3. **开启你想要的互动**：Operit先选择聊天，再开启“触摸主动回复”，可选限时或常开。ChatGPT、Claude在聊天中开始一次限时互动，并实际调用工具读取新触摸。

自动同步记录和主动回复是两个开关。只想留记录时，关掉主动回复即可；“停止后台任务”会一起停止同步与续接。

AI思考时可以继续按压，记录会保存。Operit会合并后续触摸；“触摸合并与等待”可设置松开后等多久再回应。

设备离线暂存最多256条事件，按下和松开分别计数；重连后补传仍保留的记录。长期无人值守记录可使用服务器。

## 6. 遇到问题，先看这里

大多数连接问题可以按这几步处理

1. **找不到娃娃热点？**：确认已开机，在正常运行中长按BOOT约3秒并松开。必要时取下上盖找到按钮；不要同时按RST。
2. **192.168.4.1 打不开？**：先确认手机连接的是娃娃热点。已切回家庭Wi-Fi时，从配对好的客户端打开设备设置，别再用热点地址。
3. **一直连不上家庭Wi-Fi？**：确认是2.4 GHz网络、名称和密码正确。提示热点没有互联网时选择继续连接，靠近路由器后再试。
4. **按了却没有回应？**：先看是否有真实记录，再检查端口状态和校准。Operit还需选好聊天并开启主动回复；官方MCP聊天需启用连接并开始互动。
5. **重启后设备IP变了？**：客户端会尝试原地址和固定名称。未恢复时，用“找回设备”重开热点读取；同设备的历史和绑定保留。

先从一个传感器开始，确认有记录、有回应，再把其他部位逐个接上。
