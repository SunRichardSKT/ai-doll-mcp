# 开箱运行与设备登录设置

更新：2026-10-11。Windows 软件包 v2.16.2，设备固件 v2.8.1。

## Windows 完整包

完整解压软件包，保留根目录 `python/` 和 `tools/`，双击 `AI_Doll.cmd`。包内提供 Windows x64 Python 3.14.8、MCP SDK、串口与网络依赖，不需要安装系统 Python，不需要配置 PATH，也不需要首次联网下载 Python 依赖。

“准备 / 修复运行环境”会检查内置依赖并生成本机 MCP 客户端配置。若提示运行环境不完整，重新完整解压软件包；不要复制其他电脑的 `.venv`。Secure MCP 的官方隧道客户端仍需在首次配置时下载，联网配对与远程隧道也需要网络。

个人配置与数据库保存在本机 `build/device-lab/`。软件解压在固定可写目录后再配对；移动已安装目录后重新生成客户端配置。更新代码时保留旧目录中的个人配置，不要用旧 Python 文件夹混合覆盖新运行环境。

官方 CPython 来源与校验信息在 [运行环境说明](../python/README.md) 和 `python/RUNTIME.json`；依赖固定版本、wheel SHA-256 在 `requirements-windows-runtime.lock`。GitHub 源码目录只保留运行环境说明与校验信息，完整二进制在交付 ZIP 内。固件源码编译工具不属于日常运行依赖，仍需开发者另外配置。

## 联网后的设备设置页

打开设备局域网 IP，例如 `http://192.168.1.50/`，**默认无需账号密码**。旧版固件升级到 2.8.1 后同样默认关闭保护；如果之前已在新固件开启保护，后续升级和重启会保留选择。

在“设置页登录保护”选择是否要求登录：

1. **开启**：勾选开关，填写账号和自行设定的密码，保存后重新登录。账号为 1～32 个字母、数字、下划线或短横线；密码为 8～64 字节。已有密码时留空可保留。
2. **关闭**：登录后取消勾选并保存。随后访问设备设置页不再要求登录。
3. **忘记密码**：长按 BOOT 约 3 秒进入配网热点，连接 `AI-Doll-xxxxxx`，打开 `http://192.168.4.1/`，关闭保护或重设密码。RST 仅重启，不清除已保存的设置。

该开关只管理设备网页；不改变 Wi-Fi 密码、MCP 配对令牌或服务器连接令牌。电脑端修改网络和无线升级，在保护关闭时无需管理密码；保护开启时在管理中心“设备连接”保存相同账号密码。MCP 设备接口继续使用已有配对令牌。

配网热点始终免登录；无线升级仅在已连接家庭局域网时开放，保留来源检查、设置令牌、芯片型号、镜像大小与 SHA-256 校验。设备设置页继续只供家庭局域网使用。
