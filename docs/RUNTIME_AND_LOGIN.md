# 运行环境与账号密码

## 需要安装 Python 吗

Windows **完整交付包**自带 x64 Python 3.14.8 与固定依赖。完整解压后双击 `AI_Doll.cmd` 或 `AI_Doll_Server.cmd`，不用安装系统 Python 或配置 PATH。

GitHub 源码 ZIP 只包含运行环境说明，不含这些二进制。提示缺少 Python 时先确认下载的是完整交付包，保留 `python/` 与 `tools/`，不要搬用别人的 `.venv`。来源、许可和校验见 [Python 说明](../python/README.md)。

Secure 官方客户端首次需要联网下载；远程 Linux 部署使用 Docker 内的 Python，不需要上传 Windows Python。源码编译另见 [开发指南](DEVELOPER_GUIDE.md)。

## 设备网页的账号从哪里来

**默认没有账号密码，也不要求登录。** 在设备页“设置页登录保护”开启后，由你自己设定：

1. 开启开关，填写账号与密码，保存后重新登录。
2. 账号为 1～32 个字母、数字、下划线或短横线；密码为 8～64 字节。已有密码时留空保留。
3. 关闭开关并保存，即恢复免登录。

忘记密码时，设备运行中长按 BOOT 约 3 秒，连接无密码配网热点，打开 `http://192.168.4.1/`，重新设置或关闭保护。RST 仅重启，不清空配置。

开启保护后，在管理中心保存相同账号密码，供网络修改和 OTA 使用。关闭保护时不需要管理密码。已开启的保护会在重启和后续升级中保留。

## 几种密码 / 令牌分别做什么

| 信息 | 用途 | 如何取得 |
| --- | --- | --- |
| Wi-Fi 密码 | 连接家庭网络 | 你自己的路由器 / 热点密码 |
| 设备网页账号密码 | 可选的设置页保护 | 你自行开启并设定 |
| 设备 MCP 令牌 | 电脑与设备配对 | 设备设置页或 USB 一次识别 |
| Secure 运行 API 密钥 | 官方隧道运行 | 按 [Secure 指南](SECURE_MCP.md)创建 |
| 直传设备令牌 | ESP32 上传给服务器 | 服务器生成设备配置 |
| 服务器管理连接 | 管理直传服务 | 安装完成链接或 `ai-doll-server link` |

这些信息不能互相替代。MCP 使用原聊天模型，不要求再填模型密钥。

电脑配置和历史在 `build/device-lab/`，本机直传数据在 `build/direct-server/`。更新保留自己的数据目录；移动软件后重新生成绝对路径配置。公共包不含个人配置。
