# Operit：服务器或仅安卓手机使用

手机可以直接采集娃娃的触摸，也可以从自己的服务器读取记录。两条路线使用同一个 [AI_Doll_Operit.toolpkg](https://github.com/SunRichardSKT/ai-doll-mcp/releases/download/v0.1.2/AI_Doll_Operit.toolpkg)。

本页配对流程适用于公开下载的 **v0.1.2 内测版**。温度与擦眼泪使用配套 0.1.2 软件、Operit 和固件，见[制作指南](../../hardware/expansion/resistive-inputs/README.md)。

| 用法 | 使用时保持运行 | 历史保存位置 | 手机网络 |
| --- | --- | --- | --- |
| 安卓手机直连 | 娃娃、Operit 记录任务 | 手机插件目录 | 与娃娃局域网互通 |
| 服务器直传 | 娃娃、服务器；回复时运行 Operit | 服务器 SQLite | 可访问自己的服务器 |
| 电脑采集 | 娃娃、电脑采集服务、Operit | 电脑 SQLite | 可访问电脑的局域网地址 |

## 只有安卓手机没有电脑和服务器

准备已烧录、已供电的娃娃和能正常聊天的 Operit。空白开发板先用电脑[烧录](../start/QUICK_FLASH.md)。

1. 在 Operit 包管理导入 `.toolpkg`，打开工具箱中的“AI Doll · 连接与互动”，点击“添加娃娃”。
2. 到系统 Wi-Fi 连接娃娃热点，回到向导点击“读取热点设备”。此时保存配对草稿。
3. 打开 `http://192.168.4.1/setup`，选择家庭 **2.4 GHz Wi-Fi** 并填写密码。等页面显示家庭 IP，再回到向导读取最新地址。已配好网可跳过填写。
4. 在手机系统中切回家庭网络，点击“已切回家庭 Wi-Fi，完成配对”。身份和认证核对成功后保存连接。
5. 要收到触摸回复，按标题选择已有聊天，确认绑定，再开启“触摸主动回复”。要先记录历史，保持默认开启的“自动同步记录”即可。

正常流程自动读取 IP 和令牌，按标题选择聊天。`192.168.4.1` 在连接娃娃热点时使用；家庭网络内从已配对的 Operit 打开设备设置。手机与娃娃可在不同 Wi-Fi 频段，路由器需允许它们互通。

热点读取失败时，在设备设置页“获取手机连接”下载 JSON 后导入，或复制连接码。开启登录保护的设备先按页面提示登录。

## 二维码不需要贴在设备上

设备设置页和服务器管理页可以临时显示连接二维码：另一块屏幕上的二维码用“拍照读取”，保存在本手机的图片用“从相册选择”。也可直接导入连接文件或粘贴连接码。

二维码生成与图片解码在本机完成。相机或相册入口受当前 Operit、WebView 和系统权限支持情况影响；无法返回识别结果时改用文件导入。

## IP变化与重新配网

设备重启或 DHCP 换地址后，插件优先尝试上次地址和固定 `.local` 名称，核对原安装身份后更新 IP，保留聊天、历史和回执。名称解析失败时，在“设备与连接”选择“从设备热点重新获取地址”。

更换路由器、SSID 或密码时，运行中长按 BOOT 约 3 秒并松开，连接热点重新配网。USB 重新烧录产生新的安装身份，需要重新配对；原历史继续保留。

## 历史同步与离线补传

“自动同步记录”与“触摸主动回复”独立：关闭回复可以继续记录；“停止后台任务”同时停止采集和自动续接。恢复时重新开启同步，或点击“立即同步记录”。

采集优先读取实时事件，再分批补传设备 Flash 中的旧记录。手机将归档写入并读回校验后才确认设备进度；补传按设备和事件身份去重，只进入历史。发生时间未知的记录在独立入口查看。

同一设备由一个主归档端确认进度。切换手机、电脑或服务器时，先停止原归档端，或等待 90 秒租约到期。旧固件使用兼容复制模式，保留设备缓存；完整分页补传需要具备租约能力的配套固件。

设备最多缓存 **256 条事件**，按下和释放分别计数，满后覆盖最早记录。手机任务停止期间依靠这份缓存；恢复后补传仍保留的事件。长期无人值守归档可使用服务器。[缓存与时间说明](../daily/OFFLINE_RECORDS.md)

## 有自己的服务器

1. 按[服务器部署教程](REMOTE_SERVER_SETUP.md)安装同批次 Linux 包；升级保留原数据卷。
2. 在管理页生成设备上传配置，写入 ESP32 设置页的“直连服务器”。等管理页收到实际上传。
3. 在设备卡片点击“连接 Operit：文件、连接码或二维码”，将这份**手机连接**导入 Operit。
4. 核对服务器身份后选择聊天，再开启触摸回复。

服务器需提供手机可达的 `interaction` MCP 接口。家庭设备 IP 变化由服务器路线处理；更换服务器域名后重新导入连接。同一设备使用服务器归档时，手机通过服务器读取，避免另开直连归档任务。

设备上传配置、手机连接和管理链接分别用于上传、聊天接入和管理。手机关闭后，服务器继续归档；Operit 聊天回复需要手机任务运行。

## 设置能力与离线边界

| 设置 | 手机直连 | 电脑／服务器 |
| --- | --- | --- |
| 部位名称、关闭／模拟／已接入 | 在线修改并保存到设备 | 在线修改并保存到设备 |
| 部位别名、轻回应、互动提示、安静时段 | 在电脑／服务器设置 | 保存到当前服务数据库 |
| 人设来源、全局触摸回复 | 保存到手机插件目录 | 使用相应服务与客户端设置 |
| 已归档历史 | 手机离线可查 | 服务可达时可查 |

端口改名和开关保留原校准。常开陪伴需要 Android 允许 Operit 后台运行；遇到停顿先检查任务状态和省电设置。结果待核对的发送，到原聊天确认后再恢复。

## 临时配网热点（固件0.1.1）

首次热点最长开放 10 分钟，新配网成功后约 90 秒关闭。日常重启连接家庭 Wi-Fi，断网后持续重连。需要维护时，在运行中长按 BOOT 约 3 秒再松开，保持 RST 不动。

配置热点密码后，在手机系统 Wi-Fi 中填写该密码；网页登录使用另一个密码。配网完成后及时切回家庭网络。具体步骤见[配网与恢复](../daily/WIFI_CONNECTION.md)，日常设置见[Operit 完整指南](OPERIT_SETUP.md)。
