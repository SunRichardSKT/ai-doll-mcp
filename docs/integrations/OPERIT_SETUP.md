# Operit：连接、记录与触摸回复

完成配对后，可以查看互动历史、选择聊天并开启触摸回复。手机直连、电脑采集和服务器使用同一个工具包。

公开下载使用 [v0.1.2 AI_Doll_Operit.toolpkg](https://github.com/SunRichardSKT/ai-doll-mcp/releases/download/v0.1.2/AI_Doll_Operit.toolpkg)。0.1.2 增加温度与擦眼泪，需配套软件和固件，见[扩展指南](../../hardware/expansion/resistive-inputs/README.md)。

| --- | --- |

## 只有安卓手机：首次配对

准备已烧录、已供电的娃娃，以及能正常聊天的 Operit：

1. 在包管理导入 `.toolpkg`，打开工具箱中的“AI Doll · 连接与互动”。
2. 点击“添加娃娃”，到系统 Wi-Fi 连接娃娃热点，回到向导点击“读取热点设备”。
3. 点击“打开热点设置，配置家庭 Wi-Fi”，填写家庭 **2.4 GHz Wi-Fi**。等页面显示家庭 IP，再回向导读取最新地址；已配好网可跳过填写。
4. 在手机系统中切回家庭网络，点击“已切回家庭 Wi-Fi，完成配对”。核对设备身份和认证后保存。
5. 要触摸回复时，在首页“选择原聊天”，按标题确认绑定，再开启“触摸主动回复”。自动同步记录默认开启，可以先查看历史。

正常流程自动读取 IP 和令牌。备用入口位于“设备与连接”，支持连接文件、连接码、拍照或相册二维码；设备设置页可临时显示二维码。相机或 WebView 无法返回结果时使用文件导入。详细步骤见[免电脑指南](OPERIT_NO_PC.md)。

## 电脑采集：首次使用

1. 完整解压 Windows 包，双击 `AI_Doll.cmd`，打开“Operit 手机陪伴”。包内自带 Python。
2. 手机与电脑接入互通的家庭网络。选择手机可访问的**电脑 IP**，点击“保存并启动”。
3. 点击“下载手机工具包”和“导出手机连接”，将 `.toolpkg` 与连接 JSON 传到手机。
4. 在 Operit 包管理导入工具包，打开面板，选择“导入服务器／电脑连接”，导入 JSON。
5. 在“对话窗口绑定”按标题选择聊天并确认，再点“一键检查”。插件配置自己的工作流与状态文件；Android 提示时授予所需文件权限。

手机导入的连接由自己的电脑生成。MCP 服务使用电脑局域网地址，电脑管理页在本机打开。Operit 安装包见[官方发布页](https://github.com/AAswordman/Operit/releases)。

## 自动检查与可选诊断

进入面板会自动检查连接，先显示已保存的信息，再更新在线状态。保存连接并绑定聊天后可直接开启触摸回复。

“发送诊断消息（可选）”用于排查聊天发送。看到消息和回复后可记录确认；日常互动通过连接与绑定检查即可启动。实际触摸发送结果待核对时，到原聊天确认，再用“测试与帮助”的恢复入口处理该条反馈。

工具包适配 Operit **1.12.2 ToolPkg／Workflow／MAIN Chat** 接口。后台延迟时先查看任务状态和 Android 省电设置。

## 陪伴首页与常开

选择陪伴方式，再开启“触摸主动回复”。可以先选 1 分钟测试，之后使用 15 分钟或“常开，直到我关闭”。主动开关默认关闭。

常开通过后台任务自动续接，状态区分别显示已保存的常开选择与实际运行状态。Android 需允许 Operit 后台运行；网络中断后按恢复策略续接，过期触摸留在历史。更改聊天或陪伴方式前关闭主动开关。

同一次按压主要回应一次，释放补充持续时间。关闭主动回复后，自动同步记录可以继续；已提交给模型的回复可能完成。结果待核对的发送先保留，核对原聊天后恢复，避免重复回应。

## 思考期间的触摸排队

“触摸合并与等待”设置停止按压后的等待时间，默认 **1 秒**，可设 **0～30 秒**并支持小数。大于 0 时等松开并经过相应安静时间再发送；0 为立即触发。运行中修改约 5 秒内生效。

模型生成期间继续采集。后续触摸合成下一批回复，每次按下和释放仍分别保存历史。有效新事件需在 30 秒内采集，已捕获触摸最多排队 120 秒；停止、静音或会话到期取消未发送反馈。

电脑／服务器的批次接口需要配套 0.1.1 或更新服务端。手机直连完整补传需要具备归档租约能力的固件；查看设备能力后选择升级。

## 分类设置

| 页面 | 可以做什么 |
| --- | --- |
| 身体与传感器 | 查看端口，修改部位和关闭／已接入状态，打开设备设置；0.1.2 可选择扩展事件只记录或允许回复 |
| 人设与反馈 | 选择人设来源，自定义触摸回应方式 |
| 对话窗口绑定 | 按标题选择已有聊天 |
| 设备与连接 | 添加娃娃、热点找回地址、导入连接、修正电脑 IP、查看已确认设备 IP |
| 测试与帮助 | 试摸一下、一键检查、发送诊断、核对上次发送结果 |
| 开发者选项 | 模拟输入、实时数值、配置与后台任务诊断 |

提示“请先停止当前后台任务”时，点击面板顶部的**停止后台任务**，再改连接、聊天或时长。它同时停止互动、自检、手机同步及续接；恢复记录时重新开启“自动同步记录”。旧包可在聊天中调用 `ai_doll_companion:stop`。

“关闭／模拟／已接入”由设备保存，需 `per_port_v1` 能力。已接入是用户确认的安装状态，FSR 松开也可能接近零。改一个端口保留其他端口与校准，见[端口与校准](../daily/CALIBRATION_AND_DAILY_MODE.md)。

手机直连在线修改名称和端口状态；别名、轻回应、互动提示和安静时段在电脑／服务器管理页设置。[设置能力对照](OPERIT_NO_PC.md#设置能力与离线边界)

## 查看互动记录

首页点击“查看互动记录”，可按日期、按下／松开等条件查询并翻页。手机直连读取手机归档，电脑／服务器模式读取相应数据库。手机已归档记录离线可查。

旧记录发生日期未知时，使用“查看时间未确认的记录”。日期支持中文输入法的全角横线，修改日期后点击“按日期查询”；翻页保持当前筛选。读取出错时按页面错误排查。

### 自定义触摸回应

进入“设置 → 人设与反馈 → 触摸回应方式”，填写后点击“保存回应方式”。例如：“顺着当前话题，用一句温柔的话回应；连续触摸合并，可以提本批次数。”最多 4000 字；保存空白或点击“恢复默认回应方式”可还原。

保存后从下一批触摸使用新提示词，当前生成中的回复继续完成。该设置保存在本机 Operit，适用于手机、电脑和服务器三条连接路线；可在设备离线或任务运行中编辑。

## 自动同步与补传

手机直连首页的“历史同步”显示最近同步、待补传、主归档端及缓存覆盖状态。可以开关“自动同步记录”或点击“立即同步记录”。实时采集和补传共用一个任务，模型思考期间继续记录。

手机归档写入并读回校验后才提交进度和 ACK。配套固件以 90 秒租约协调归档端，每 30 秒续租，每页最多读取 24 条持久事件。使用设备直传时，手机改为连接服务器。

旧固件的兼容复制保留缓存，当前页最多 24 条；完整分页需要配套固件。设备共缓存 256 条事件，按下／释放分别计数。手机任务停止期间依靠设备缓存，恢复后补传仍保留的记录。[断网记录说明](../daily/OFFLINE_RECORDS.md)

## 日常启动与停止

- 手机直连：给娃娃供电，打开面板，按需启用自动同步和触摸回复。
- 电脑采集：先双击 `AI_Doll.cmd` 启动服务，再使用手机面板。
- 暂停回复：关闭“触摸主动回复”，可继续保留同步。
- 全部停止：点击“停止后台任务”；电脑“停止手机连接”停止本项目的 Operit MCP 进程，保留数据。

手机和电脑需网络互通。连接失败时检查访客网络隔离、电脑防火墙与当前地址。

## 电脑重启后地址变化

1. 在电脑管理中心“Operit 手机陪伴”选择当前可用的电脑局域网 IP，点击“保存并启动”。
2. 手机“设置 → 设备与连接”中，在“电脑 IP（电脑重启后可修改）”填入该 IP，点击“检查并保存电脑 IP”。填写如 `192.168.1.20`，省略协议和端口。
3. 检查成功后恢复所需的后台任务。聊天绑定、端口、私密路径和历史保留。

地址检查失败时保留原连接。若换了电脑安装、私密路径或服务器，重新导入连接文件。电脑 IP 用于 MCP 服务，设备 IP 用于娃娃设置；`127.0.0.1:8769` 是电脑本机管理页。

## 仅手机模式：设备换 IP 或家庭网络

插件先检查上次地址和固定 `.local` 名称，并核对安装身份。前台单次恢复目标约 8 秒；后台失败按 2、5、10、30、60 秒退避，成功后重置。停止后台任务会结束自动重试。

名称解析失败时，用“添加娃娃／从热点找回地址”重新读取。更换家庭 SSID 或密码时，长按 BOOT 开热点重新配网，再切回家庭网络核对。相同身份保留聊天、回执与历史；USB 重刷产生新身份后重新配对。

服务器模式核对持久实例和配对标识，设备家庭 IP 变化由服务器路线处理。

## 工具包升级

先停止 AI Doll 后台任务，再导入新版工具包。若提示相同插件 ID 已存在：

1. 在包管理打开 AI Doll 详情，删除工具包文件，保留插件数据。
2. 导入新版，按名称打开“AI Doll · 连接与互动”。
3. 核对原连接、聊天与历史，再恢复任务。

升级保留 `Download/Operit/plugins/org.ai_doll.companion`，以及 Operit 应用数据。Operit 1.12.2 的删除包再导入流程已有数据保留记录；其他版本若出现删除插件数据选项，取消该选项并备份。遇到 `Failed to parse toolpkg file` 时，从发布页重新下载完整 `.toolpkg`。

## 从旧原型升级

停止旧独立监听与手工作流，改用单个 ToolPkg。电脑更换安装目录时迁移原 `build` 数据，再启动新版服务。

旧触摸发送结果尚待核对时，在面板绑定相同聊天和连接，使用“升级：选择旧发送记录（可选）”导入匹配 JSON，再核对原聊天。首次安装跳过这一步。

## 临时配网热点（固件0.1.1）

首次热点最长 10 分钟，新配网成功约 90 秒后关闭。正常重启连接家庭网络，断线后持续重连；维护时长按 BOOT 约 3 秒再松开，保持 RST 不动。

配置完成后到系统 Wi-Fi 切回家庭网络，再从已配对面板打开设备设置。[完整配网步骤](../daily/WIFI_CONNECTION.md)
