# 双击启动与快捷配对

适用：Windows 64 位完整软件包 v2.16.2，固件 v2.8.1。完整解压到固定、可写的目录，保留根目录 `python/` 和 `tools/`。包内已有 Python 与依赖，不需要安装 Python、设置 PATH 或输入安装命令。

## 先选择入口

| 你准备怎样使用 | 双击哪个文件 |
|---|---|
| 在现有 ChatGPT / Claude / 支持 MCP 的客户端中查询历史、进行限时互动 | `AI_Doll.cmd` |
| 让设备直接上传到电脑上的接收服务，供自己的应用或原前端接入 | `AI_Doll_Server.cmd` |

两种入口都管理设备和服务，回复继续出现在原来的 AI 聊天中。直连接收服务不会自动变成普通 Chat 的 MCP 连接；普通 Chat 的接入仍从管理中心配置 Secure MCP Tunnel。

## 原聊天的 MCP：一次识别，之后用 Wi-Fi

1. 双击 **AI_Doll.cmd**。完整包自动检查运行环境并生成本机 MCP 配置，首次直接进入设备配对。
2. 先给 ESP32 配好家庭 2.4 GHz Wi-Fi，让电脑与设备处于可互通的局域网。用 USB 将开发板接电脑，在“设备连接”填写实际串口，例如 COM3，点击 **一键识别并配对 Wi-Fi**。程序通过 USB 读取设备 IP 与 MCP 令牌，再验证 Wi-Fi 连接并保存；不用手动复制令牌。
3. 本机 MCP 客户端使用界面生成的 STDIO 配置。普通 Chat 使用 Secure MCP Tunnel，首次填写官方隧道 ID 和运行密钥，并在 ChatGPT 添加同一个隧道；已有配置可直接复用。无需另建娃娃账号或填写聊天模型密钥。
4. 在原聊天实际调用状态工具，随后查询历史或开始 60 秒互动。详细步骤见 [管理中心指南](GUI_GUIDE.md)。

Wi-Fi 配对完成后，开发板可独立供电，不必长期连接 USB 数据线。电脑与采集 / MCP 服务仍需运行。已有配置时再次双击会启动或复用服务；历史不会清空。

## 设备直连：填写 IP，点击连接

1. 双击 **AI_Doll_Server.cmd**。服务自动使用内置 Python 启动，并打开 `http://127.0.0.1:8781/` 管理页。本机管理连接自动完成，无需复制管理令牌。
2. 页面显示当前电脑的“设备连接地址”。填写已配网娃娃的局域网 IP，例如 `192.168.1.50`，点击 **连接设备**。程序读取设备身份、生成连接配置，并写入开发板。设备设置页默认免登录；只有你开启了登录保护才需要展开并填写账号密码。
3. 点击“刷新连接状态”。收到实际上传后，设备才显示“在线”，并显示最后同步时间。点击设备下方的链接，可设置通道类型 / 部位、人设与偏好，查看历史并模拟输入。

快捷配对成功会启用设备的“直连服务器”。该设备改由直连服务归档；原电脑采集器检测到这个开关后暂停读取，避免两个归档服务争用设备记录。要恢复普通 Chat 的电脑采集流程，在设备设置页关闭“直连服务器”，然后启动管理中心的日常服务。两边已有历史均保留。

关闭浏览器不会停止服务。在“服务器地址与其他安装方式”中点击 **停止服务端**；下次双击可重新启动。重复启动会复用本安装的服务，端口被其他程序占用时会提示失败，不结束其他程序。

## 地址与配网

- **设备未配网**：长按 BOOT 约 3 秒，连接无密码的 `AI-Doll-xxxxxx` 热点，打开 `http://192.168.4.1/`，扫描并选择家庭 2.4 GHz Wi-Fi。联网后设置 AP 关闭，指示灯常亮。设置页默认免登录，可按需开启“设置页登录保护”。
- **不知道设备 IP**：MCP 管理中心可通过 USB 一次识别；直连服务端填写设备设置页 / 路由器中显示的 IP。
- **电脑有多张网卡**：展开“服务器地址与其他安装方式”，将服务器地址改为开发板能够访问的电脑局域网 IP，保存后再次点击“连接设备”。电脑 IP 变更后也按此操作。
- **需要远程服务器**：已有 Linux 服务器和域名时使用 [部署指南](DIRECT_SERVER.md) 的 Docker Compose / HTTPS 模板。Windows 双击入口提供本机接收服务，不会自动购买服务器、绑定域名或申请公网证书。
- **设备不在本机可达的局域网**：使用页面中的“手动添加 / 远程设备”，在设备设置页粘贴生成的配置。配置完成后仍需实际上传才能确认在线。

自己的前端通过事件适配器沿用原模型、上下文与聊天 ID，接入见 [直连与原前端指南](DIRECT_SERVER.md)。普通 Chat 的空闲主动唤醒仍需宿主单独验收。

## 保存的数据

电脑 MCP 配置和历史在 `build/device-lab/`；设备直连服务配置和历史在 `build/direct-server/`。停止、重启或重复启动不清空这些目录。升级时保留原数据目录，不用重新配对。软件包中的公共模板不包含个人历史或本机连接信息。

目前开发板未接实体传感器。使用模拟压力测试，来源标记为 simulation，物理输出保持关闭；模拟成功不能代替实物压力和执行器验收。
