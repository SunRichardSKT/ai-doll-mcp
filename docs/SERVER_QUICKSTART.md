# 在电脑上启动接收服务器

适用于自己的聊天应用，先用 Windows 电脑接收设备直接上传的记录。普通 Chat 用户使用 [AI_Doll.cmd](AI_INSTALL.md)；真正远程 Linux 部署使用 [Install_Server.sh](REMOTE_SERVER_SETUP.md)。

## 四步连接

1. 完整解压 Windows 软件包，双击根目录 **AI_Doll_Server.cmd**。
2. 程序使用内置 Python 启动接收服务，打开管理页，自动生成本机连接配置。
3. 给 ESP32 配好 Wi-Fi，让电脑和设备在可互通的局域网。在页面填写设备 IP，点击 **连接设备**。
4. 等待设备实际上传后显示在线，再模拟按压，检查历史新增记录。

连接操作自动写入设备直传设置，重复配对复用绑定，无需手工复制令牌。若设备开启网页登录保护，使用自行设置的账号密码；默认不要求。

电脑有多张网卡或 IP 改变时，展开“服务器地址与其他安装方式”，选择娃娃可访问的电脑局域网 IP，保存后重新连接设备。不能把 `127.0.0.1` 当作设备能访问的电脑地址。

## 什么时候需要手动配置

设备不在电脑可直接访问的局域网时，在“手动添加 / 远程设备”生成配置，用手机粘贴到设备“直连服务器”。真实远程服务器部署见 [远程指南](REMOTE_SERVER_SETUP.md)。

## 停止与切回电脑 MCP

关闭浏览器不停止服务；页面中点击 **停止服务端**，下次双击可重新启动。重复启动复用本安装，其他程序占用端口时提示失败，不结束它。

直传模式开启时，电脑采集器停止读取和确认缓存，避免抢同一份记录。切回原电脑 MCP 时，先在设备页关闭直传，再启动管理中心的日常采集。两边旧历史均保留。

本机直传配置与数据库在 `build/direct-server/`，电脑 MCP 数据在 `build/device-lab/`。接收服务器不是独立 AI，原应用回调见 [接口指南](DIRECT_SERVER.md)。
