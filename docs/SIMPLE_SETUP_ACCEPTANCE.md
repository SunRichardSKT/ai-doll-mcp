## Windows 完整包

根目录 Python 自带依赖；从含中文和空格的全新目录运行，在 PATH 无系统 Python、无虚拟环境时，两个根目录启动入口、自动生成 MCP 配置、SDK 实际发现 45 个工具及服务端重复启动通过。桌面与手机尺寸页面检查通过。

真实 ESP32 快捷配对已确认写入直传配置、通过 Wi-Fi 上传并归档模拟压力记录；重复配对复用绑定。随后恢复原电脑 MCP 采集方式，物理输出关闭。

## 远程部署

远程安装共 8 项测试通过：Bash 测试替身检查下载校验、安装、重复安装、停止、保存配置、域名与 DNS 错误、证书失败、陌生目录和既有项目保护；另从实际小型服务包启动真实 HTTP 服务并调用管理接口，验证包内运行文件完整。替身不安装系统软件、不申请证书，不代表真实公网部署。

相关验证共 55 项通过：远程安装与小型包 8 项、完整 Windows 包 1 项、服务端 22 项、快捷设置 5 项、GUI 后端 17 项、真实进程启动 / 重复启动 / 停止与端口保护 2 项。证据保存在本机 `build/portable-acceptance/` 与对应测试输出。

此电脑没有运行中的 Docker 引擎，用户没有远程服务器和域名；实际 Docker 构建、远端官方 apt 安装、自动签发公网证书与开机恢复需在对应服务器验收。安装器只有校验证书及本安装管理接口成功后才显示部署成功。

操作见 [远程服务器快捷部署](REMOTE_SERVER_SETUP.md)。设备直传服务与普通 Chat MCP 的宿主接入分别验收；本轮不承诺普通 Chat 空闲唤醒。
