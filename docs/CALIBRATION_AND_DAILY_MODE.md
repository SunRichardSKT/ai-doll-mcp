# FSR 压力校准与日常模式

没有传感器时保持手动 / 模拟模式，不做真实校准。安装八路 FSR 后，每路分别采集静置、轻按、用力按，确认推荐值再保存。

## 第一次校准，按这个顺序

1. 按 [接线指南](SENSOR_CHANNELS.md)确认电源、模块方向、4051 和传感器，观察各路读数随对应按压变化。
2. 在设备页或管理中心“通道与校准”启用真实输入，通道绑定实际 `mux_adc` / `gpio_adc`。
3. 选择 CH0，娃娃保持最终安装姿态，不触碰传感器，采集静置约 3 秒。
4. 保持轻按采集；再保持更强的按压采集。三阶段依次完成。
5. 检查推荐值；通过后点击 **保存推荐阈值**。其余通道按同样步骤处理。

静置不稳定、样本不足、轻按与静置分不开、强按低于轻按或 ADC 饱和时不能保存。先修复接线 / 安装，再重采。模拟值不能代替真实校准。

## 手动阈值与模式

每路可设置 `press_threshold`、`release_threshold`，要求 `0 <= release < press <= 4095`。这是 ADC 触发阈值，不是牛顿。

| 设置 | 当前与重启行为 |
| --- | --- |
| 手动模式（默认） | 重启不启用真实输入 |
| 日常模式 | 用户确认硬件后启用输入，重启恢复输入 |
| 临时输入开关 | 只改当前状态，不改重启策略 |
| 保存全部通道配置 | 关闭输入 / 输出，取消日常模式 |
| 只改部位或保存校准阈值 | 不取消已有启动策略 |

输出从不自动恢复。想永久停止输入应保存手动模式，不能只临时关开关。

## 校准期间与诊断

选中通道暂停普通触摸事件，其他通道照常；开始校准会停止并关闭真实输出，校准时不能开启。取消或 60 秒无操作退出，不保存阈值。重新采前阶段清空后续阶段。

诊断显示来源、单位、有效性和阈值，曲线保留最近 120 次有效读数。断线后旧曲线不是新读数。接触不良和未被按压都可能接近 0，零值不能证明断线。

## 开发 / MCP 参考

每阶段 `duration_ms=500..10000`，最多 512 样本，使用静置 95 百分位、轻按 20 百分位和强按统计判断分离，设置迟滞。

| 工具 | 用途 |
| --- | --- |
| `capture_pressure_calibration` | channel、stage=0/1/2，启动非阻塞采集 |
| `get_pressure_calibration` | 进度、统计、失败原因及推荐值 |
| `apply_pressure_calibration` | 显式保存有效推荐值 |
| `cancel_pressure_calibration` | 取消不保存 |
| `get_operating_mode` / `set_operating_mode` | 启动策略；daily 要求 `hardware_confirmed=true` |

真实压力尚未接线验收，见 [验证汇总](VALIDATION.md)。AI 不应替未安装硬件作确认。
