# 压力校准、日常模式与实时诊断

设备固件 v2.3.0；电脑 Bridge v2.6.0。固件 v2.3 加入 6 个模式/校准工具；当前电脑 MCP 共 35 个，设备 MCP 共 22 个。必须升级固件才能使用这些校准工具，仅更新电脑代码不够。

## 没有传感器时

保持“手动模式”，不要勾选已安装硬件。可使用原来的模拟压力/温度，以及新增的实时诊断曲线。曲线和日志会明确标记 simulation，模拟测试不会产生真实压力或电机反馈。

## 安装后的第一次校准

1. 检查主板供电、SuperMini 方向、74HC4051 和 FSR 接线。先验证八路数值能随对应传感器变化。
2. 在设备设置页或电脑 `/companion` 页面启用真实输入。压力通道必须绑定实际的 `mux_adc` 或 `gpio_adc`。
3. 在“日常使用与压力校准”选择通道。让娃娃保持最终安装姿态，不碰传感器，点击“静置采集”，等待约 3 秒。
4. 保持轻按并点击“轻按采集”；随后保持更强的按压并点击“用力按采集”。三阶段须按顺序完成，不能用模拟数值替代。
5. 查看数据与推荐阈值。轻按未明显高于静置、静置不稳定、样本不足、用力按反而低于轻按或 ADC 饱和时不能保存，先检查接线、安装及动作，再重新采集。
6. 点击“保存推荐阈值”，只更新所选通道的按下/释放阈值；其他通道参数和历史不变。重启后阈值保留。校准期间不要同时从另一个页面编辑通道。

每阶段最多 10 秒，最多保存 512 个采样点。算法使用静置的 95 百分位、轻按的 20 百分位和强按统计来判断可分离性，再设置具有迟滞的两条阈值；这些是 ADC 触发阈值，不是牛顿标定。

选中通道在整个校准流程暂停普通触摸事件；其他通道照常工作。开始校准会停止并关闭真实震动输出，校准期间不能启用真实输出。取消或 60 秒无操作退出，不会自动修改阈值。重新采集前一个阶段会清空后续阶段，避免旧样本混用。

## 日常模式与手动模式

确认已装好真实传感器后勾选硬件确认，点击“保存日常模式”。立即启用真实输入，并在以后重启自动恢复。震动输出不自动恢复，也不自动执行上一次命令。

“恢复手动模式”会关闭真实采集、停止输出并保存重启关闭输入的策略。旧 v2.2 配置升级时仍默认手动，不会擅自开启采样。

临时的“应用输入开关”只改变当前采样状态，不修改日常启动策略。若日常模式下临时关闭输入，重启仍会恢复；希望永久关闭时必须保存手动模式。

保存整份通道配置会关闭真实输入/输出并返回手动模式，需重新检查接线后确认日常模式。只改部位名称或保存本次校准阈值不会取消已有启动策略。

## 诊断页面

显示类型、单位、真实/模拟来源、有效性、压力触发状态及两条阈值。可以选择任意通道，查看最近 120 次有效读数；绿色表示真实采样，棕色表示模拟。曲线横轴为等间距采样点，没有承诺精确时间或真实力单位。

无效、过期或关闭的真实输入不会显示成有效当前值；连接中断会注明曲线是以前的读数。单个接触不良的 FSR 与未被按压可能都接近 0，不能仅凭零读数认定传感器断线。

## 新 MCP 工具

| 工具 | 用途 |
|---|---|
| get_operating_mode | 读取启动策略及当前输入/输出状态 |
| set_operating_mode | 保存 manual 或 daily；daily 要求 hardware_confirmed=true |
| capture_pressure_calibration | channel、stage=0/1/2、duration_ms=500..10000，非阻塞采集 |
| get_pressure_calibration | 读取进度、各阶段统计、原因及推荐阈值 |
| apply_pressure_calibration | 显式保存有效推荐值 |
| cancel_pressure_calibration | 取消且不保存 |

AI 不应自行把用户尚未安装的硬件标成已确认，不应声称模拟校准是真实传感器验收。具体实测范围见 [测试记录](DEVICE_LAB_TEST_REPORT.md)。
