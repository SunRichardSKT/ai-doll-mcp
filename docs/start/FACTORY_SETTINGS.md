# 新板第一次启动与恢复出厂

> [返回完整目录](../README.md) · [一键烧录](QUICK_FLASH.md)

新板第一次烧录后，程序会自动初始化；不需要你填写配置文件。已有板标准升级保留设置，只有明确选择“恢复出厂”才清空。

## 首次启动默认值

| 项目 | 默认行为 | 为什么这样设置 |
| --- | --- | --- |
| 设备名称 | 烧录时选择自定义名或随机名；内部编号每次新建 | 热点易辨认，配对身份仍可追溯 |
| 家庭 Wi-Fi | 未配置 | 由用户选择自己的网络 |
| 设置热点 | 开启，固定页面 http://192.168.4.1/ | 首次配网和日后修改都有入口 |
| 网页登录 | 默认免登录，可自行开启保护 | 先完成基本连接 |
| MCP 接口 | 开启，独立随机配对令牌 | 便于与自己的 AI 配对，无公共固定令牌 |
| CH0～CH7 | 预设八路压力、对应 MUX 0～7，仅 CH0 启用 | 默认装好主板及 J1 传感器；其他通道按实物启用 |
| 真实输入 | CH0 开启，日常模式，重启后恢复 | 直接接收已装传感器的输入 |
| 电机输出 | 关闭，重启不自动恢复 | 电机需要板外驱动 |
| 压力阈值 | 按压 1200、释放 800 | 起始参考，实际安装后校准 |
| 直传服务器 | 关闭，没有服务器配置 | 不预设用户自己的服务器 |
| 电脑人设和历史 | 随本机管理程序另行建立 | 公共软件不附带别人的个人记录 |

在设备状态中，新安装配置标记为 `physical-ch0-v1`，传感器模式为 `sensor`。旧设备保留原通道、日常模式和校准，可能显示 `safe-manual-v1` 或 `legacy`，这些兼容标记不代表故障。模拟测试放在设备设置页的开发者选项中。

## 标准烧录与恢复出厂的区别

| 内容 | 标准烧录 | 明确选择恢复出厂 |
| --- | --- | --- |
| 固件程序 | 更新 | 重新写入 |
| 设备名称和烧录编号 | 按本次命名选择保存，内部编号换新 | 按本次命名选择保存，内部编号换新 |
| 家庭 Wi-Fi、通道、校准、日常模式 | 保留 | 清除，回到默认 |
| 配对令牌与网页保护 | 保留 | 清除并重新初始化 |
| 板内离线缓存 | 保留 | 清除 |
| 电脑历史与人设 | 保留 | 保留 |
| 本次日志和结果 | 新建独立目录 | 新建独立目录 |

恢复出厂会清空整个设备 Flash，再写入完整镜像。页面需要选中恢复出厂并勾选清除确认；命令行需显式传入 `--factory`。普通刷新页面、重启和标准烧录都不会自动执行它。

本次 USB 烧录设置的名称会保持到下一次 USB 烧录。RST、断电和日常重启不改名称与编号。OTA 只更新应用，保留设备名称和 USB 烧录编号。

## 初始化后做什么

按 [配网教程](../daily/WIFI_CONNECTION.md)连接网络。默认接收 J1／CH0 压力输入；其他通道只按实际安装启用。按 [校准教程](../daily/CALIBRATION_AND_DAILY_MODE.md)采集三阶段数据。旧板升级后仍使用原来的采样模式，需要恢复采样时检查已保存的日常模式。
