# 一代批量烧录与八路实时数据

[教程目录](../README.md) · [一代硬件](../../hardware/gen1/README.md)

下载 Release 附件 `AI_Doll_Factory_v0.1.4.zip` 并完整解压，在 Windows 双击 **AI_Doll_Factory.exe**。程序自带运行环境，一次连接一块一代 ESP32-C3 主板，持续显示八路真实 ADC、各路本次最低值、最高值、变化范围和电平条。

## 出品操作

1. 用数据线连接 SuperMini USB 口，串口自动刷新；只有一块原生 USB C3 时自动选择，也可手选。关闭占用该串口的监视器与采集服务。
2. 选择随包固件、本地 ZIP、本地固件目录，或点击“从 GitHub 更新”。窗口显示校验后的来源、版本与八路采样支持情况。
3. 可填写设备名称。烧录时名称写入设备显示名和热点名，允许 1～32 个 UTF-8 字节，中文通常每字 3 字节；留空使用随机名称。批次／编号字段单独保存到本机记录。
4. 点击“烧录并实时采样”。仅查看已刷好主板时点击“开始实时采样”。默认烧录速度为 115200，连接稳定后可选 460800。
5. 自由按压任意传感器，可同时按下多个，观察八路数据变化。程序持续采样，由操作员点击“停止采样”结束并保存记录。
6. 换下一块板，等待串口刷新，再次开始。每次开始会重置本次最低、最高值。

烧录期间保持连接，必要时按住 BOOT、点按 RST、松开 BOOT。关闭忙碌窗口会请求结束任务，等待写入或下载完成后保存记录并关闭。

## 固件来源和设备身份

本地 ZIP 需包含一套同目录的四镜像和 `FLASH_MANIFEST.json`，也可选择包含这五个文件的目录。复用项目烧录器校验芯片、地址、大小和 SHA-256。GitHub 更新从项目最新正式 Release 下载，额外核对发布包 `SHA256SUMS.txt`，下载并校验完成后选中，点击烧录按钮才写板。准备来源期间操作按钮锁定，下载或校验失败时保留先前选择。

普通烧录保留配网、端口状态、校准和历史，每次生成新内部设备编号。自定义名称作为显示名与热点名。批量工具的操作记录独立保存，设备身份以本次烧录回读为准。

八路实时采样需要固件提供 `factory_sample_revision=1`。窗口标明所选包是否声明支持；旧包仍可烧录，烧录成功后若设备不支持采样，会明确提示。采样支持情况与烧录结果分别记录。

随包固件具有一代日常功能和 USB 八路采样入口。该入口直接读物理 MUX 口，日常关闭的通道也可查看；日常使用按已保存的端口配置运行，新板默认只启用 CH0。实际装了其他通道时，应按接线设为“已接入”。

## 观察与记录

实时数据由操作员观察判断。窗口取消逐路引导、基线门限和阶段倒计时，连续采样到手动停止。串口错误、重启、设备身份变化或无效采样会结束本轮并记录原因。

每次操作在程序旁 `build/factory-check/` 保存独立 JSON，并追加 Excel 可读的 **检测汇总.csv**。包含批次、名称、时间、实际设备身份、烧录来源与结果、采样帧数、八路观察范围和最后读数。手动停止后的正常采样标为“已记录”，通过通道栏留空，供人工验收。历史引导版的通过／未通过记录继续保留。

烧录日志在 `build/flash/`，下载缓存位于 `build/flash-sources/`。这些目录只保留在生产电脑。Excel 占用汇总表时，先关闭文件再保存新一轮记录。

单路无响应、固定高值或串扰时，按[单通道故障标准测试流程](SINGLE_CHANNEL_TEST.md)定位。电池／开关供电、充放电温升、Wi-Fi、NTC 和湿润片按各自功能另行验收。

## 维护与打包

复制程序时保留整个文件夹。根目录入口为 `AI_Doll_Factory.exe`，运行库和烧录辅助程序在 `_internal`，源码在“对应源码”。重新打包保留程序旁已有 `build/` 记录。

维护使用项目 `.venv` 或带 Tcl/Tk 的 Python，安装 `requirements-flash.txt` 后运行 `python tools/factory_check.py`。独立打包安装 `requirements-factory-build.txt`，再运行 `python tools/package_factory.py`。修改固件后先编译并导出镜像。要生成发布附件，运行 `python tools/package_factory.py --release-zip delivery/AI_Doll_Factory_v0.1.4.zip`，再通过 `python tools/package_companion.py --include-factory` 校验并写入交付清单。

开发回归运行 `python -m unittest discover -s tools -p test_factory_check.py`，固件来源测试见 `test_flash_sources.py`。替身采样仅验证程序逻辑，实体传感器按实物连接和观察记录验收。
