接入现有前端
你原来的聊天负责模型调用、上下文和消息展示。设备服务提供新事件、部位、人设与反馈偏好。
  1. 在原聊天中绑定稳定的 chat_id。
  2. 开启互动并订阅事件流。
  3. 新按压到达后，调用原模型生成队列。
  4. 将回复写入原对话，并确认事件回执。
浏览器适配器支持本地或服务器地址。默认普通状态只记录；前端可明确开启较长互动并续订。
