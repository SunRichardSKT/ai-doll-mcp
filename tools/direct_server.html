开发者：接入自有前端
接入现有前端
你原来的聊天负责模型调用、上下文和消息展示。设备服务提供新事件、部位、人设与反馈偏好。
  1. 在原聊天中绑定稳定的 chat_id。
  2. 开启互动并订阅事件流。
  3. 新按压到达后，调用原模型生成队列。
  4. 将回复写入原对话，并确认事件回执。
浏览器适配器支持本地或服务器地址。默认普通状态只记录；前端可明确开启较长互动并续订。

Operit 手机陪伴 · 无需电脑
设备上传到本服务器，Operit 继续使用你原来的聊天、模型和人设。
  1. 下载本服务器提供的同版工具包，在 Operit 包管理中导入。
  2. 在下方设备卡片下载连接文件，手机面板中导入一次。
  3. 选择已有聊天，检查连接后即可开启触摸回应；发送聊天诊断为可选。
  4. 选择限时或常开陪伴，返回原聊天。可在任何能访问服务器的网络使用手机。
